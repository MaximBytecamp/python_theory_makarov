§4Как готовиться и проверять решения

  1. Решите один вариант целиком без справочника. Засеките время.
  2. Запустите каждую программу и введите значения из колонки «Ввод»: каждое значение отдельной строкой, после каждого Enter.
  3. Сравните вывод с колонкой «Вывод» символ в символ: пробелы, двоеточия, количество знаков после точки. Подсказки input() в примерах не показаны, проверяется только результат.
  4. Прогоните все примеры задачи. Второй и третий пример часто проверяют крайний случай: ноль, отрицательный результат, ровное деление.
  5. Если задача не решилась, откройте главы из строки «Повторить» и задачи к ним, затем решите ту же задачу в другом варианте.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Ввод — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
