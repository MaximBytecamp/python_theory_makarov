§1Разборы: как решать и оформлять

Три задачи решены полностью. Обратите внимание на порядок: сначала ввод, потом проверки — каждая в своей переменной с именем на is_ или has_, в конце вывод.

Разбор 1

Вход в кинозал

★☆☆базовая

На сеанс пускают зрителей от 18 лет с билетом. Пользователь вводит возраст и отвечает, есть ли у него билет: да или нет. Выведите результат каждой проверки и общий ответ: можно ли войти.

Как рассуждаем

  1. Проверок две: возраст не меньше 18 и билет есть. Каждую сохраняем в свою переменную.
  2. Ответ про билет приходит строкой. Сравнение answer == "да" превращает его в логическое значение.
  3. Войти можно, когда выполнены обе проверки, — значит, соединяем их через and.

Проверка на других данных

Пример 1
Ввод
16
да
Вывод
Совершеннолетний: False
Билет есть: True
Можно войти: False
Пример 2
Ввод
30
нет
Вывод
Совершеннолетний: True
Билет есть: False
Можно войти: False
Почему не bool(answer)

Функция bool() считает ложью только пустую строку. Строка "нет" не пустая, поэтому bool("нет") — это True. Чтобы получить логическое значение из ответа, строку сравнивают с ожидаемым словом: answer == "да".

Зачем переменные is_adult и has_ticket

Последнюю строку можно записать как age >= 18 and answer == "да". Результат тот же, но запись is_adult and has_ticket читается без расшифровки чисел и строк.

Разбор 2

Бесплатная доставка

★★☆средняя

Интернет-магазин доставляет заказ бесплатно, если сумма заказа не меньше 3000 рублей или у покупателя есть подписка. Вводятся сумма заказа и ответ про подписку (да или нет). Выведите, бесплатна ли доставка и нужно ли за неё платить.

Как рассуждаем

  1. Условий два, и достаточно любого из них. Это оператор or.
  2. Результат сохраняем в is_free: он нужен дважды.
  3. «Нужно платить» — это противоположный ответ. Его даёт not is_free, второй раз условие не записываем.

Проверка на других данных

Вывод

Доставка платная: False
Пример 2
Ввод
900
нет
Вывод
Доставка бесплатная: False
Доставка платная: True
Пример 3
Ввод
5000
да
Вывод
Доставка бесплатная: True
Доставка платная: False
Оба условия сразу

В последнем примере выполнены оба условия: и сумма большая, и подписка есть. Оператор or в этом случае тоже даёт True: ему нужно хотя бы одно истинное условие, а не ровно одно.

Разбор 3

Отбор кандидата

★★☆средняя

На вакансию берут кандидата, который подходит по трём требованиям: возраст от 18 лет, стаж от 3 лет и не меньше 60 баллов за тест по английскому. Вводятся возраст, стаж и балл. Выведите, сколько требований выполнено и подходит ли кандидат.

Как рассуждаем

  1. Три требования — три проверки, каждая в своей переменной.
  2. Кандидат подходит, когда выполнены все три: соединяем через and.
  3. Количество выполненных требований получаем сложением: True в арифметике равно 1, False — 0.

Проверка на других данных

Пример 1
Ввод

1
80
Вывод
Выполнено требований: 2 из 3
Кандидат подходит: False
Пример 2
Ввод
17
0
40
Вывод
Выполнено требований: 0 из 3
Кандидат подходит: False
Почему логические значения складываются

Тип bool — подкласс int, поэтому True + True + False равно 2. Сумма проверок — это количество истинных среди них.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
