§1Разборы: как решать и оформлять

Три задачи решены полностью. Смотрите не только на ответ, но и на оформление: исходные данные сверху, расчёт отдельными строками с понятными именами, вывод — в конце.

Разбор 1

Поменять значения местами

★☆☆базовая

Программа читает два числа в переменные a и b, меняет их значения местами и выводит.

Как рассуждаем

  1. Наивный вариант a = b, затем b = a теряет старое значение a на первой же строке.
  2. В записи a, b = b, a правая часть вычисляется первой: берутся текущие значения, потом раздаются по именам.
  3. Третья переменная для обмена не нужна.

Проверка на других данных

Пример 1
Ввод
-1
0
Вывод
a = 0
b = -1
Как не надо

a = b → в a уже 9, пятёрка потеряна; b = a → в b тоже 9. Обе переменные получили одно значение.

Разбор 2

Дежурство по кругу

★★☆средняя

Три сотрудника дежурят по очереди: сегодня первый, завтра второй, послезавтра третий. Каждую неделю очередь сдвигается: первый уходит в конец. Выведите очередь сейчас и через неделю.

Как рассуждаем

  1. Сдвиг по кругу: новый первый — это старый второй, новый второй — старый третий, новый третий — старый первый.
  2. Все три имени меняются одновременно, поэтому пишем одну строку: first, second, third = second, third, first.
  3. Имена — строки, преобразовывать ввод не нужно.
Проверка по шагам

Правая часть second, third, first — это значения «Борис», «Вера», «Анна». Они раздаются по порядку: first = Борис, second = Вера, third = Анна. Если бы присваивание шло по одному, Анна потерялась бы на первом шаге.

Разбор 3

Робот-пылесос на плане квартиры

★★☆средняя

Робот стартует в точке (0, 0). За один шаг он смещается на dx по горизонтали и dy по вертикали. Выведите координаты после первого и второго шага.

Как рассуждаем

  1. Координаты — пара связанных величин: задаём и обновляем их вместе, одной строкой.
  2. Новая точка = старая точка + смещение: x, y = x + dx, y + dy.
  3. Смещение вводится один раз и используется на обоих шагах.

Проверка на других данных

Пример 1
Ввод
0
5
Вывод
После шага 1: (0, 5)
После шага 2: (0, 10)
Когда объединять в одну строку

x, y = 0, 0 читается как одна мысль — «точка в начале координат». А вот dx и dy приходят разными вводами, и склеивать их нечем: разбирать строку на части научимся в главе о строках.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
