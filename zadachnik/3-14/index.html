§1Разборы: как решать и оформлять

Три задачи решены полностью. В них по очереди работают enumerate(), zip() и пара any() / all().

Разбор 1

Нумерованный список покупок

★☆☆базовая

Приложение показывает список покупок с номерами. Вводятся количество товаров и названия, по одному в строке. Выведите каждый товар в виде 1. молоко, нумерация с единицы.

Как рассуждаем

  1. Номер нужен вместе с названием в каждой строке вывода. Для этого подходит enumerate(): он выдаёт пары «номер — значение».
  2. По умолчанию номера идут с нуля, а покупателю нужна единица. Параметр start=1 сдвигает только номер, сам список не меняется.
  3. Пара сразу распаковывается в две переменные в заголовке for.

Проверка на других данных

Пример 1
Ввод
1
чай
Вывод
1. чай
Пример 2
Ввод
0
Вывод


start=1 не сдвигает элементы
Первый товар по-прежнему лежит в items[0]. Параметр start меняет только число, которое enumerate() выдаёт рядом с элементом. Если взять items[number], то при нумерации с единицы получится сдвиг на один элемент, а на последнем номере — ошибка.






Разбор 2
Чек из двух списков
★★☆средняя




На кассе пробили несколько позиций. Вводятся количество позиций, затем столько же цен, затем столько же количеств. Для каждой позиции выведите строку Позиция 1: 3 x 120 = 360 (количество, цена, стоимость), в конце — Итого: ….


Как рассуждаем


  1. Цена и количество одной позиции лежат на одинаковых местах в двух разных списках. Параллельный проход по ним — это zip(prices, quantities).
  2. Нужен ещё и номер позиции. Тогда enumerate() оборачивает zip(): каждый шаг выдаёт номер и пару. Пару в заголовке for записывают в скобках.
  3. Стоимость позиции считаем в теле цикла и сразу добавляем к итогу. Итог выводим после цикла.

Если списки разной длины
zip() останавливается, когда кончился самый короткий список. Лишние элементы длинного списка молча отбрасываются и ошибки не будет. Поэтому в задаче количество вводится один раз и для цен, и для количеств.






Разбор 3
Проверка пульса
★★☆средняя




Фитнес-браслет записал серию измерений пульса. Вводятся количество измерений и сами значения. Норма — от 50 до 100 ударов в минуту включительно. Если измерений нет, выведите Измерений нет. Иначе выведите Все в норме или Есть выход за норму, а второй строкой — Тревога, если хотя бы одно значение выше 140, иначе Тревоги нет.


Как рассуждаем


  1. Вопросов два. «Все ли значения в норме?» — это all(). «Есть ли хотя бы одно выше 140?» — это any().
  2. Обе функции работают со списком из True и False. Строим два списка одним проходом: для каждого пульса добавляем результат проверки.
  3. Пустой список обрабатываем отдельно, до вызова функций: all() от пустого списка даёт True, и без проверки браслет объявил бы «все в норме» при нуле измерений.

all() и any() на пустом списке
all([]) равно True: нет ни одного элемента, который нарушил бы условие. any([]) равно False: нет ни одного подходящего. Если для пустого входа нужен особый ответ, его проверяют отдельным if заранее.

§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
