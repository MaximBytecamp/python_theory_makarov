§1Разборы: как решать и оформлять

Три задачи решены полностью. В первой перебирается строка, во второй — числа из range() с накоплением нескольких величин, в третьей цикл прерывается по условию и использует блок else.

Разбор 1

Сколько раз встречается буква

★☆☆базовая

Вводятся слово и одна буква. Выведите, сколько раз эта буква встречается в слове, в формате Буква «а»: 3 раз(а) — подставьте введённую букву и найденное число.

Как рассуждаем

  1. Строку можно перебирать: цикл for берёт из неё символы по одному.
  2. Нужен счётчик count, который до цикла равен нулю.
  3. Для каждого символа сравниваем его с искомой буквой. Совпало — счётчик растёт на 1.
  4. Вывод стоит после цикла, на уровне самого for: иначе сообщение напечатается для каждой буквы.

Проверка на других данных

Пример 1
Ввод
банан
к
Вывод
Буква «к»: 0 раз(а)
Пример 2
Ввод
ааа
а
Вывод
Буква «а»: 3 раз(а)
Переменная цикла получает копию элемента

Имя letter в каждом проходе указывает на очередной символ. Изменить саму строку через эту переменную нельзя. Если нужен результат обработки, его накапливают в отдельной переменной — здесь это count.

Разбор 2

Выручка за неделю

★★☆средняя

Магазин ведёт учёт выручки по дням. Вводятся плановая дневная выручка, число дней n и затем выручка за каждый из n дней. Выведите три строки: Всего: ..., Лучший день: ... (наибольшая выручка) и Дней с выполненным планом: ... (выручка не меньше плана).

Как рассуждаем

  1. Число дней известно заранее, значения вводятся по одному. Подходит for day in range(n): тело выполнится n раз. Значение day тут не нужно, оно служит только счётчиком повторов.
  2. Три результата — три накопителя: total, best и days_done. Все три заводятся до цикла.
  3. Выручка не бывает отрицательной, поэтому лучший день можно начать искать с нуля: любая введённая выручка не меньше него.
  4. В теле цикла читаем число и обновляем все три накопителя. Сравнение с планом и с лучшим — два отдельных if, потому что оба условия могут выполняться одновременно.

Проверка на других данных

Пример 1
Ввод
3000
1
2000
Вывод
Всего: 2000
Лучший день: 2000
Дней с выполненным планом: 0
Пример 2
Ввод
100
0
Вывод
Всего: 0
Лучший день: 0
Дней с выполненным планом: 0
Два if подряд и if / elif — разные вещи

Если связать проверки в if / elif, то день, который побил рекорд, не попал бы во вторую проверку, и подсчёт дней с выполненным планом оказался бы неверным. Когда условия независимы, каждое записывают отдельным if.

Разбор 3

Допуск к экзамену

★★★повышенная

Студент допускается к экзамену, если по всем предметам оценка не ниже 3. Вводится число предметов n, затем оценки по порядку предметов. Если найдена оценка ниже 3, выведите Долг по предмету N с номером предмета (начиная с 1) и Допуск закрыт, остальные оценки не разбирайте. Если долгов нет, выведите Допуск открыт.

Как рассуждаем

  1. Номера предметов нужны пользователю с 1, поэтому берём range(1, n + 1): переменная цикла сразу равна номеру предмета.
  2. Как только найден первый долг, остальное не интересно. Выходим из цикла командой break.
  3. Сообщение «допуск открыт» нужно только если break не сработал. Для этого есть блок else у цикла: он выполняется, если цикл дошёл до конца без прерывания.
  4. Так не нужен ни флаг, ни повторная проверка после цикла.

Проверка на других данных

Пример 1
Ввод
4
5
2
3
2
Вывод
Долг по предмету 2
Допуск закрыт
Пример 2
Ввод
0
Вывод
Допуск открыт
Блок else привязан к for, а не к if

Блок else стоит на уровне for и срабатывает при нормальном завершении цикла. Если его по ошибке сдвинуть под if, программа будет писать «допуск открыт» после каждой хорошей оценки.

Задача 3.3.16
Самая длинная серия роста
★★★повышенная




Курс валюты записан за n дней (n ≥ 1). Вводится n, затем курс по дням, целые числа. Серия роста — подряд идущие дни, в каждом из которых курс строго выше, чем в предыдущем. Выведите длину самой длинной серии, считая в ней дни, в формате Серия роста: 3 дн.. Один день тоже считается серией длины 1.

Подсказка
Храните предыдущее значение и длину текущей серии. Если рост прервался, серия начинается заново с длины 1.




§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
