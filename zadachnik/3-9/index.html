§1Разборы: как решать и оформлять

Три задачи решены полностью. В каждой границы записаны один раз в именованном срезе, а дальше используется только имя.

Разбор 1

Код детали

★☆☆базовая

Код детали на складе записан так: BT-2045-17. Первые два символа — категория, символы с четвёртого по седьмой — номер, последние два — партия. Вводится код. Выведите три строки: Категория: …, Номер: …, Партия: ….

Как рассуждаем

  1. Формат фиксированный, значит, у каждого поля свои неизменные границы. Сначала считаем индексы: категория — 0 и 1, дефис стоит под индексом 2.
  2. Номер начинается с индекса 3, это четыре символа, поэтому граница stop равна 7. Дефис под индексом 7 в срез не попадает.
  3. Партия — символы с индексом 8 и 9. Каждому полю даём имя через slice() и применяем его к строке.

Проверка на других данных

Пример 1
Ввод
KX-0007-03
Вывод
Категория: KX
Номер: 0007
Партия: 03
Пример 2
Ввод
ZZ-9999-99
Вывод
Категория: ZZ
Номер: 9999
Партия: 99
Зачем имя вместо чисел

Запись code[3:7] требует помнить, что за поле лежит между индексами. Имя number объясняет это само. Если формат изменится, правят одну строку со срезом. Места, где поле используется, остаются прежними.

Разбор 2

Ведомость платежей

★★☆средняя

Кассовая программа хранит платёж в строке фиксированной длины: символы с индексом 0–7 — дата (09.11.25), с индекса 9 по 14 — сумма в рублях, выровненная вправо пробелами, дальше после пробела — название магазина. Вводятся количество платежей и сами строки. Выведите, сколько платежей было и на какую сумму. Формат: Платежей: 3, на сумму 1750 руб.

Как рассуждаем

  1. Из трёх полей нужна только сумма. Дата и магазин в расчёте не участвуют, поэтому им срезы не нужны.
  2. Сумма занимает шесть символов: индексы 9–14, то есть slice(9, 15). Если сумма короткая, слева в поле пробелы. Функция int() спокойно относится к пробелам по краям строки.
  3. Срез создаём один раз до цикла. В цикле читаем строку, вырезаем поле, превращаем в число и прибавляем к общей сумме.

Проверка на других данных

Пример 1
Ввод
1
01.01.25  12500 Салон
Вывод
Платежей: 1, на сумму 12500 руб.
Пример 2
Ввод
0
Вывод
Платежей: 0, на сумму 0 руб.
Поле считают по индексам, а не по видимым символам

Пробелы в записи тоже занимают индексы. Если сдвинуть границу на один символ, в срез попадёт часть соседнего поля, а int() выдаст ошибку на букве. Перед написанием среза выпишите индексы нужного поля на листе.

Разбор 3

Срез выходит за границы

★★★повышенная

Табло показывает начало названия остановки: срез с позиции 0 до позиции stop. Но stop вводит диспетчер, и он может оказаться больше длины названия. Вводятся название (одной строкой) и число stop. Выведите, сколько символов вошло в срез, и до какой позиции срез реально дошёл, — в формате Взято 4, граница 4.

Как рассуждаем

  1. Срез с завышенной границей не вызывает ошибку: Python останавливается на конце строки. Значит, реальную границу надо узнать отдельно.
  2. Метод .indices(n) принимает длину и возвращает три числа: реальные start, stop, step. Распаковываем их в три переменные.
  3. Число символов в срезе проверяем через len() от самого среза. Границу берём из .indices(): она не больше длины строки.

Проверка на других данных

Пример 1
Ввод
Кино
10
Вывод
Взято 4, граница 4
Пример 2
Ввод
Парк
0
Вывод
Взято 0, граница 0
Что даёт .indices()

Метод заменяет границы среза на настоящие индексы для списка заданной длины: слишком большое число превращается в длину, отсутствующая граница — в 0 или конец списка. Эти три числа можно подставить в range().

Найдите окно из w подряд идущих дней с наибольшей суммой и выведите номер его первого дня, считая с нуля, и сумму: Окно с 2, сумма 14. Если таких окон несколько, выведите первое. Сумму окна считайте циклом по срезу slice(i, i + w).

Подсказка
Окон ровно len(temps) - w + 1. Для каждого начала i заново создавайте срез.




§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
