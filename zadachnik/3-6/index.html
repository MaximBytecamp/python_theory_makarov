§1Разборы: как решать и оформлять

Три задачи решены полностью: изменение элементов по индексу, сравнение соседних элементов и нумерованный вывод через enumerate().

Разбор 1

Снижение цен

★☆☆базовая

В магазине снижают цену на 50 рублей у всех товаров дороже 500 рублей. Вводятся пять цен, по одной в строке. Выведите список цен после снижения одной командой print().

Как рассуждаем

  1. Цены нужно изменить в самом списке. Цикл for price in prices не подойдёт: он меняет копию значения, а список остаётся прежним.
  2. Поэтому проходим позиции: range(len(prices)) даёт 0, 1, 2, 3, 4.
  3. На каждой позиции читаем значение prices[index], проверяем условие и, если оно верно, записываем новое значение в ту же ячейку.
  4. Список выводим после цикла: он уже содержит новые цены.

Проверка на других данных

Пример 1
Ввод
100
200
300
400
500
Вывод
[100, 200, 300, 400, 500]
Пример 2
Ввод
501
501
501
501
501
Вывод
[451, 451, 451, 451, 451]
Цикл по значениям список не меняет

В записи for price in prices: price = price - 50 переменной price присваивается новое число, а ячейка списка остаётся прежней. Чтобы изменить сам список, пишите в ячейку по индексу: prices[index] = ….

Разбор 2

Дни похолодания

★★☆средняя

Вводятся температуры за шесть дней подряд. День считается днём похолодания, если температура упала на 5 градусов и больше по сравнению с предыдущим днём. Для каждого такого дня выведите строку Похолодание в день 4, а в конце — Всего дней: 2. Дни нумеруются с 1.

Как рассуждаем

  1. Для сравнения с предыдущим днём нужен индекс. Пара состоит из элемента index - 1 и элемента index.
  2. У первого дня предыдущего нет, поэтому индексы начинаем с 1: range(1, len(temperatures)). Так мы не выйдем за левую границу и не получим temperatures[-1] по ошибке.
  3. Падение — это temperatures[index - 1] - temperatures[index]. Если оно не меньше 5, выводим номер дня index + 1 и увеличиваем счётчик.

Проверка на других данных

Начало диапазона зависит от того, с кем сравниваем

Если сравнивать с предыдущим элементом, индекс 0 брать нельзя: temperatures[0 - 1] — это последний элемент списка, и программа даст неверный ответ без ошибки. Если сравнивать со следующим, диапазон заканчивается на len(...) - 1.

Разбор 3

Маршрут с остановками

★★☆средняя

Вводятся названия четырёх остановок маршрута, по одному в строке. Выведите их с номерами от 1 в виде 1. Вокзал. К последней остановке добавьте в конце (конечная).

Как рассуждаем

  1. Нужны и номер, и название, поэтому используем enumerate(stops, start=1): он выдаёт пары (номер, значение), а номер начинает с единицы.
  2. Последняя остановка — та, чей номер равен длине списка: number == len(stops).
  3. Остальные остановки выводим по общему образцу, у последней добавляем пометку.

Проверка на других данных

Пример 1
Ввод
А
Б
В
Г
Вывод
1. А
2. Б
3. В
4. Г (конечная)
Нумерация с нуля и с единицы

Без start=1 счёт идёт с нуля. Человек считает с единицы, поэтому в списке для чтения номера начинают с 1. Значение start меняет только номера, индексы списка остаются прежними: нулевой элемент по-прежнему stops[0].

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
