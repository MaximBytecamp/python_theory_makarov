§1Разборы: как решать и оформлять

Три задачи решены полностью. В каждой видно, какой метод подходит к действию и что в итоге хранится в списке.

Разбор 1

Очередь в кассу

★☆☆базовая

Покупатели подходят к кассе. Вводятся имена, по одному в строке, до слова конец. Выведите список в порядке прихода и на отдельной строке — сколько людей в очереди: В очереди: 3.

Как рассуждаем

  1. Заранее не известно, сколько людей придёт, поэтому начинаем с пустого списка и растим его. Новый элемент в конец добавляет append().
  2. Ввод повторяется, пока не встретится слово-стоп. Это цикл while: первое имя читаем до цикла, следующее — в конце каждого прохода.
  3. Слово конец в список добавлять не нужно, поэтому append() стоит внутри цикла, а стоп-слово до него не доходит.

Проверка на других данных

Пример 1
Ввод
Ольга
конец
Вывод
['Ольга']
В очереди: 1
Пример 2
Ввод
конец
Вывод
[]
В очереди: 0
append() ничего не возвращает

Запись queue = queue.append(name) сохраняет в queue значение None, и следующий вызов падает с ошибкой. Метод меняет список на месте, поэтому пишут только queue.append(name).

Разбор 2

Расписание рейсов

★★☆средняя

Автовокзал составляет расписание. Вводятся количество утренних рейсов и их время отправления (по одному в строке), затем количество вечерних рейсов и их время. Потом вводится время внепланового рейса. Он должен стоять вторым в общем списке. Выведите общий список и количество рейсов в нём.

Как рассуждаем

  1. Утренние и вечерние рейсы читаем в два отдельных списка через append() внутри цикла for.
  2. Вечерние рейсы нужно присоединить сразу целым списком: для этого есть extend(). Он добавляет каждый элемент второго списка в конец первого.
  3. Внеплановый рейс идёт на конкретную позицию. «Вторым» значит индекс 1, это работа для insert(1, значение): он сдвигает остальные элементы вправо.

Пример 1
Ввод

08:00
0
11:30
Вывод
['08:00', '11:30']
Рейсов: 2
Пример 2
Ввод
3
06:00
07:00
08:00
1
20:00
13:15
Вывод
['06:00', '13:15', '07:00', '08:00', '20:00']

insert() и позиция за концом списка

Если номер позиции больше длины списка, insert() добавляет значение в конец, ошибки нет. Поэтому в задаче с пустым утренним списком внеплановый рейс всё равно окажется в списке.

Разбор 3

Пересдача оценки

★★★повышенная

В журнале хранятся оценки студента. Нужно заменить одну оценку на новую после пересдачи, но сохранить старый список для отчёта. Вводятся количество оценок, сами оценки, затем оценка, которая заменяется (она точно есть в списке), и новая оценка. Выведите две строки: Было: […] и Стало: […]. Новая оценка добавляется в конец списка.

Как рассуждаем

  1. Если написать old = grades, это будет второе имя того же списка: изменение через одно имя видно через другое. Копию делает только grades.copy().
  2. Копию делаем до изменений. После этого работаем с основным списком: remove() удаляет первое подходящее значение, append() добавляет новое в конец.
  3. В конце печатаем оба списка. Копия осталась прежней, основной список изменился.

Проверка на других данных

Пример 1
Ввод
1
2
2
5
Вывод
Было: [2]
Стало: [5]
Пример 2
Ввод
3
5
5
5
5
4
Вывод
Было: [5, 5, 5]
Стало: [5, 5, 4]
Два имени — один список

Строка before = grades не копирует данные: оба имени указывают на один и тот же список. После grades.remove(old_grade) список before тоже станет другим, и отчёт покажет уже изменённые данные. Для независимого списка нужен grades.copy().

§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
