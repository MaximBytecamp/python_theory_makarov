§1Разборы: как решать и оформлять

В трёх разборах — три основные формулировки: «каждое», «хотя бы одно» и «ровно одно». В каждом сначала записаны простые проверки, потом они соединены.

Разбор 1

Комплект документов

★☆☆базовая

Для записи на курсы нужны три документа: паспорт, СНИЛС и заявление. Вводятся три ответа да или нет — есть ли каждый документ. Выведите, полон ли комплект и не хватает ли чего-нибудь.

Как рассуждаем

  1. Формулировка «нужны все три» — это «каждое». Записывается цепочкой and.
  2. Каждый ответ сразу превращаем в логическое значение сравнением со словом "да".
  3. «Чего-то не хватает» — отрицание полного комплекта: not is_complete.

Проверка на других данных

Пример 1
Ввод
да
нет
да
Вывод
Комплект полный: False
Чего-то не хватает: True
Пример 2
Ввод
нет
нет
нет
Вывод
Комплект полный: False
Чего-то не хватает: True
Одного «нет» достаточно

Во втором примере два документа из трёх есть, но комплект неполный. Цепочка and истинна, только когда истинны все её части.

Разбор 2

Просроченный товар

★★☆средняя

У трёх товаров на полке записано, сколько дней осталось до конца срока годности. Отрицательное число означает, что срок истёк. Вводятся три числа. Выведите, есть ли на полке просроченный товар и все ли товары годны.

Как рассуждаем

  1. Простая проверка: days < 0 — товар просрочен. Таких проверок три.
  2. «Есть просроченный» — это «хотя бы одно»: соединяем через or.
  3. «Все годны» — то же, что «нет ни одного просроченного». Это отрицание предыдущего условия.

Проверка на других данных

Пример 1
Ввод
5
1
14
Вывод
Есть просроченный товар: False
Все товары годны: True
Пример 2
Ввод
-2
-1
-10
Вывод
Есть просроченный товар: True
Все товары годны: False
Две записи одного условия

«Все товары годны» можно записать напрямую: milk >= 0 and bread >= 0 and cheese >= 0. Результат совпадает с not (milk < 0 or bread < 0 or cheese < 0) при любых числах. Отрицание «хотя бы одного» всегда равно «каждое наоборот».

Сравнение нужно каждому числу

Запись milk or bread or cheese < 0 не вызовет ошибки, но проверит другое: сравнение с нулём относится только к cheese, а milk и bread считаются истиной при любом ненулевом значении.

Разбор 3

Один дежурный

★★☆средняя

На смену нужен ровно один дежурный. Два сотрудника отвечают, готовы ли они выйти: да или нет. Смена утверждается, если готов ровно один из них. Выведите, утверждена ли смена.

Как рассуждаем

  1. «Ровно один» одним оператором не записать. Перечисляем случаи, которые подходят.
  2. Случай первый: первый готов, второй нет. Случай второй: первый не готов, второй готов.
  3. Подходит любой из двух случаев — соединяем их через or, каждый случай берём в скобки.

Проверка на других данных

Пример 1
Ввод
да
да
Вывод
Смена утверждена: False
Пример 2
Ввод
нет
нет
Вывод
Смена утверждена: False
Пример 3
Ввод
нет
да
Вывод
Смена утверждена: True
Чем «ровно один» отличается от «хотя бы один»

Во втором примере готовы оба. Условие is_first_ready or is_second_ready дало бы True, а смена не утверждена: дежурных двое, нужен один.

Короткая запись для двух значений

Для двух логических значений «ровно одно истинно» означает, что они разные: is_first_ready != is_second_ready. Для трёх и более значений эта запись не подходит — там перечисляют случаи.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
