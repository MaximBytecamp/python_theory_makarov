§1Разборы: как решать и оформлять

Три задачи решены полностью: накопление с условием, перебор цифр и поиск наибольшего значения с его номером. В каждой видно, что задаётся до цикла, что делается в цикле и что выводится после.

Разбор 1

Выручка за период

★☆☆базовая

Кассир сверяет выручку магазина с планом. Вводятся количество дней, план на один день в рублях и затем выручка за каждый день. Выведите общую выручку и число дней, в которые план выполнен или перевыполнен.

Как рассуждаем

  1. Нужны два накопителя: сумма выручки и счётчик удачных дней. Оба начинаются с нуля и создаются до цикла.
  2. Цикл повторяется столько раз, сколько дней. Значения читаем прямо в цикле: хранить все дни сразу не нужно.
  3. Сумма растёт на каждой итерации. Счётчик растёт только при условии revenue >= plan.
  4. Если дней ноль, цикл не выполнится, и программа выведет нули. Это верный ответ.

Проверка на других данных

Пример 1
Ввод
3
8000
5000
6000
7000
Вывод
Выручка за период: 18000 руб.
Дней с выполненным планом: 0
Пример 2
Ввод
0
10000
Вывод
Выручка за период: 0 руб.
Дней с выполненным планом: 0
Обнуляйте накопитель до цикла

Если записать total = 0 внутри цикла, на каждой итерации сумма начинается заново. В конце останется только последнее значение. Всё, что накапливается, создают перед for.

Разбор 2

Сумма цифр номера

★★☆средняя

Номер билета состоит только из цифр. Вводится номер. Выведите сумму его цифр и количество нулей в нём.

Как рассуждаем

  1. Функция input() возвращает строку. Цикл for по строке выдаёт символы по одному, поэтому преобразовывать номер в число не нужно.
  2. Каждый символ — цифра в виде текста. Чтобы сложить, переводим её в число: int(digit).
  3. Нули считаем отдельным счётчиком. Сравниваем символ с текстом "0", а не с числом.

Проверка на других данных

Пример 1
Ввод
100200
Вывод
Сумма цифр: 3
Нулей в номере: 4
Пример 2
Ввод
0
Вывод
Сумма цифр: 0
Нулей в номере: 1
Число нельзя перебирать циклом

Если номер сразу превратить в число командой int(input()), запись for digit in ticket даст ошибку: по числу цикл не идёт. Для перебора цифр оставляйте введённое значение строкой.

Разбор 3

Самая дорогая покупка

★★☆средняя

Вводятся количество покупок (не меньше одной) и сумма каждой. Выведите самую большую сумму и номер покупки, в которой она встретилась впервые.

Как рассуждаем

  1. Наибольшее число ищут так: запоминают лучшее из уже виденных и сравнивают с ним каждое новое. Начальное «лучшее» нельзя брать наугад, поэтому им становится первая покупка.
  2. Первая покупка прочитана до цикла, её номер — 1. Цикл начинается со второй: range(2, count + 1) даёт номера 2, 3, …, count.
  3. Новое значение заменяет лучшее только при строгом сравнении >. Тогда при равных суммах останется номер первой.
  4. Вместе с суммой обновляется и номер: оба значения меняются в одном if.

Проверка на других данных

Пример 1
Ввод
1
500
Вывод
Самая дорогая покупка: 500 руб.
Номер покупки: 1
Пример 2
Ввод
3
90
150
700
Вывод
Самая дорогая покупка: 700 руб.
Номер покупки: 3
Начальное значение 0 подходит не всегда

Запись best = 0 работает для сумм, но ломается для температур или баланса: если все значения отрицательные, ноль «победит», хотя его не было в данных. Надёжнее взять за начальное значение первый элемент.

§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
