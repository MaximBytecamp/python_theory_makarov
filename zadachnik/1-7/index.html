§1Разборы: как решать и оформлять

Три задачи решены полностью. Смотрите не только на ответ, но и на оформление: исходные данные сверху, расчёт отдельными строками с понятными именами, вывод — в конце.

Разбор 1

Зачёт по баллам

★☆☆базовая

Экзамен сдан, если набрано не меньше 60 баллов, и сдан на «отлично» — если не меньше 90. Программа спрашивает баллы и выводит оба признака.

Как рассуждаем

  1. «Не меньше» — это >=: граница включается.
  2. Результат сравнения — значение True или False. Его можно сохранить в переменную с именем-вопросом.
  3. Выводим признаки через запятую — print() покажет True или False.

Проверка на других данных

Пример 1
Ввод
90
Вывод
Сдан: True
Отлично: True
Пример 2
Ввод
59
Вывод
Сдан: False
Отлично: False
Проверяйте границы

Второй и третий примеры стоят ровно на границах: 90 и 59. Ошибка > вместо >= проявляется только там — поэтому граничные значения берут в проверку всегда.

Разбор 2

Средняя оценка: где ошибка

★★☆средняя

Студент считает среднюю из трёх оценок и получает странно большое число. Покажем обе версии формулы рядом.

Как рассуждаем

  1. Деление выполняется раньше сложения: a + b + c / 3 делит на три только последнюю оценку.
  2. Скобки задают порядок явно: (a + b + c) / 3.
  3. Выводим обе версии с двумя знаками — разница видна сразу.

Проверка на других данных

Пример 1
Ввод
5
5
5
Вывод
Без скобок: 11.67
Со скобками: 5.00
Ошибка без сообщения

Программа без скобок не падает — она уверенно печатает 10.00 вместо 4.00. Такие ошибки находит только проверка на примере, ответ к которому вы знаете заранее.

Разбор 3

Вклад со сложными процентами

★★☆средняя

Вклад открыт на несколько лет, проценты каждый год прибавляются к сумме. Выведите сумму в конце срока и доход.

Как рассуждаем

  1. За год сумма умножается на 1 + ставка / 100. За несколько лет — возводится в степень числа лет: **.
  2. Степень выполняется раньше умножения, а сложение внутри скобок — первым: deposit * (1 + rate / 100) ** years.
  3. Доход — итог минус вложенное, считаем по готовым переменным.

Проверка на других данных

Пример 1
Ввод
5000
10
2
Вывод
Через 2 г.: 6050.00 руб.
Доход: 1050.00 руб.
Порядок в формуле

Скобки → ** → * / → + -. Без скобок deposit * 1 + rate / 100 ** years посчитало бы совсем другое число.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
