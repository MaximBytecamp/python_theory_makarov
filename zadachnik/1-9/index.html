§1Разборы: как решать и оформлять

Три задачи решены полностью. Смотрите не только на ответ, но и на оформление: исходные данные сверху, расчёт отдельными строками с понятными именами, вывод — в конце.

Разбор 1

Средняя оценка в электронном журнале

★☆☆базовая

Журнал показывает среднюю из трёх оценок: точное значение, округлённое до десятых число и вид с двумя знаками.

Как рассуждаем

  1. Среднее считаем один раз и не округляем — точное значение пригодится.
  2. round(average, 1) возвращает новое число — оно не меняет average.
  3. :.2f — только вид в выводе: всегда два знака, даже нули.

Проверка на других данных

Пример 1
Ввод
3
4
5
Вывод
Точно: 4.0
До десятых: 4.0
Два знака: 4.00
Число или текст

round() вернул float — с ним можно считать дальше. F-строка вернула бы текст. Во втором примере видно различие: round(4.0, 1) — это 4.0, а формат даёт 4.00.

Разбор 2

Счёт с НДС

★★☆средняя

Поставщик выставляет счёт: цена единицы без НДС и количество. Выведите сумму без налога, НДС 20% и итог — всё в рублях с копейками.

Как рассуждаем

  1. Все промежуточные суммы считаем без округления — чтобы не накапливать ошибку.
  2. НДС — 20% от суммы: subtotal * 0.2.
  3. Округляем только при выводе: формат :.2f в каждой строке.

Проверка на других данных

Пример 1
Ввод
1000
3
Вывод
Сумма без НДС: 3000.00 руб.
НДС 20%: 600.00 руб.
Итого: 3600.00 руб.
Не округляйте на каждом шаге

Если сначала округлить subtotal, потом vat, потом итог, копейки начнут расходиться с бухгалтерией. Считайте точно, показывайте аккуратно.

Разбор 3

Процент выполнения плана

★★☆средняя

Трекер задач показывает, на сколько процентов выполнен план, — целым числом.

Как рассуждаем

  1. Доля = выполнено / запланировано, в процентах — умножить на 100.
  2. Нужно целое число для дальнейшей работы — round() без второго аргумента вернёт int.
  3. Выводим тип результата, чтобы убедиться.

Проверка на других данных

Пример 1
Ввод
1
8
Вывод
План выполнен на 12%
Тип результата: <class 'int'>
Половина — к чётному

Во втором примере 1 / 8 × 100 = 12.5, а round() дал 12: значения ровно посередине Python округляет к ближайшему чётному. Об этом стоит помнить, когда результат «на половине» кажется неверным.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
