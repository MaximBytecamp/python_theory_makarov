«Truthy и Falsy»

Условию не обязательно быть сравнением: if items: проверяет, что список не пуст, а if name: — что строка не пуста. Ложными (falsy) считаются 0, пустая строка, пустой список и None; всё остальное истинно. Функция filter(None, …) убирает ложные элементы из коллекции.

§1Разборы: как решать и оформлять

Три задачи решены полностью: проверка списка, проверка строки из input() и очистка списка через filter(None, …).

Разбор 1

Пуста ли очередь

★☆☆базовая

В кабинете принимают по очереди. Вводятся количество людей в очереди и их имена, по одному в строке. Если очередь не пуста, выведите Следующий: … (первое имя) и Ждут: … (сколько человек). Если пуста — Очередь пуста.

Как рассуждаем

  1. Вопрос «есть ли кто-нибудь» — это проверка, что список не пуст. Сравнение len(queue) > 0 работает, но короче записать само имя списка: if queue:.
  2. Пустой список ложен, любой непустой истинен. Ветка if получает первое имя и длину, ветка else сообщает, что очередь пуста.
  3. Ветку с обращением к queue[0] нельзя выполнять на пустом списке, поэтому проверка стоит раньше.

Проверка на других данных

Пример 1
Ввод
1
Марина
Вывод
Следующий: Марина
Ждут: 1
Пример 2
Ввод
0
Вывод
Очередь пуста
Список с нулём внутри не пуст

Истинность списка зависит только от того, есть ли в нём элементы. Список [0] истинен, хотя единственный элемент ложен. Ложным будет только [].

Разбор 2

Промокод из пустой строки

★★☆средняя

На странице оплаты есть поле промокода. Если промокода нет, покупатель нажимает Enter, не вводя текста. Вводятся промокод и сумма заказа. Если промокод введён, выведите Промокод принят: … и уменьшите сумму на десятую часть (целая часть от деления на 10). Если нет — выведите Промокода нет. В конце выведите К оплате: ….

Как рассуждаем

  1. Пустой Enter в input() даёт пустую строку "", а она ложна. Любой введённый текст — непустая строка, а значит, истинна.
  2. Достаточно написать if promo:. Сравнение promo != "" делает то же самое, но длиннее.
  3. Скидку применяем только в ветке if. Итог выводим после условия: он нужен в обоих случаях.

Проверка на других данных

Пример 1
Ввод
1500
Вывод
Промокода нет
К оплате: 1500
Пример 2
Ввод
0
800
Вывод
Промокод принят: 0
К оплате: 720
Строка «0» истинна

Ложно число 0, но не строка "0". Всё, что вернул input() и что не пусто, — истинно, даже если там цифра 0 или слово False. Если нужна проверка числа, сначала переводят строку в число через int().

Разбор 3

Анкета с пропусками

★★☆средняя

В анкете несколько вопросов, на некоторые студенты не ответили. Вводятся количество вопросов и ответы по порядку; пропуск — пустая строка. Выведите Заполнено: … из …, а затем только заполненные ответы с номерами с единицы в виде 1. пицца.

Как рассуждаем

  1. Нужно выкинуть из списка пустые строки. Для этого есть filter(None, answers): он оставляет только истинные элементы.
  2. filter() возвращает объект filter, у него нет длины и индексов. Чтобы получить список с длиной и повторным обходом, оборачиваем его в list().
  3. Дальше нумерация через enumerate() с start=1. Номера идут по оставшимся ответам, а не по исходным вопросам.

Проверка на других данных

Пример 1
Ввод
2
Вывод
Заполнено: 0 из 2
Пример 2
Ввод
3
да
нет
да
Вывод
Заполнено: 3 из 3
1. да
2. нет
3. да
filter(None, …) убирает и нули

Функция отбрасывает все ложные значения, не только пустые строки. В списке чисел [5, 0, 7] она оставит [5, 7]. Если ноль — настоящее значение, как температура или остаток, такой фильтр потеряет данные.

§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
