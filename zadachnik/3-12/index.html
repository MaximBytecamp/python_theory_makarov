§1Разборы: как решать и оформлять

Три задачи решены полностью. В каждой видно, чем отличаются похожие действия: копия и второе имя, == и is, поверхностная и глубокая копия.

Разбор 1

Запрещённые слова

★☆☆базовая

Чат отклоняет сообщения с запрещёнными словами: спам, реклама, казино. Вводится одно слово. Выведите Запрещено, если слово есть в этом списке, и Можно, если нет.

Как рассуждаем

  1. Запрещённые слова храним в списке. Проверку «есть ли значение в списке» выполняет оператор in.
  2. Результат in — True или False. Его ставят прямо в условие if, отдельно сравнивать с True не нужно.
  3. Две ветки: запрещённое слово и все остальные.

Проверка на других данных

Пример 1
Ввод
привет
Вывод
Можно
Пример 2
Ввод
Спам
Вывод
Можно
Регистр важен

Слова Спам и спам для Python разные строки, поэтому in не найдёт слово с заглавной буквы. Приводить регистр к одному виду умеют методы строк, они появятся в модуле 5.

Разбор 2

Маршрут туда и обратно

★★☆средняя

Автобус идёт по остановкам в заданном порядке и возвращается по тому же маршруту в обратную сторону. Вводятся количество остановок и их названия. Выведите две строки: Туда: […] и Обратно: […]. Список «туда» менять нельзя.

Как рассуждаем

  1. Для обратного маршрута подходит reverse(), но он меняет список на месте. Если применить его к исходному, маршрут «туда» пропадёт.
  2. Поэтому сначала делаем независимую копию через copy(), а переворачиваем уже её.
  3. Метод reverse() возвращает None, поэтому выводим копию после вызова, а не результат метода.

Проверка на других данных

Пример 1
Ввод
1
Депо
Вывод
Туда: ['Депо']
Обратно: ['Депо']
Пример 2
Ввод
0
Вывод
Туда: []
Обратно: []
Результат reverse() — None

Строка back = route.reverse() оставит в back значение None, а исходный список окажется перевёрнутым. Метод работает на месте и ничего не возвращает.

Разбор 3

План с черновиком

★★★повышенная

План на два дня — это список из двух списков дел. Вводятся количество дел первого дня и сами дела, затем то же для второго дня. Потом вводится новое дело. Нужно сделать черновик плана и добавить новое дело в первый день черновика, не трогая основной план. Выведите План: … и Черновик: ….

Как рассуждаем

  1. План — список, внутри которого лежат два списка. Метод copy() создаст новый внешний список, но внутренние списки останутся общими с оригиналом.
  2. Значит, добавление в первый день черновика изменило бы и основной план. Чтобы скопировать все уровни, берём copy.deepcopy() и подключаем модуль строкой import copy.
  3. После глубокой копии добавляем дело в draft[0]. Основной план остаётся прежним.

Проверка на других данных

Пример 1
Ввод
0
1
выходной
позвонить
Вывод
План: [[], ['выходной']]
Черновик: [['позвонить'], ['выходной']]
Пример 2
Ввод
1
сон
0
бег
Вывод
План: [['сон'], []]
Черновик: [['сон', 'бег'], []]
Поверхностная копия не спасает

При draft = plan.copy() список draft[0] и plan[0] — один и тот же объект. Это легко проверить: draft[0] is plan[0] даст True. После глубокой копии та же проверка даёт False.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
