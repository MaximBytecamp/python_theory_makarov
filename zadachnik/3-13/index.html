§1Разборы: как решать и оформлять

Три задачи решены полностью. В каждой видно, как таблица создаётся, как к ней обращаются и где легко перепутать строку со столбцом.

Разбор 1

Оценки студента

★☆☆базовая

В журнале три студента, у каждого три оценки за контрольные: [[5, 4, 5], [3, 4, 4], [5, 5, 5]]. Вводится номер студента (1–3). Выведите его оценки списком и сумму баллов: Сумма: 14.

Как рассуждаем

  1. Каждая строка таблицы — один студент. Строку с номером n достаём индексом journal[n - 1]: индексы начинаются с нуля, а студентов нумеруют с единицы.
  2. Сумму оценок строки считаем одним циклом по этой строке. Вложенный цикл здесь не нужен: строка таблицы — это список чисел.

Проверка на других данных

Пример 1
Ввод
2
Вывод
[3, 4, 4]
Сумма: 11
Пример 2
Ввод
3
Вывод
[5, 5, 5]
Сумма: 15
Первый индекс — строка

В записи journal[0][2] первое число выбирает строку (первого студента), второе — столбец (третью контрольную). Если поменять индексы местами, получится ячейка другого студента или ошибка выхода за границы.

Разбор 2

Продажи по магазинам и дням

★★☆средняя

Вводятся количество магазинов (строки), количество дней (столбцы) и затем выручка: магазин за магазином, внутри магазина день за днём. Выведите выручку каждого магазина за весь период (Магазин 1: …) и общую выручку за каждый день (День 1: …).

Как рассуждаем

  1. Сначала читаем таблицу. Для каждой строки заводим свой новый список row, наполняем его append() и только потом добавляем в таблицу. Так строки получаются независимыми.
  2. Сумма по магазину — это сумма строки: внешний цикл по строкам, внутренний по её ячейкам, перед каждой строкой счётчик сбрасывается в ноль.
  3. Сумма по дню — это сумма столбца. Тут внешний цикл идёт по номерам столбцов, а внутренний — по строкам, и берётся table[i][j].

День 2: 8

Магазин 2: 6
Магазин 3: 9

Счётчик сбрасывают для каждой строки

Если поставить total = 0 один раз до внешнего цикла, суммы строк будут накапливаться: у второго магазина окажется сумма двух магазинов. Начальное значение задают перед внутренним циклом.

Разбор 3

Игровое поле

★★★повышенная

Игровое поле — квадрат из клеток. Вводятся размер поля n, количество ходов и сами ходы: номер строки и номер столбца (с единицы), по одному числу в строке. Пустая клетка обозначается точкой, занятая — буквой X. Выведите поле: каждая строка поля — одна строка текста, символы без пробелов.

Как рассуждаем

  1. Поле создаём построчно: для каждой строки новый список из n точек. Запись [["."] * n] * n дала бы одну строку, повторённую n раз, и ход в одной клетке появился бы во всех строках.
  2. Ход приходит как две пары чисел с единицы, а индексы идут с нуля, поэтому вычитаем единицу из каждого.
  3. Для вывода обходим строки, а внутри строки печатаем клетки с end="", чтобы они стояли подряд. После строки пустой print() переводит вывод на следующую.

Проверка на других данных

Пример 1

0
Вывод
..
..
Пример 2
Ввод

4
1
1
1
2
2
1
2
2

XX
XX
Почему не [["."] * n] * n

Внешнее умножение копирует ссылки: все n строк оказываются одним и тем же списком. Присваивание field[0][0] = "X" тогда меняет первую клетку в каждой строке. Построчное создание в цикле даёт независимые строки.

Подсказка
Первая строка новой таблицы — это первый столбец старой, прочитанный снизу вверх.




§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
