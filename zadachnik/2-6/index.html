§1Разборы: как решать и оформлять

Три задачи решены полностью. В каждой тернарный оператор выбирает значение, а действие с этим значением — расчёт или вывод — записано отдельной строкой.

Разбор 1

Статус заказа

★☆☆базовая

В списке заказов рядом с номером показан статус. Вводятся номер заказа и ответ, оплачен ли он: да или нет. Выведите строку вида Заказ 1054: оплачен или Заказ 1054: ожидает оплаты.

Как рассуждаем

  1. От условия зависит одно значение — текст статуса. Вариантов ровно два. Это случай для тернарного оператора.
  2. Порядок частей: сначала значение для истинного условия, потом if и условие, потом else и второе значение.
  3. Вывод один для обоих случаев: в f-строку подставляется уже выбранный статус.

Проверка на других данных

Пример 1
Ввод
1055
нет
Вывод
Заказ 1055: ожидает оплаты
Та же программа через if / else

Без тернарного оператора выбор занял бы четыре строки: if is_paid:, присваивание, else:, второе присваивание. Результат одинаковый. Короткая запись удобнее, когда обе ветки только присваивают значение одной и той же переменной.

Разбор 2

Доставка и итог

★★☆средняя

Доставка стоит 300 рублей, а при заказе от 3000 рублей она бесплатная. Вводится сумма заказа. Выведите стоимость доставки — числом с рублями или словом бесплатно — и итог к оплате.

Как рассуждаем

  1. Стоимость доставки — одно из двух чисел: 0 или 300. Выбираем тернарным оператором.
  2. Итог считаем обычной формулой: выбранное число уже лежит в переменной.
  3. Подпись для вывода тоже одна из двух. Обе ветки дают строку, поэтому число в подпись вставляем через f-строку.

Проверка на других данных

Пример 1
Ввод
1200
Вывод
Доставка: 300 руб.
К оплате: 1500 руб.
Пример 2
Ввод
3000
Вывод
Доставка: бесплатно
К оплате: 3000 руб.
В обеих ветках — значения одного типа

Запись "бесплатно" if delivery == 0 else delivery положила бы в переменную то строку, то число. Программа с такой переменной ломается в неожиданных местах: строку нельзя сложить с числом. Поэтому вторая ветка тоже строка.

Разбор 3

Изменение цены

★★☆средняя

Сервис сравнения цен показывает, как изменилась цена товара. Вводятся вчерашняя и сегодняшняя цена. Выведите разницу со знаком: +150, -80 или 0. Второй строкой выведите вывод словами: Цена выросла, Цена снизилась или Цена не изменилась.

Как рассуждаем

  1. Минус у отрицательного числа выводится сам, а плюс у положительного — нет. Знак перед числом — одно из двух значений: "+" или пустая строка.
  2. Словесных выводов три. Тернарный оператор выбирает из двух значений, поэтому здесь нужна цепочка if / elif / else.
  3. В одной программе используем обе записи — каждую там, где она подходит.

Проверка на других данных

Пример 1
Ввод
1200
1120
Вывод
Изменение: -80 руб.
Цена снизилась
Пример 2
Ввод
1200
1200
Вывод
Изменение: 0 руб.
Цена не изменилась
Почему не два тернарных оператора подряд

Три варианта можно уместить в одну строку, вложив один тернарный оператор в другой. Такая строка работает, но порядок выбора в ней трудно проследить. Для трёх и более вариантов пишут if / elif / else.

§3Как проверить своё решение

  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.
Оформление, которое проверяют

Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
