«Срезы»

Срез items[start:stop:step] берёт часть списка или строки одним выражением: первые элементы, последние, каждый второй, всё в обратном порядке. Срезу можно присвоить новое значение, чтобы заменить часть списка, а через del — удалить.

§1Разборы: как решать и оформлять

Три задачи решены полностью: чтение частей списка, замена и удаление через срез, копия списка перед изменением.

Разбор 1

Недельный отчёт

★☆☆базовая

Вводятся продажи за семь дней недели. Выведите списками три группы: первые три дня, последние три дня и каждый второй день, начиная с первого.

Как рассуждаем

  1. Первые три элемента — это позиции 0, 1, 2. Срез sales[:3]: начало пропущено (значит, с самого начала), конец 3 не входит.
  2. Последние три берём отрицательным началом: sales[-3:]. Конец пропущен — до конца списка.
  3. Каждый второй, начиная с первого, — это шаг 2 на всём списке: sales[::2].
  4. Каждый срез — новый список. Исходный остаётся прежним.

Проверка на других данных

Пример 1
Ввод
5
5
5
5
5
5
5
Вывод
Первые три дня: [5, 5, 5]
Последние три дня: [5, 5, 5]
Каждый второй день: [5, 5, 5, 5]
Конец среза не входит

Срез sales[0:2] содержит два элемента — с индексами 0 и 1. Чтобы взять три, нужно sales[0:3] или sales[:3]. Число элементов в срезе без шага равно stop - start: так проверяют срез в уме.

Разбор 2

Очередь заказов

★★☆средняя

В очереди шесть номеров заказов. Первые два уже выданы. На освободившиеся места в конце очереди добавили два новых заказа. Вводятся шесть номеров очереди, затем два новых номера. Удалите выданные заказы, замените два последних элемента новыми и выведите получившийся список.

Как рассуждаем

  1. Выданные заказы — первые два элемента, срез [:2]. Удаляем его командой del orders[:2]. Список теперь короче на два элемента.
  2. Заменить последние два элемента можно присваиванием среза: orders[-2:] = [новый, новый]. Справа записан список из двух значений.
  3. Порядок важен: срез [-2:] считается от конца текущего списка, а после удаления в нём четыре элемента.
  4. Новые номера читаем прямо в правой части присваивания, в том порядке, в каком они вводятся.

Проверка на других данных

Пример 1
Ввод
1
2
3
4
5
6
6
6
Вывод
[3, 4, 6, 6]
Срез слева от = меняет список

Запись orders[-2:] = … не создаёт новый список, а подменяет часть старого. Справа должен стоять список, а не одно число: число вместо списка вызовет ошибку. Новая часть может быть любой длины, и список подстроится.

Разбор 3

Цены до и после наценки

★★☆средняя

Вводятся пять цен. Магазин делает наценку 20 рублей на каждый товар, но прежний прайс нужно сохранить. Выведите список цен после наценки, затем старый список и затем старый список в обратном порядке.

Как рассуждаем

  1. Простое присваивание old_prices = prices не создаёт копию: обе переменные ссылаются на один и тот же список, и изменение через одну будет видно через другую.
  2. Копию делает полный срез: prices[:]. Это новый список с теми же значениями.
  3. Наценку добавляем в основном списке по индексам, а копию не трогаем.
  4. Обратный порядок старого списка — срез с шагом −1: old_prices[::-1].

Проверка на других данных

Пример 1
Ввод
0
0
0
0
0
Вывод
Новый прайс: [20, 20, 20, 20, 20]
Старый прайс: [0, 0, 0, 0, 0]
Старый прайс с конца: [0, 0, 0, 0, 0]
Присваивание не копирует список

Если вместо prices[:] написать old_prices = prices, то после наценки в обоих списках окажутся новые цены, потому что список всего один. Срез создаёт новый объект.

§3Как проверить своё решение


  1. Запустите программу и введите значения из колонки «Ввод» — каждое значение отдельной строкой, после каждого Enter.
  2. Сравните то, что напечатала программа, с колонкой «Вывод» — символ в символ: пробелы, двоеточия, количество знаков после точки.
  3. Подсказки input() в примерах не показаны: текст подсказки у каждого свой, проверяется только результат.
  4. Прогоните все примеры, а не только первый: второй обычно ловит ошибку, которую первый пропускает.


Оформление, которое проверяют
Имена переменных называют смысл: total_cost, а не x. Данные — вверху, расчёт — отдельными строками, вывод — в конце. Одно и то же выражение не повторяется: результат сохраняется в переменную и дальше используется по имени.
