Вложенные условия — это конструкции, в которых **один оператор `if` находится внутри другого оператора `if`**.

Такая конструкция используется, когда необходимо **проверить несколько условий последовательно**.

Иными словами, второе условие проверяется **только если первое условие оказалось истинным**.

---

# Общий синтаксис

```Python
if условие1:
    if условие2:
        блок_кода
```

Здесь:

- сначала проверяется `условие1`

- если оно **True**, тогда проверяется `условие2`

- если оба условия истинны — выполняется блок кода

---

# Пример

Предположим, программа проверяет возможность входа на сайт.

```Python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Вход разрешен")
```

Результат:

```Python
Вход разрешен
```

Разберем выполнение программы:

1. Проверяется условие `age >= 18`

2. Если условие истинно, программа переходит к следующему `if`

3. Проверяется `has_ticket`

4. Если оба условия истинны — выполняется `print()`

---

# Пример, когда второе условие не выполняется

```Python
age = 20
has_ticket = False

if age >= 18:
    if has_ticket:
        print("Вход разрешен")
```

Результат:

```Python
(ничего не выводится)
```

Потому что второе условие оказалось **ложным**.

---

# Использование `else` во вложенных условиях

Во вложенных условиях также можно использовать `else`.

Пример:

```Python
age = 17

if age >= 18:
    print("Вы совершеннолетний")
else:
    print("Вы несовершеннолетний")
```

---

# Более сложный пример

```Python
age = 20
has_ticket = False

if age >= 18:
    if has_ticket:
        print("Вход разрешен")
    else:
        print("Нет билета")
else:
    print("Вход запрещен по возрасту")
```

Результат:

```Python
Нет билета
```

---

# Почему используются вложенные условия

Вложенные условия позволяют:

```Python
проверять несколько зависимых условий
строить более сложную логику программы
управлять последовательностью проверок
```

---

# Итог

Вложенные условия — это конструкция, в которой один оператор `if` находится внутри другого.

Пример:

```Python
if условие1:
    if условие2:
        действие
```

Главная идея:

```Python
второе условие проверяется только после выполнения первого
```
