Тернарный оператор в Python позволяет **записать условие `if-else` в одной строке**.

Он используется, когда необходимо **присвоить значение переменной в зависимости от условия**, но без написания полноценной конструкции `if / else`.

---

# Общий синтаксис

```Python
значение_если_True if условие else значение_если_False
```

Сначала записывается значение, которое будет возвращено **если условие истинно**, затем пишется `if`, потом **условие**, и после `else` — значение, которое будет возвращено **если условие ложно**.

---

# Простой пример

Обычная конструкция:

```Python
x = 10

if x > 5:
    result = "Больше"
else:
    result = "Меньше или равно"
```

То же самое с использованием тернарного оператора:

```Python
x = 10
result = "Больше" if x > 5 else "Меньше или равно"
```

---

# Пример вывода

```Python
age = 20

message = "Совершеннолетний" if age >= 18 else "Несовершеннолетний"

print(message)
```

Результат:

```Python
Совершеннолетний
```

---

# Пример с числами

```Python
num = 7

result = "Четное" if num % 2 == 0 else "Нечетное"

print(result)
```

Результат:

```Python
Нечетное
```

---

# Когда используется тернарный оператор

Тернарный оператор удобно применять:

```Python
• для коротких условий
• для присвоения значения переменной
• для упрощения кода
```

---

# Когда лучше использовать обычный `if`

Если условие **сложное или содержит много действий**, лучше использовать обычную конструкцию `if`.

Пример:

```Python
if score >= 90:
    grade = "A"
else:
    grade = "B"
```

В некоторых случаях такой код **читается легче**, чем длинная строка с тернарным оператором.

---

# Итог

Тернарный оператор — это **сокращенная форма `if-else`**.

Синтаксис:

```Python
значение_если_True if условие else значение_если_False
```

Он позволяет **писать компактный и удобный код**, особенно для простых условий.
