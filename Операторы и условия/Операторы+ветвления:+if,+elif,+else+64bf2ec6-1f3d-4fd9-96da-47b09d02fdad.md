Операторы ветвления используются в программировании для **принятия решений на основе условий**.
Они позволяют программе выполнять **разные действия в зависимости от результата проверки условия**.

---

# Пример из жизни

Представим ситуацию:

Вы утром просыпаетесь и решаете, идти ли на улицу.

Ваше решение зависит от условия:

```Python
идет дождь или нет
```

Если дождь идет → вы остаётесь дома.
Если дождя нет → вы идёте на улицу.

В программировании оператор ветвления работает **по такому же принципу**: программа выбирает одно из направлений выполнения.

---

# Основные операторы ветвления

В Python используются три основных оператора:

```Python
if
elif
else
```

---

# 1. Оператор `if`

Оператор `if` позволяет выполнить блок кода **только в том случае, если условие истинно (`True`)**.

### Синтаксис

```Python
if условие:
    блок_кода
```

Важно помнить:

- после условия ставится **двоеточие `:`**

- блок кода должен иметь **отступ**

---

### Пример

```Python
num = 10

if num > 5:
    print("Число больше 5")
```

Результат:

```Python
Число больше 5
```

Если изменить значение:

```Python
num = 3
```

тогда условие станет ложным, и программа **ничего не выведет**.

---

# 2. Оператор `else`

Оператор `else` используется вместе с `if` и выполняется **если условие `if` оказалось ложным (`False`)**.

### Синтаксис

```Python
if условие:
    блок_кода_1
else:
    блок_кода_2
```

---

### Пример

```Python
x = 10

if x > 5:
    print("Число больше 5")
else:
    print("Число меньше или равно 5")
```

Результат:

```Python
Число больше 5
```

Если изменить значение:

```Python
x = 5
```

Результат:

```Python
Число меньше или равно 5
```

---

### Важная особенность

`else` выполняется **только тогда**, когда **все предыдущие условия ложны**.

Если хотя бы одно условие оказалось `True`, блок `else` выполняться **не будет**.

---

# 3. Оператор `elif`

`elif` означает **else if** — «иначе если».

Он используется для **проверки дополнительных условий**, если условие `if` оказалось ложным.

---

### Синтаксис

```Python
if условие1:
    блок1
elif условие2:
    блок2
elif условие3:
    блок3
else:
    блок4
```

---

### Пример

```Python
grade = 85

if grade >= 90:
    print("Отлично")
elif grade >= 80:
    print("Хорошо")
elif grade >= 70:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

Результат:

```Python
Хорошо
```

---

# Важная особенность `elif`

Python проверяет условия **по порядку сверху вниз**.

Как только найдено **первое истинное условие**, остальные **уже не проверяются**.

---

### Пример

```Python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
```

Результат:

```Python
B
```

Хотя число `85` подходит и для `>=70`, Python **не проверяет дальше**, потому что условие `>=80` уже выполнено.

---

# Итог

Основные операторы ветвления:

```Python
if   — проверяет условие
elif — проверяет дополнительные условия
else — выполняется, если все условия ложны
```

Программа выполняет **только один блок кода из всей конструкции**.
