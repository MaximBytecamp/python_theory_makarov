В языке программирования Python операторы используются для выполнения различных действий над данными.

Операторы позволяют:

- выполнять математические вычисления

- сравнивать значения

- выполнять логические операции

- работать с битами

- проверять принадлежность объектов

- присваивать значения переменным

Операторы в Python можно разделить на несколько категорий.

---

# 1. Арифметические операторы

Арифметические операторы используются для выполнения математических операций над числами.

|Оператор|Описание|
|-|-|
|`+`|сложение|
|`-`|вычитание|
|`*`|умножение|
|`/`|деление|
|`//`|целочисленное деление|
|`%`|остаток от деления|
|`**`|возведение в степень|

---

## Примеры арифметических операций

```Python
a = 10
b = 3

print(a + b)   # сложение
print(a - b)   # вычитание
print(a * b)   # умножение
print(a / b)   # деление
print(a // b)  # целочисленное деление
print(a % b)   # остаток
print(a ** b)  # степень
```

Результат:

```Python
13
7
30
3.333...
3
1
1000
```

---

# 2. Операторы сравнения

Операторы сравнения используются для проверки отношений между значениями.

Результатом таких операций является значение **True** или **False**.

|Оператор|Описание|
|-|-|
|`==`|равно|
|`!=`|не равно|
|`>`|больше|
|`<`|меньше|
|`>=`|больше или равно|
|`<=`|меньше или равно|

---

## Пример сравнения

```Python
a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)
```

---

# 3. Логические операторы

Логические операторы используются для объединения логических выражений.

|Оператор|Описание|
|-|-|
|`and`|логическое И|
|`or`|логическое ИЛИ|
|`not`|логическое НЕ|

---

## Пример логических операций

```Python
x = 10

print(x > 5 and x < 20)
print(x > 5 or x < 5)
print(not(x > 5))
```

---

# 4. Побитовые операторы

Побитовые операторы выполняют операции **на уровне отдельных битов числа**.

|Оператор|Описание|
|-|-|
|`&`|побитовое И|
|`|`|побитовое ИЛИ|
|`^`|исключающее ИЛИ|
|`~`|побитовое НЕ|
|`<<`|сдвиг влево|
|`>>`|сдвиг вправо|

---

## Пример побитовых операций

```Python
a = 5   # 0101
b = 3   # 0011

print(a & b)
print(a | b)
print(a ^ b)
print(a << 1)
print(a >> 1)
```

---

# 5. Операторы присваивания

Операторы присваивания используются для сохранения значений в переменных.

|Оператор|Описание|
|-|-|
|`=`|простое присваивание|
|`+=`|сложение и присваивание|
|`-=`|вычитание и присваивание|
|`*=`|умножение и присваивание|
|`/=`|деление и присваивание|
|`//=`|целочисленное деление и присваивание|
|`%=`|остаток и присваивание|
|`**=`|степень и присваивание|

---

## Пример

```Python
x = 10

x += 5
print(x)

x *= 2
print(x)

x -= 3
print(x)
```

---

# 6. Операторы идентификации

Операторы идентификации проверяют, **ссылаются ли две переменные на один и тот же объект**.

|Оператор|Описание|
|-|-|
|`is`|объекты идентичны|
|`is not`|объекты не идентичны|

---

## Пример

```Python
a = [1, 2, 3]
b = a

print(a is b)
print(a is not b)
```

---

# 7. Операторы принадлежности

Эти операторы проверяют, содержится ли элемент в контейнере.

Контейнеры могут быть:

- строки

- списки

- множества

- словари

|Оператор|Описание|
|-|-|
|`in`|элемент содержится|
|`not in`|элемент отсутствует|

---

## Пример

```Python
numbers = [1, 2, 3, 4]

print(3 in numbers)
print(10 not in numbers)
```

---

# 8. Унарные операторы

Унарные операторы применяются к **одному операнду**.

|Оператор|Описание|
|-|-|
|`+`|унарный плюс|
|`-`|изменение знака|

---

## Пример

```Python
a = 10

print(+a)
print(-a)
```

---

# 9. Тернарный оператор

Тернарный оператор позволяет выполнить **условное выражение в одной строке**.

Формат:

```Python
значение_если_true if условие else значение_если_false
```

---

## Пример

```Python
age = 18

result = "Совершеннолетний" if age >= 18 else "Несовершеннолетний"

print(result)
```
