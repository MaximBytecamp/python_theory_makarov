В Python существуют разные способы **округления и отображения чисел с плавающей точкой**.
Наиболее часто используются:

```Python
round()
форматирование .2f
```

---

# Функция `round()`

Функция `round()` используется для **округления числа** до заданного количества знаков после запятой.

Общий синтаксис:

```Python
round(число, количество_знаков)
```

- первый аргумент — число, которое нужно округлить

- второй аргумент — количество знаков после запятой

---

## Пример

```Python
number = 3.14159

print(round(number, 2))
```

Результат:

```Python
3.14
```

Число округляется **до двух знаков после запятой**.

---

## Ещё пример

```Python
print(round(5.6789, 3))
```

Результат:

```Python
5.679
```

---

# Важная особенность

Если второй аргумент не указывать, число округляется **до целого**.

```Python
print(round(3.6))
```

Результат:

```Python
4
```

---

# Форматирование `.2f`

Иногда число не нужно изменять, а нужно **просто красиво вывести его**.
Для этого используется **форматирование строк**.

Запись `.2f` означает:

```Python
2 — количество знаков после запятой
f — формат числа с плавающей точкой (float)
```

---

## Пример

```Python
number = 3.14159

print(f"{number:.2f}")
```

Результат:

```Python
3.14
```

---

# Ещё пример

```Python
price = 12.5

print(f"{price:.2f}")
```

Результат:

```Python
12.50
```

Обратите внимание, что `.2f` **добавляет нули**, если знаков после запятой меньше.

---

# Разница между `round()` и `.2f`

`round()` — **округляет число**

```Python
round(3.14159, 2) → 3.14
```

`.2f` — **форматирует вывод**

```Python
f"{3.14159:.2f}" → "3.14"
```

Главное отличие:

```Python
round() изменяет значение числа
.2f изменяет только способ вывода
```

---

# Итог

Основные способы работы с дробными числами:

```Python
round(x, n)  — округляет число до n знаков
.2f          — выводит число с фиксированным количеством знаков
```

Они часто используются при работе с:

- денежными значениями

- результатами вычислений

- научными расчетами.
