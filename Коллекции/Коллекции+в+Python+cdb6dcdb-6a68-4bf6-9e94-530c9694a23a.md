**Коллекция** в Python — это общее понятие, которое объединяет структуры данных, предназначенные для **хранения группы элементов**.

Коллекции позволяют:

```Shell
хранить несколько значений
организовывать данные
выполнять операции над группами элементов
```

К основным коллекциям Python относятся:

```Python
list  — список
tuple — кортеж
set   — множество
dict  — словарь
```

Также существуют дополнительные структуры данных:

```Python
deque
namedtuple
```

Каждая коллекция имеет свои особенности и методы, которые позволяют выполнять различные операции:

```Shell
добавление элементов
удаление элементов
изменение элементов
поиск элементов
перебор элементов
```

---

# СПИСОК (LIST)

**Список** — это упорядоченная коллекция элементов.

Каждый элемент списка имеет **индекс**.

Индексация начинается с **0**.

---

# Пример списка

```Python
numbers = [10, 20, 30, 40]
```

Индексы элементов:

```Shell
0 → 10
1 → 20
2 → 30
3 → 40
```

Получение элемента:

```Python
print(numbers[0])
```

Результат:

```Shell
10
```

---

# Основная особенность списков

Списки являются **изменяемыми (mutable)**.

Это означает, что после создания списка можно:

```Shell
изменять элементы
добавлять элементы
удалять элементы
```

Пример изменения элемента:

```Python
numbers = [10, 20, 30]

numbers[1] = 50

print(numbers)
```

Результат:

```Python
[10, 50, 30]
```

---

# УПОРЯДОЧЕННЫЕ ПОСЛЕДОВАТЕЛЬНОСТИ

Упорядоченная последовательность — это коллекция, в которой **порядок элементов имеет значение**.

Такие структуры данных имеют **индексы**.

Примеры:

```Python
list   — список
str    — строка
tuple  — кортеж
```

---

# НЕУПОРЯДОЧЕННЫЕ КОЛЛЕКЦИИ

Неупорядоченные коллекции — это структуры данных, в которых **порядок элементов не имеет значения**.

Примеры:

```Python
set  — множество
dict — словарь
```

В таких коллекциях элементы не имеют обычных индексов.

---

# ИЗМЕНЯЕМЫЕ И НЕИЗМЕНЯЕМЫЕ КОЛЛЕКЦИИ

## Изменяемые (mutable)

Их содержимое можно изменять после создания.

```Python
list
dict
set
deque
```

---

## Неизменяемые (immutable)

После создания изменить их нельзя.

```Python
tuple
str
frozenset
```

---

# СПИСКИ МОГУТ ХРАНИТЬ РАЗНЫЕ ТИПЫ ДАННЫХ

Одна из сильных сторон Python — список может хранить **разные типы данных одновременно**.

---

# Пример смешанных типов

```Python
data = [10, "Python", True, 3.14]

print(data)
```

Результат:

```Python
[10, 'Python', True, 3.14]
```

---

# Вложенные структуры

Списки могут содержать **другие коллекции**.

---

## Пример №1 — список внутри списка

```Python
matrix = [
    [1, 2],
    [3, 4]
]

print(matrix)
```

---

## Пример №2 — разные коллекции

```Python
data = [
    [1, 2, 3],
    (4, 5),
    {6, 7},
    {"a": 1, "b": 2}
]

print(data)
```

---

## Пример №3 — сложная структура

```Python
items = [
    10,
    "Python",
    [1, 2, 3],
    {"name": "Alex"}
]

print(items)
```

---

# Итог

Коллекции в Python используются для **хранения и обработки групп данных**.

Основные типы коллекций:

```Python
list   — изменяемая упорядоченная коллекция
tuple  — неизменяемая упорядоченная коллекция
set    — неупорядоченная коллекция без дубликатов
dict   — коллекция пар ключ-значение
```

Списки являются одной из самых **гибких и часто используемых структур данных** в Python.
