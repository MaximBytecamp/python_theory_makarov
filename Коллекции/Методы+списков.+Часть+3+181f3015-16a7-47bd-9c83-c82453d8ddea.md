# 1. `reverse()`

Метод `reverse()` **разворачивает список в обратном порядке**.

---

## Пример

```Python
numbers = [1, 2, 3, 4]
numbers.reverse()

print(numbers)
```

Результат:

```Python
[4, 3, 2, 1]
```

---

## Особенности `reverse()`

### 1. Работает на месте (in-place)

Метод `reverse()` **изменяет сам список**, а не создаёт новый.

```Python
numbers = [10, 20, 30]
numbers.reverse()

print(numbers)
```

Результат:

```Python
[30, 20, 10]
```

---

### 2. Не возвращает новый список

```Python
numbers = [1, 2, 3]
result = numbers.reverse()

print(numbers)
print(result)
```

Результат:

```Python
[3, 2, 1]
None
```

Это важно помнить:

```Python
все методы, работающие на месте, обычно возвращают None
```

---

### 3. Если нужен новый список

Если нужно получить **новый перевёрнутый список**, не изменяя старый, можно использовать срез:

```Python
numbers = [1, 2, 3, 4]
new_numbers = numbers[::-1]

print(numbers)
print(new_numbers)
```

Результат:

```Python
[1, 2, 3, 4]
[4, 3, 2, 1]
```

---

### 4. Работает с любыми типами элементов

```Python
data = [1, "Python", [10, 20], True]
data.reverse()

print(data)
```

Результат:

```Python
[True, [10, 20], 'Python', 1]
```

---

### 5. Комбинация с сортировкой

```Python
numbers = [5, 2, 8, 1]
numbers.sort()
numbers.reverse()

print(numbers)
```

Результат:

```Python
[8, 5, 2, 1]
```

То же самое можно сделать короче:

```Python
numbers = [5, 2, 8, 1]
numbers.sort(reverse=True)

print(numbers)
```

# 2. `copy()`

Метод `copy()` **создаёт поверхностную копию списка**.

---

## Пример

```Python
numbers = [1, 2, 3]
copy_numbers = numbers.copy()

print(copy_numbers)
```

Результат:

```Python
[1, 2, 3]
```

---

## Что такое поверхностная копия

Поверхностная копия (**shallow copy**) означает:

- копируется **сам список**

- но вложенные объекты **не копируются**

- вместо этого сохраняются **ссылки на те же объекты**

---

## Пример с обычным списком

```Python
a = [1, 2, 3]
b = a.copy()

b[0] = 100

print(a)
print(b)
```

Результат:

```Python
[1, 2, 3]
[100, 2, 3]
```

Здесь всё хорошо: списки независимы.

---

## Пример с вложенными списками

```Python
a = [[1, 2], [3, 4]]
b = a.copy()

b[0][0] = 100

print(a)
print(b)
```

Результат:

```Python
[[100, 2], [3, 4]]
[[100, 2], [3, 4]]
```

Почему так произошло?

Потому что `copy()` создал новый внешний список,
но внутренние списки остались теми же самыми объектами.

---

## Аналог через срез

Поверхностную копию также можно сделать так:

```Python
a = [1, 2, 3]
b = a[:]

print(b)
```

---

## Разница с `deepcopy()`

Если нужна **полностью независимая копия**, включая вложенные объекты, используется `deepcopy()` из модуля `copy`.

```Python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

b[0][0] = 100

print(a)
print(b)
```

Результат:

```Python
[[1, 2], [3, 4]]
[[100, 2], [3, 4]]
```

# 3. `len()`

Функция `len()` возвращает **количество элементов в списке**.

---

## Пример

```Python
numbers = [10, 20, 30]
print(len(numbers))
```

Результат:

```Python
3
```

---

## Пустой список

```Python
numbers = []
print(len(numbers))
```

Результат:

```Python
0
```

---

## Полезно в циклах

```Python
numbers = [10, 20, 30]

for i in range(len(numbers)):
    print(i, numbers[i])
```

Результат:

```Python
0 10
1 20
2 30
```

---

## Работает не только со списками

`len()` можно применять к:

- строкам

- кортежам

- словарям

- множествам

```Python
print(len("Python"))       # 6
print(len((1, 2, 3)))      # 3
print(len({1, 2, 3, 4}))   # 4
```

# 4. `del`

Оператор `del` используется для **удаления элемента по индексу, среза или самой переменной**.

---

## Удаление элемента по индексу

```Python
numbers = [10, 20, 30]
del numbers[1]

print(numbers)
```

Результат:

```Python
[10, 30]
```

---

## Удаление среза

```Python
numbers = [1, 2, 3, 4, 5]
del numbers[1:4]

print(numbers)
```

Результат:

```Python
[1, 5]
```

---

## Удаление переменной

```Python
numbers = [1, 2, 3]
del numbers
```

После этого переменная `numbers` больше не существует.

---

## Важная особенность

`del` удаляет **не сам объект**, а **ссылку (переменную)**.

Если на объект есть другие ссылки, он останется в памяти.

```Python
a = [1, 2, 3]
b = a

del a

print(b)
```

Результат:

```Python
[1, 2, 3]
```

Список остался, потому что на него всё ещё ссылается `b`.

---

## Если ссылка была единственной

```Python
a = [1, 2, 3]
del a
```

Теперь объект становится недоступным, и память позже освободит сборщик мусора.

---

## `del` и неизменяемые объекты

`del` можно использовать для удаления **переменной**, указывающей на строку или кортеж,
но нельзя удалять отдельные элементы строк и кортежей, потому что они неизменяемые.

# 5. `in`

Оператор `in` используется для **проверки наличия элемента в списке**.

---

## Пример

```Python
numbers = [10, 20, 30]

print(20 in numbers)
print(50 in numbers)
```

Результат:

```Python
True
False
```

---

## Проверка отсутствия

```Python
numbers = [1, 2, 3]

print(5 not in numbers)
```

Результат:

```Python
True
```

---

## Работает с разными типами данных

```Python
data = [1, "Python", [10, 20]]

print("Python" in data)
print([10, 20] in data)
```

Результат:

```Python
True
True
```

---

## В строках

Для строк `in` проверяет наличие **подстроки**.

```Python
text = "Python"

print("th" in text)
print("java" in text)
```

Результат:

```Python
True
False
```

---

## Проверка подсписков

```Python
data = [1, 2, 3, 4, 5]

print([2, 3] in data)
```

Результат:

```Python
False
```

Потому что `[2, 3]` не является отдельным элементом списка.

Но если подсписок — это отдельный элемент:

```Python
data = [1, [2, 3], 4]

print([2, 3] in data)
```

Результат:

```Python
True
```

---

## Часто используется в условиях

```Python
numbers = [10, 20, 30]

if 20 in numbers:
    print("Элемент найден")
```

Результат:

```Python
Элемент найден
```

---

Разобранные конструкции:

```Python
reverse() — развернуть список
copy()    — создать поверхностную копию
len()     — получить длину списка
del       — удалить элемент, срез или переменную
in        — проверить наличие элемента
```

|Метод / оператор|Что делает|
|-|-|
|`reverse()`|разворачивает список|
|`copy()`|создаёт поверхностную копию|
|`len()`|возвращает длину списка|
|`del`|удаляет элемент, срез или переменную|
|`in`|проверяет наличие элемента|
