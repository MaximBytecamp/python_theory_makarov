**Цикл в цикле** — это конструкция, при которой **один цикл находится внутри другого**.
Внутренний цикл выполняется **полностью для каждой итерации внешнего цикла**.

Такая конструкция используется для:

- работы с **матрицами**

- обработки **двумерных данных**

- генерации **комбинаций**

- создания **таблиц**

- сравнения элементов двух наборов данных

---

# Общая схема

```Python
for внешний_элемент in внешний_набор:
    for внутренний_элемент in внутренний_набор:
        действие
```

---

# Как работает вложенный цикл

1️⃣ запускается **внешний цикл**
2️⃣ для первой итерации внешнего цикла запускается **внутренний цикл**
3️⃣ внутренний цикл выполняется **полностью**
4️⃣ затем внешняя итерация продолжается

---

# Пример №1

```Python
for i in range(3):
    for j in range(3):
        print(i, j)
```

Результат:

```Python
0 0
0 1
0 2
1 0
1 1
1 2
2 0
2 1
2 2
```

---

# Пошаговое выполнение

### Первая итерация внешнего цикла

```Python
i = 0
```

Запускается внутренний цикл:

```Python
j = 0 → print(0,0)
j = 1 → print(0,1)
j = 2 → print(0,2)
```

---

### Вторая итерация внешнего цикла

```Python
i = 1
```

Внутренний цикл снова выполняется полностью:

```Python
j = 0 → print(1,0)
j = 1 → print(1,1)
j = 2 → print(1,2)
```

---

### Третья итерация

```Python
i = 2
```

```Python
j = 0 → print(2,0)
j = 1 → print(2,1)
j = 2 → print(2,2)
```

---

# Важное правило

Если:

```Python
внешний цикл = N
внутренний цикл = M
```

то общее количество операций:

```Python
N × M
```

# Пример №4

Поиск совпадений

```Python
list1 = [1,2,3]
list2 = [2,3,4]

for a in list1:
    for b in list2:
        if a == b:
            print("Совпадение:", a)
```

Результат:

```Python
Совпадение: 2
Совпадение: 3
```

# Использование break

`break` завершает **только текущий цикл**, а не оба.

```Python
for i in range(3):
    for j in range(5):

        if j == 2:
            break

        print(i, j)
```

Результат:

```Python
0 0
0 1
1 0
1 1
2 0
2 1
```

---

# Использование continue

`continue` пропускает текущую итерацию внутреннего цикла.

```Python
for i in range(3):
    for j in range(3):

        if j == 1:
            continue

        print(i, j)
```

Результат:

```Python
0 0
0 2
1 0
1 2
2 0
2 2
```

# Сложность алгоритма

Вложенные циклы часто дают **квадратичную сложность**.

Если:

```Python
for i in range(n):
    for j in range(n):
```

то сложность:

```Python
O(n²)
```

Поэтому при больших данных нужно использовать вложенные циклы **осторожно**.
