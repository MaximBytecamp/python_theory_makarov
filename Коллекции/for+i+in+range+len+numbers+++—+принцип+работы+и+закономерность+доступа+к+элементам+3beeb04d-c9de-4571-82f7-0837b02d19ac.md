Конструкция

```Python
for i in range(len(numbers)):
```

используется, когда нужно **перебирать список по индексам**, а не по самим элементам.

Она часто применяется, когда:

- нужно изменить элементы списка

- нужен **доступ к соседним элементам**

- требуется **знать индекс элемента**

---

# Разбор конструкции

Предположим:

```Python
numbers = [10, 20, 30, 40]
```

---

## 1. `len(numbers)`

Функция `len()` возвращает **количество элементов** в списке.

```Python
len(numbers)
```

Результат:

```Python
4
```

---

## 2. `range(len(numbers))`

`range(4)` создаёт последовательность индексов:

```Python
0 1 2 3
```

---

## 3. Цикл `for`

```Python
for i in range(len(numbers)):
```

будет выполнять цикл **4 раза**.

Значения `i` будут:

```Python
i = 0
i = 1
i = 2
i = 3
```

---

# Получение элемента через индекс

Внутри цикла обычно пишут:

```Python
numbers[i]
```

Это означает:

```Python
взять элемент списка с индексом i
```

---

# Пример

```Python
numbers = [10, 20, 30, 40]

for i in range(len(numbers)):
    print(i, numbers[i])
```

Результат:

```Python
0 10
1 20
2 30
3 40
```

---

# Закономерность

Очень важное правило Python:

```Python
индекс элемента = его позиция в списке
```

|индекс|элемент|
|-|-|
|0|10|
|1|20|
|2|30|
|3|40|

Поэтому:

```Python
numbers[i]
```

всегда возвращает **элемент на позиции `i`**.

---

# Алгоритм работы

Python выполняет примерно такой алгоритм:

```Python
numbers = [10,20,30,40]

i = 0
print(numbers[0])

i = 1
print(numbers[1])

i = 2
print(numbers[2])

i = 3
print(numbers[3])
```

---

# Визуальная схема

```Python
numbers = [10, 20, 30, 40]

индекс:   0   1   2   3
элемент: 10  20  30  40
```

---

# Пример изменения элементов списка

Главная причина использования этой конструкции — **изменение элементов**.

```Python
numbers = [1,2,3,4]

for i in range(len(numbers)):
    numbers[i] = numbers[i] * 2

print(numbers)
```

Результат:

```Python
[2, 4, 6, 8]
```

---

# Пример доступа к соседним элементам

Иногда нужно сравнивать элементы.

```Python
numbers = [5, 8, 3, 10]

for i in range(len(numbers)-1):
    print(numbers[i], numbers[i+1])
```

Результат:

```Python
5 8
8 3
3 10
```

---

# Почему используется `len(numbers)-1`

Если бы написали:

```Python
numbers[i+1]
```

при `i = 3` произошло бы:

```Python
numbers[4]
```

А такого индекса **нет**.

Поэтому используют:

```Python
range(len(numbers)-1)
```

---

# Особенность Python

Индексация в Python начинается с:

```Python
0
```

Это называется **нулевая индексация (zero-based indexing)**.

---

# Альтернатива — обычный перебор

Чаще используют более простой вариант:

```Python
for num in numbers:
    print(num)
```

Но в этом случае **индекс недоступен**.

---

# Альтернатива — `enumerate()`

Лучший современный способ:

```Python
numbers = [10,20,30,40]

for i, num in enumerate(numbers):
    print(i, num)
```

Результат:

```Python
0 10
1 20
2 30
3 40
```

---

# Когда используется `for i in range(len())`

Этот вариант нужен когда:

- нужно **изменять элементы списка**

- требуется **доступ к соседним элементам**

- используется **алгоритм (сортировка, поиск)**

---

# Итог

Конструкция

```Python
for i in range(len(numbers))
```

работает по алгоритму:

```Python
1. len() определяет размер списка
2. range() создаёт индексы
3. цикл проходит по индексам
4. numbers[i] получает элемент по индексу
```

---

# Главное правило

```Python
индекс i → элемент numbers[i]
```
