# 1. `pop()`

Метод `pop()` **удаляет элемент по указанному индексу и возвращает его**.
Если индекс не указан, удаляется **последний элемент списка**.

---

## Пример

```Python
numbers = [10, 20, 30]
x = numbers.pop()

print(numbers)
print(x)
```

Результат:

```Python
[10, 20]
30
```

---

## Особенности `pop()`

### 1. Удаляет и возвращает элемент

```Python
numbers = [1, 2, 3]

x = numbers.pop()

print(x)
print(numbers)
```

Результат:

```Python
3
[1, 2]
```

---

### 2. Удаление по индексу

```Python
numbers = [10, 20, 30]

x = numbers.pop(1)

print(x)
print(numbers)
```

Результат:

```Python
20
[10, 30]
```

---

### 3. Ошибка при пустом списке

Если вызвать `pop()` для пустого списка:

```Python
numbers = []
numbers.pop()
```

возникнет ошибка:

```Python
IndexError
```

---

### 4. Поддержка отрицательных индексов

```Python
numbers = [10, 20, 30]

x = numbers.pop(-1)

print(x)
print(numbers)
```

Результат:

```Python
30
[10, 20]
```

---

### 5. Использование как стек (LIFO)

Стек — структура данных **Last In — First Out**
(последний добавленный элемент удаляется первым).

```Python
stack = []

stack.append(1)
stack.append(2)
stack.append(3)

print(stack)

print(stack.pop())
print(stack)
```

Результат:

```Python
[1, 2, 3]
3
[1, 2]
```

---

### 6. Использование как очередь (FIFO)

Хотя `pop()` не предназначен для очередей, его можно использовать так:

```Python
queue = [1, 2, 3]

print(queue.pop(0))
print(queue)
```

Результат:

```Python
1
[2, 3]
```

Но для очередей лучше использовать `collections.deque`.

---

## Сравнение `pop()`, `remove()` и `del`

|Метод|Что удаляет|Возвращает значение|
|-|-|-|
|`pop(index)`|элемент по индексу|Да|
|`remove(x)`|элемент по значению|Нет|
|`del list[index]`|элемент по индексу|Нет|

# 2. `clear()`

Метод `clear()` **удаляет все элементы списка**.

При этом сам объект списка **сохраняется**.

---

## Пример

```Python
numbers = [1, 2, 3, 4]

numbers.clear()

print(numbers)
```

Результат:

```Python
[]
```

---

## Особенности `clear()`

### 1. Работает на месте (in-place)

```Python
numbers = [1, 2, 3]

numbers.clear()

print(numbers)
```

Результат:

```Python
[]
```

---

### 2. Разница с `numbers = []`

```Python
numbers = [1, 2, 3]
another = numbers

numbers.clear()

print(numbers)
print(another)
```

Результат:

```Python
[]
[]
```

Обе переменные указывали на один список.

---

Теперь другой вариант:

```Python
numbers = [1, 2, 3]
another = numbers

numbers = []

print(numbers)
print(another)
```

Результат:

```Python
[]
[1, 2, 3]
```

Создался **новый список**, а старый остался.

---

### 3. Используется и в других коллекциях

Метод `clear()` работает также с:

- множествами

- словарями

```Python
data = {1, 2, 3}
data.clear()

print(data)
```

Результат:

```Python
set()
```

# 3. `index()`

Метод `index()` **возвращает индекс первого вхождения элемента**.

---

## Пример

```Python
numbers = [10, 20, 30, 20]

print(numbers.index(20))
```

Результат:

```Python
1
```

---

## Особенности `index()`

### 1. Возвращает только первое вхождение

```Python
numbers = [5, 10, 5, 20]

print(numbers.index(5))
```

Результат:

```Python
0
```

---

### 2. Ошибка если элемент не найден

```Python
numbers = [1, 2, 3]

numbers.index(10)
```

Ошибка:

```Python
ValueError
```

---

### 3. Поиск в диапазоне

```Python
numbers = [10, 20, 30, 20]

print(numbers.index(20, 2))
```

Результат:

```Python
3
```

Параметры:

```Python
index(element, start, end)
```

|параметр|значение|
|-|-|
|element|что ищем|
|start|начало поиска|
|end|конец поиска|

---

### 4. Не ищет внутри вложенных списков

```Python
data = [1, [2, 3], 4]

print(data.index([2, 3]))
```

Результат:

```Python
1
```

Но искать `2` внутри вложенного списка метод не будет.

---

# 4. `count()`

Метод `count()` **подсчитывает количество вхождений элемента**.

---

## Пример

```Python
numbers = [1, 2, 2, 3, 2]

print(numbers.count(2))
```

Результат:

```Python
3
```

---

## Особенности

### 1. Работает с любыми типами данных

```Python
data = ["a", "b", "a", "c"]

print(data.count("a"))
```

Результат:

```Python
2
```

---

### 2. Чувствительность к регистру

```Python
data = ["Python", "python", "Python"]

print(data.count("Python"))
```

Результат:

```Python
2
```

---

### 3. Проверка уникальности элемента

```Python
numbers = [1, 2, 3]

print(numbers.count(2) == 1)
```

Результат:

```Python
True
```

---

### 4. Работает с вложенными списками

```Python
data = [[1, 2], [1, 2], [3, 4]]

print(data.count([1, 2]))
```

Результат:

```Python
2
```

---

### 5. Временная сложность

Метод `count()` работает за:

```Python
O(n)
```

Потому что Python проходит весь список.

# 5. `sort()`

Метод `sort()` **сортирует список на месте**.

По умолчанию сортировка выполняется **по возрастанию**.

---

## Пример

```Python
numbers = [5, 2, 9, 1]

numbers.sort()

print(numbers)
```

Результат:

```Python
[1, 2, 5, 9]
```

---

## Особенности `sort()`

### 1. Сортировка на месте

```Python
numbers = [3, 1, 2]

result = numbers.sort()

print(numbers)
print(result)
```

Результат:

```Python
[1, 2, 3]
None
```

---

### 2. Сортировка в обратном порядке

```Python
numbers = [3, 1, 2]

numbers.sort(reverse=True)

print(numbers)
```

Результат:

```Python
[3, 2, 1]
```

---

### 3. Алгоритм сортировки

Python использует алгоритм:

```Python
Timsort
```

Сложность:

```Python
O(n log n)
```

---

### 4. Сортировка строк

```Python
words = ["banana", "apple", "cherry"]

words.sort()

print(words)
```

Результат:

```Python
['apple', 'banana', 'cherry']
```

---

### 5. Разница между `sort()` и `sorted()`

```Python
numbers = [3, 1, 2]

new_numbers = sorted(numbers)

print(numbers)
print(new_numbers)
```

Результат:

```Python
[3, 1, 2]
[1, 2, 3]
```

|Метод|Что делает|
|-|-|
|`sort()`|сортирует список на месте|
|`sorted()`|создаёт новый отсортированный список|

---

|Метод|Что делает|
|-|-|
|`pop()`|удаляет элемент по индексу и возвращает его|
|`clear()`|удаляет все элементы списка|
|`index()`|возвращает индекс первого вхождения|
|`count()`|считает количество вхождений|
|`sort()`|сортирует список|
