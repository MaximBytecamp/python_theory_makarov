В Python список (`list`) — это **изменяемая упорядоченная коллекция элементов**.
Это означает, что после создания списка его можно:

- дополнять

- изменять

- расширять

- очищать

- удалять элементы

В этой части разберём методы:

```Python
append()
extend()
insert()
remove()
```

---

# 1. `append()`

Метод `append()` **добавляет один элемент в конец списка**.

## Синтаксис

```Python
list.append(element)
```

## Пример

```Python
numbers = [1, 2, 3]
numbers.append(4)

print(numbers)
```

Результат:

```Python
[1, 2, 3, 4]
```

---

## Особенности `append()`

### 1. Изменяет список на месте

Метод `append()` изменяет **сам исходный список** и **не создаёт новый**.

```Python
numbers = [1, 2]
result = numbers.append(3)

print(numbers)
print(result)
```

Результат:

```Python
[1, 2, 3]
None
```

Важно:

```Python
append() ничего не возвращает
```

Он просто изменяет список.

---

### 2. Может добавить объект любого типа

С помощью `append()` можно добавить:

- число

- строку

- список

- словарь

- функцию

- объект класса

```Python
data = [1, 2]
data.append("Python")
data.append([10, 20])
data.append({"name": "Alex"})

print(data)
```

Результат:

```Python
[1, 2, 'Python', [10, 20], {'name': 'Alex'}]
```

---

### 3. Часто используется в циклах

`append()` очень часто применяется, когда список нужно **построить постепенно**.

```Python
squares = []

for i in range(1, 6):
    squares.append(i * i)

print(squares)
```

Результат:

```Python
[1, 4, 9, 16, 25]
```

---

### 4. Сравнение с `+`

```Python
list1 = [1, 2]
list1 = list1 + [3]
print(list1)
```

и

```Python
list1 = [1, 2]
list1.append(3)
print(list1)
```

дают одинаковый результат:

```Python
[1, 2, 3]
```

Но работают по-разному:

- `list1 = list1 + [3]` создаёт **новый список**

- `list1.append(3)` изменяет **старый список**

---

## Сравнение

|Характеристика|`list1 = list1 + [3]`|`list1.append(3)`|
|-|-|-|
|Создание нового списка|Да|Нет|
|Изменение на месте|Нет|Да|
|Использование памяти|Больше|Меньше|
|Временная сложность|`O(n)`|амортизированная `O(1)`|

---

### 5. Можно добавлять функции

Так как в Python функции — это объекты первого класса, их тоже можно хранить в списке.

```Python
def hello():
    print("Привет!")

funcs = []
funcs.append(hello)

funcs[0]()
```

Результат:

```Python
Привет!
```

Важно: функция **не выполняется при добавлении**, а просто сохраняется в списке.

# 2. `extend()`

Метод `extend()` **расширяет список**, добавляя в него **все элементы другого итерируемого объекта**.

## Синтаксис

```Python
list.extend(iterable)
```

## Пример

```Python
numbers = [1, 2, 3]
numbers.extend([4, 5, 6])

print(numbers)
```

Результат:

```Python
[1, 2, 3, 4, 5, 6]
```

---

## Особенности `extend()`

### 1. Добавляет элементы по одному

В отличие от `append()`, который добавляет **один объект**, `extend()` добавляет **все элементы итерируемого объекта отдельно**.

```Python
numbers = [1, 2]
numbers.append([3, 4])

print(numbers)
```

Результат:

```Python
[1, 2, [3, 4]]
```

А теперь:

```Python
numbers = [1, 2]
numbers.extend([3, 4])

print(numbers)
```

Результат:

```Python
[1, 2, 3, 4]
```

---

### 2. Работает с разными итерируемыми объектами

`extend()` принимает не только списки, но и:

- кортежи

- строки

- множества

- генераторы

```Python
data = [1, 2]
data.extend((3, 4))
data.extend("ab")

print(data)
```

Результат:

```Python
[1, 2, 3, 4, 'a', 'b']
```

---

### 3. Строка разбивается на символы

Если передать строку в `extend()`, Python будет воспринимать её как последовательность символов.

```Python
letters = [1, 2]
letters.extend("abc")

print(letters)
```

Результат:

```Python
[1, 2, 'a', 'b', 'c']
```

Если нужно добавить строку как **один элемент**, следует использовать `append()`:

```Python
letters = [1, 2]
letters.append("abc")

print(letters)
```

Результат:

```Python
[1, 2, 'abc']
```

---

### 4. Изменяет список на месте

```Python
numbers = [1, 2]
result = numbers.extend([3, 4])

print(numbers)
print(result)
```

Результат:

```Python
[1, 2, 3, 4]
None
```

---

### 5. Часто эффективнее, чем цикл с `append()`

```Python
numbers = [1, 2]
more = [3, 4, 5]

for x in more:
    numbers.append(x)
```

Этот код можно заменить более короткой записью:

```Python
numbers = [1, 2]
numbers.extend([3, 4, 5])
```

---

### 6. Работа с пустым итерируемым объектом

```Python
numbers = [1, 2, 3]
numbers.extend([])

print(numbers)
```

Результат:

```Python
[1, 2, 3]
```

Список не изменится.

---

### 7. Работа с генераторами

```Python
numbers = [1, 2]
numbers.extend(x * 10 for x in range(3))

print(numbers)
```

Результат:

```Python
[1, 2, 0, 10, 20]
```

---

# 3. `insert()`

Метод `insert()` **вставляет элемент в список по указанному индексу**.

## Синтаксис

```Python
list.insert(index, element)
```

## Пример

```Python
numbers = [1, 2, 3]
numbers.insert(1, 100)

print(numbers)
```

Результат:

```Python
[1, 100, 2, 3]
```

---

## Особенности `insert()`

### 1. Вставка в начало списка

```Python
numbers = [2, 3, 4]
numbers.insert(0, 1)

print(numbers)
```

Результат:

```Python
[1, 2, 3, 4]
```

---

### 2. Если индекс больше длины списка

Если индекс слишком большой, элемент будет добавлен в конец.

```Python
numbers = [1, 2, 3]
numbers.insert(10, 99)

print(numbers)
```

Результат:

```Python
[1, 2, 3, 99]
```

---

### 3. Поддержка отрицательных индексов

```Python
numbers = [1, 2, 3]
numbers.insert(-1, 50)

print(numbers)
```

Результат:

```Python
[1, 2, 50, 3]
```

---

### 4. Работает с пустым списком

```Python
numbers = []
numbers.insert(0, 100)

print(numbers)
```

Результат:

```Python
[100]
```

---

### 5. Можно вставлять сложные объекты

```Python
data = [1, 2, 3]
data.insert(1, [10, 20])

print(data)
```

Результат:

```Python
[1, [10, 20], 2, 3]
```

---

### 6. Использование в циклах

```Python
numbers = []

for i in range(3):
    numbers.insert(0, i)

print(numbers)
```

Результат:

```Python
[2, 1, 0]
```

---

# 4. `remove()`

Метод `remove()` **удаляет первое вхождение указанного значения**.

## Синтаксис

```Python
list.remove(value)
```

## Пример

```Python
numbers = [1, 2, 3, 2]
numbers.remove(2)

print(numbers)
```

Результат:

```Python
[1, 3, 2]
```

---

## Особенности `remove()`

### 1. Удаляет только первое вхождение

Если одинаковых значений несколько, удалится только первое.

```Python
numbers = [5, 1, 5, 5]
numbers.remove(5)

print(numbers)
```

Результат:

```Python
[1, 5, 5]
```

---

### 2. Если элемента нет — ошибка

```Python
numbers = [1, 2, 3]
numbers.remove(10)
```

Ошибка:

```Python
ValueError
```

---

### 3. Изменяет список на месте

```Python
numbers = [1, 2, 3]
result = numbers.remove(2)

print(numbers)
print(result)
```

Результат:

```Python
[1, 3]
None
```

---

### 4. Часто используется вместе с условиями

```Python
numbers = [1, 2, 3, 4]

if 3 in numbers:
    numbers.remove(3)

print(numbers)
```

Результат:

```Python
[1, 2, 4]
```

---

### 5. Временная сложность

Метод `remove()` в общем случае работает за:

```Python
O(n)
```

Потому что Python должен сначала найти элемент в списке.

---

В этой части были разобраны методы:

```Python
append()  — добавить один элемент в конец
extend()  — добавить все элементы итерируемого объекта
insert()  — вставить элемент по индексу
remove()  — удалить первое вхождение значения
```

|Метод|Что делает|
|-|-|
|`append(x)`|добавляет один элемент в конец|
|`extend(iterable)`|добавляет все элементы по отдельности|
|`insert(i, x)`|вставляет элемент на указанную позицию|
|`remove(x)`|удаляет первое вхождение элемента|
