# 1. `enumerate()`

Функция `enumerate()` используется для **получения пары индекс–значение** при переборе элементов коллекции.

---

# Основная идея

Обычно при обходе списка нужно одновременно получать:

- индекс элемента

- значение элемента

Без `enumerate()` код выглядит так:

```Python
numbers = [10, 20, 30]

for i in range(len(numbers)):
    print(i, numbers[i])
```

Используя `enumerate()` код становится проще:

```Python
numbers = [10, 20, 30]

for index, value in enumerate(numbers):
    print(index, value)
```

Результат:

```Python
0 10
1 20
2 30
```

---

# Особенности `enumerate()`

## 1. Возвращает объект enumerate

Функция возвращает **итератор**, который можно преобразовать в список.

```Python
numbers = [10, 20, 30]

print(list(enumerate(numbers)))
```

Результат:

```Python
[(0, 10), (1, 20), (2, 30)]
```

---

## 2. Индексы начинаются с нуля

По умолчанию нумерация начинается с `0`.

```Python
words = ["apple", "banana", "cherry"]

for i, word in enumerate(words):
    print(i, word)
```

Результат:

```Python
0 apple
1 banana
2 cherry
```

---

## 3. Можно изменить начальный индекс

```Python
words = ["apple", "banana", "cherry"]

for i, word in enumerate(words, start=1):
    print(i, word)
```

Результат:

```Python
1 apple
2 banana
3 cherry
```

---

## 4. Работает с любыми итерируемыми объектами

### Строка

```Python
text = "Python"

for i, char in enumerate(text):
    print(i, char)
```

Результат:

```Python
0 P
1 y
2 t
3 h
4 o 
5 n
```

---

### Кортеж

```Python
data = (10, 20, 30)

for i, value in enumerate(data):
    print(i, value)
```

Результат:

```Python
0 10
1 20
2 30
```

---

## 5. Можно создавать словари

```Python
words = ["apple", "banana", "cherry"]

dictionary = dict(enumerate(words))

print(dictionary)
```

Результат:

```Python
{0: 'apple', 1: 'banana', 2: 'cherry'}
```

---

# 2. `zip()`

Функция `zip()` используется для **объединения нескольких итерируемых объектов**.

Она возвращает **итератор кортежей**, содержащих элементы из каждой коллекции.

---

## Пример

```Python
names = ["Alice", "Bob", "Charlie"]
scores = [90, 85, 95]

result = zip(names, scores)

print(list(result))
```

Результат:

```Python
[('Alice', 90), ('Bob', 85), ('Charlie', 95)]
```

---

# Особенности `zip()`

## 1. Длина результата

Результат ограничивается **длиной самого короткого списка**.

```Python
a = [1, 2, 3]
b = ["a", "b"]

print(list(zip(a, b)))
```

Результат:

```Python
[(1, 'a'), (2, 'b')]
```

---

## 2. Распаковка с помощью `*`

Можно разъединить объединённые данные.

```Python
pairs = [(1, "a"), (2, "b"), (3, "c")]

numbers, letters = zip(*pairs)

print(numbers)
print(letters)
```

Результат:

```Python
(1, 2, 3)
('a', 'b', 'c')
```

---

## 3. Работа с несколькими коллекциями

```Python
a = [1, 2, 3]
b = ["a", "b", "c"]
c = [True, False, True]

print(list(zip(a, b, c)))
```

Результат:

```Python
[(1, 'a', True), (2, 'b', False), (3, 'c', True)]
```

---

## 4. Создание словарей

```Python
keys = ["name", "age", "city"]
values = ["Alex", 25, "Berlin"]

data = dict(zip(keys, values))

print(data)
```

Результат:

```Python
{'name': 'Alex', 'age': 25, 'city': 'Berlin'}
```

---

## 5. Совместное использование с `enumerate()`

```Python
names = ["Alice", "Bob", "Charlie"]
scores = [90, 85, 95]

for i, (name, score) in enumerate(zip(names, scores), start=1):
    print(i, name, score)
```

---

# 3. `reversed()`

Функция `reversed()` возвращает **итератор, проходящий элементы в обратном порядке**.

---

## Пример

```Python
numbers = [1, 2, 3, 4]

print(list(reversed(numbers)))
```

Результат:

```Python
[4, 3, 2, 1]
```

---

## Использование в цикле

```Python
numbers = [1, 2, 3, 4]

for n in reversed(numbers):
    print(n)
```

---

# Разница между `reversed()` и `reverse()`

||reversed()|reverse()|
|-|-|-|
|Возвращает|итератор|None|
|Меняет список|Нет|Да|
|Используется в циклах|Да|Нет|
|Создаёт копию|Нет|Нет|

---

## Пример

```Python
numbers = [1, 2, 3]

for x in reversed(numbers):
    print(x)
```

---

# 4. `any()`

Функция `any()` возвращает **True, если хотя бы один элемент является истинным**.

---

## Пример

```Python
numbers = [0, 0, 1, 0]

print(any(numbers))
```

Результат:

```Python
True
```

---

## Если все значения ложные

```Python
numbers = [0, False, None]

print(any(numbers))
```

Результат:

```Python
False
```

---

## Работает с любыми коллекциями

```Python
text = "Hello"

print(any(text))
```

Результат:

```Python
True
```

Потому что любой символ строки считается истинным значением.

---

# 5. `all()`

Функция `all()` возвращает **True, если все элементы являются истинными**.

---

## Пример

```Python
numbers = [1, 2, 3]

print(all(numbers))
```

Результат:

```Python
True
```

---

## Если хотя бы один элемент ложный

```Python
numbers = [1, 0, 3]

print(all(numbers))
```

Результат:

```Python
False
```

---

# Сравнение `any()` и `all()`

|Функция|Условие|
|-|-|
|`any()`|True если хотя бы один элемент True|
|`all()`|True если все элементы True|

---

## Совместное использование

```Python
numbers = [1, 2, 3]

print(any(x > 2 for x in numbers))
print(all(x > 0 for x in numbers))
```

Результат:

```Python
True
True
```

---

# Поведение на пустых коллекциях

```Python
print(any([]))
print(all([]))
```

Результат:

```Python
False
True
```

Почему так:

- `any([])` → нет истинных элементов

- `all([])` → нет элементов, нарушающих условие

---

# ИТОГ

|Функция|Назначение|
|-|-|
|`enumerate()`|возвращает пары индекс–значение|
|`zip()`|объединяет несколько коллекций|
|`reversed()`|итерация в обратном порядке|
|`any()`|True если хотя бы один элемент True|
|`all()`|True если все элементы True|
