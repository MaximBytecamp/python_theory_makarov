**Срез (slice)** — это способ получения части последовательности:

- списка (`list`)

- строки (`str`)

- кортежа (`tuple`)

- других итерируемых объектов

С помощью срезов можно:

- получить часть данных

- изменить часть списка

- удалить элементы

- копировать последовательности

---

# Важная особенность

Срезы **не изменяют оригинальный объект**.

Они **возвращают новый объект**.

То есть:

```Python
срез = копия части последовательности
```

Это означает, что срез **не работает in-place**.

---

# Синтаксис среза

```Python
sequence[start:stop:step]
```

|параметр|описание|
|-|-|
|`start`|начальный индекс (включительно)|
|`stop`|конечный индекс (не включительно)|
|`step`|шаг|

---

# Пример №1

Получить элементы с индекса **1 по 3**

```Python
numbers = [10, 20, 30, 40, 50]

result = numbers[1:4]

print(result)
```

Результат:

```Python
[20, 30, 40]
```

---

# Пример №2

Получить **каждый второй элемент**

```Python
numbers = [1, 2, 3, 4, 5, 6]

result = numbers[::2]

print(result)
```

Результат:

```Python
[1, 3, 5]
```

---

# Пример №3

Отрицательные индексы

Отрицательные индексы начинают отсчёт **с конца списка**.

```Python
numbers = [10, 20, 30, 40, 50]

result = numbers[-3:]

print(result)
```

Результат:

```Python
[30, 40, 50]
```

---

# Пример №4

Получить список **в обратном порядке**

```Python
numbers = [1, 2, 3, 4, 5]

result = numbers[::-1]

print(result)
```

Результат:

```Python
[5, 4, 3, 2, 1]
```

Это один из самых популярных трюков Python.

---

# Пример №5

Автоматические значения параметров

Если параметры не указаны:

```Python
start = 0
stop = len(sequence)
step = 1
```

Пример:

```Python
numbers = [1, 2, 3, 4, 5]

print(numbers[:])
```

Результат:

```Python
[1, 2, 3, 4, 5]
```

# Особенности срезов

---

# 1. Срез создает новый список

```Python
numbers = [1, 2, 3, 4]

copy_list = numbers[1:3]

copy_list[0] = 100

print(numbers)
print(copy_list)
```

Результат:

```Python
[1, 2, 3, 4]
[100, 3]
```

Оригинальный список **не изменился**.

---

# 2. Срез не вызывает ошибку при выходе за границы

```Python
numbers = [1, 2, 3]

print(numbers[0:10])
```

Результат:

```Python
[1, 2, 3]
```

Python просто возвращает **доступные элементы**.

---

# 3. Изменение части списка через срез

Срез можно использовать для **изменения элементов списка**.

```Python
numbers = [1, 2, 3, 4, 5]

numbers[1:3] = [20, 30]

print(numbers)
```

Результат:

```Python
[1, 20, 30, 4, 5]
```

---

# 4. Удаление части списка через срез

```Python
numbers = [1, 2, 3, 4, 5]

del numbers[1:4]

print(numbers)
```

Результат:

```Python
[1, 5]
```

---

# 5. Копирование списка через срез

Очень распространённый способ копирования списка:

```Python
numbers = [1, 2, 3]

copy_list = numbers[:]

print(copy_list)
```

Результат:

```Python
[1, 2, 3]
```

---

# Сравнение способов копирования

|Способ|Описание|
|-|-|
|`list[:]`|копия через срез|
|`list.copy()`|встроенный метод|
|`list(list)`|конструктор|
