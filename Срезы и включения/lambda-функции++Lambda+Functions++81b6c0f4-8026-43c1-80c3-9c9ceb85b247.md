Лямбда-функции получили своё название от **лямбда-исчисления (λ-исчисления)** — математической системы, лежащей в основе функционального программирования.

В лямбда-исчислении используется символ **λ (лямбда)** для обозначения анонимных функций.

Пример из математики:

```Python
λx.x + 1
```

Это функция, которая принимает аргумент `x` и возвращает `x + 1`.

В Python аналог выглядит так:

```Python
lambda x: x + 1
```

---

# Что такое лямбда-функция

Лямбда-функция — это **анонимная функция**, которая создаётся без использования `def`.

Она используется для создания **коротких одноразовых функций**.

---

# Синтаксис

```Python
lambda arguments: expression
```

Пример:

```Python
f = lambda x: x + 1

print(f(5))
```

Результат:

```Python
6
```

---

# Где используются лямбда-функции

Лямбда-функции часто применяются:

### 1. В функциональном программировании

С функциями:

```Python
map()
filter()
reduce()
```

---

### 2. В сортировке

```Python
sorted()
min()
max()
```

---

### 3. В обработчиках событий

Например, в GUI или колбэках.

---

# Пример простой лямбда-функции

Обычная функция:

```Python
def square(x):
    return x * x
```

Лямбда-аналог:

```Python
square = lambda x: x * x

print(square(4))
```

Результат:

```Python
16
```

---

# Преимущества лямбда-функций

## 1. Краткость

Лямбда позволяет написать функцию **в одну строку**.

```Python
add = lambda a, b: a + b

print(add(3, 4))
```

Результат:

```Python
7
```

---

## 2. Анонимность

Функция **не требует имени**.

Она может использоваться прямо в выражении.

```Python
print((lambda x: x * 2)(5))
```

Результат:

```Python
10
```

---

## 3. Удобство при работе с функциями высшего порядка

Например, с `map()`:

```Python
numbers = [1, 2, 3, 4]

result = list(map(lambda x: x * 2, numbers))

print(result)
```

Результат:

```Python
[2, 4, 6, 8]
```

---

# Использование с `filter()`

```Python
numbers = [1, 2, 3, 4, 5]

result = list(filter(lambda x: x % 2 == 0, numbers))

print(result)
```

Результат:

```Python
[2, 4]
```

---

# Использование с `sorted()`

Лямбда-функция часто используется для задания **ключа сортировки**.

```Python
data = [(1, 3), (4, 1), (2, 2)]

result = sorted(data, key=lambda x: x[1])

print(result)
```

Результат:

```Python
[(4, 1), (2, 2), (1, 3)]
```

Сортировка выполняется по **второму элементу кортежа**.

---

# Ограничения лямбда-функций

Несмотря на удобство, у них есть ограничения.

---

## 1. Только одно выражение

Лямбда может содержать **только одно выражение**.

Нельзя писать:

- циклы

- несколько операторов

- сложную логику

Неправильно:

```Python
lambda x:
    y = x + 1
    return y
```

---

## 2. Нет имени

Лямбда-функции **не имеют имени**, что усложняет:

- отладку

- трассировку ошибок

---

## 3. Может ухудшать читаемость

Если выражение сложное, код становится трудно читать.

---

# Когда использовать lambda

Лямбда-функции подходят для:

- небольших функций

- одноразовых операций

- передачи функции как аргумента

---

# Когда лучше использовать `def`

Лучше использовать обычную функцию, если:

- функция используется много раз

- логика занимает несколько строк

- нужна хорошая читаемость

- требуется документация

---

# Вывод функции lambda

Если попытаться вывести функцию:

```Python
f = lambda x: x + 1

print(f)
```

Результат будет примерно таким:

```Python
<function <lambda> at 0x7fc7a239b5b0>
```

Это означает:

- объект типа **function**

- имя функции

- адрес функции **в памяти**

---

# Сравнение с обычной функцией

```Python
def add(x):
    return x + 1

print(add)
```

Результат:

```Python
<function add at 0x...>
```

Здесь Python показывает **имя функции**.

# Пример практической задачи

Определение гласных и согласных букв.

```Python
letters = list("python")

result = list(map(lambda x: "гласная" if x in "aeiou" else "согласная", letters))

print(result)
```

Результат:

```Python
['согласная', 'согласная', 'согласная', 'гласная', 'согласная', 'согласная']
```

---

# Пример с `filter()`

Отфильтровать числа больше 10.

```Python
numbers = [5, 10, 15, 20]

result = list(filter(lambda x: x > 10, numbers))

print(result)
```

Результат:

```Python
[15, 20]
```

---

# Пример со словарём

```Python
data = {
    "a": 5,
    "b": 10,
    "c": 3
}

result = dict(filter(lambda item: item[1] > 4, data.items()))

print(result)
```

Результат:

```Python
{'a': 5, 'b': 10}
```

# Если бы не было `map()` и `filter()`

Пришлось бы писать обычные циклы.

### Пример с `map()`

```Python
numbers = [1, 2, 3, 4]

result = []

for x in numbers:
    result.append(x * 2)

print(result)
```

---

### Пример с `filter()`

```Python
numbers = [1, 2, 3, 4, 5]

result = []

for x in numbers:
    if x % 2 == 0:
        result.append(x)

print(result)
```
