**Вложенное включение** — это конструкция, в которой одно включение используется внутри другого.
Обычно применяется для работы с:

- **матрицами**

- **двумерными списками**

- **вложенными структурами данных**

- **комбинациями элементов**

По сути это аналог **вложенных циклов `for`**, только записанный компактно.

---

# Общий синтаксис

```Python
[выражение for x in iterable1 for y in iterable2]
```

Это эквивалентно следующему коду:

```Python
result = []

for x in iterable1:
    for y in iterable2:
        result.append(выражение)
```

---

# Пример №1

Создание всех комбинаций чисел

```Python
pairs = [(x, y) for x in range(3) for y in range(3)]

print(pairs)
```

Результат:

```Python
[(0,0), (0,1), (0,2),
 (1,0), (1,1), (1,2),
 (2,0), (2,1), (2,2)]
```

---

# Как работает этот код

Сначала берётся `x`, затем для него перебираются все `y`.

```Python
x = 0
    y = 0
    y = 1
    y = 2

x = 1
    y = 0
    y = 1
    y = 2

x = 2
    y = 0
    y = 1
    y = 2
```

# Пример №2

Аналог вложенных циклов

Обычный код:

```Python
result = []

for i in range(3):
    for j in range(3):
        result.append(i + j)

print(result)
```

---

Через включение:

```Python
result = [i + j for i in range(3) for j in range(3)]

print(result)
```

Результат:

```Python
[0,1,2,1,2,3,2,3,4]
```

---

# Пример №3

Работа с матрицей

```Python
matrix = [
    [1,2,3],
    [4,5,6],
    [7,8,9]
]

flatten = [num for row in matrix for num in row]

print(flatten)
```

Результат:

```Python
[1,2,3,4,5,6,7,8,9]
```

Это называется **"выпрямление матрицы" (flatten list)**.

---

# Эквивалент через циклы

```Python
flatten = []

for row in matrix:
    for num in row:
        flatten.append(num)
```

# Пример №4

Создание матрицы

```Python
matrix = [[i + j*3 for i in range(3)] for j in range(3)]

print(matrix)
```

Результат:

```Python
[
 [0,1,2],
 [3,4,5],
 [6,7,8]
]
```

---

# Как работает

Внутреннее включение:

```Python
[i + j*3 for i in range(3)]
```

создаёт строку матрицы.

Внешнее:

```Python
[ ... for j in range(3) ]
```

создаёт список строк.

# Пример №5

Включение внутри включения с условием

```Python
result = [x*y for x in range(5) for y in range(5) if x*y % 2 == 0]

print(result)
```

Результат:

```Python
[0,0,0,0,0,0,2,4,6,8,0,4,8,12,16]
```

# Правило чтения вложенных включений

Читать нужно **справа налево**:

```Python
for row in matrix
for num in row
```

означает

```Python
сначала берем row
потом берем num из row
```

---

# Когда использовать вложенные включения

Они полезны для:

- работы с **матрицами**

- **flatten списков**

- генерации **комбинаций**

- обработки **вложенных структур**

---

# Когда лучше не использовать

Если выражение становится слишком сложным.

Например:

```Python
[a*b+c for a in x for b in y if ...]
```

лучше переписать в обычные циклы.

---

# Главное запомнить

Вложенное включение — это просто **вложенные циклы `for`**, записанные компактно.

```Python
[expr for x in A for y in B]
```

эквивалентно

```Python
for x in A
    for y in B
```
