Функции высшего порядка — это функции, которые:

- **принимают другие функции как аргументы**

- **или возвращают функцию как результат**

Это один из ключевых механизмов **функционального программирования**, позволяющий писать:

- более абстрактный код

- более компактный код

- более модульные программы

---

# Основные функции высшего порядка в Python

В Python наиболее часто используются следующие функции:

```Python
map()
filter()
reduce()
sorted()
```

|Функция|Назначение|
|-|-|
|`map()`|применяет функцию к каждому элементу|
|`filter()`|отбирает элементы по условию|
|`reduce()`|сводит последовательность к одному значению|
|`sorted()`|сортирует по заданному ключу|

---

# 1. `map()`

Функция `map()` применяется **ко всем элементам последовательности**, применяя к ним указанную функцию.

---

# Синтаксис

```Python
map(function, iterable)
```

---

# Простой пример

```Python
numbers = [1, 2, 3, 4]

def square(x):
    return x * x

result = map(square, numbers)

print(list(result))
```

Результат:

```Python
[1, 4, 9, 16]
```

---

# Особенности `map()`

## 1. Ленивая вычисляемость

`map()` возвращает **итератор**, а не список.

Это означает:

- вычисления происходят **только при необходимости**

- экономится память

```Python
numbers = [1, 2, 3]

result = map(lambda x: x * 2, numbers)

print(result)
print(list(result))
```

Результат:

```Python
<map object ...>
[2, 4, 6]
```

---

## 2. Работа с несколькими последовательностями

`map()` может обрабатывать **несколько списков одновременно**.

```Python
a = [1, 2, 3]
b = [4, 5, 6]

result = map(lambda x, y: x + y, a, b)

print(list(result))
```

Результат:

```Python
[5, 7, 9]
```

---

## 3. Использование с `lambda`

Очень часто `map()` используют с **анонимными функциями**.

```Python
numbers = [1, 2, 3]

result = map(lambda x: x * 10, numbers)

print(list(result))
```

Результат:

```Python
[10, 20, 30]
```

---

## 4. Преобразование в список

Так как `map()` возвращает итератор, результат обычно преобразуют:

```Python
list()
tuple()
set()
```

```Python
numbers = [1, 2, 3]

result = list(map(lambda x: x**2, numbers))

print(result)
```

---

## 5. Работа с различными итерируемыми объектами

`map()` работает не только со списками.

### Строка

```Python
text = "abc"

result = list(map(str.upper, text))

print(result)
```

Результат:

```Python
['A', 'B', 'C']
```

---

### Кортеж

```Python
data = (1, 2, 3)

result = list(map(lambda x: x + 5, data))

print(result)
```

---

# Пример практической задачи

Преобразование строк в числа и подсчёт суммы.

```Python
numbers = ["1", "2", "3", "4"]

numbers_int = list(map(int, numbers))

print(sum(numbers_int))
```

Результат:

```Python
10
```

# 2. `filter()`

Функция `filter()` используется для **фильтрации элементов последовательности**.

Она возвращает **только те элементы, для которых функция возвращает True**.

---

# Синтаксис

```Python
filter(function, iterable)
```

---

# Пример

```Python
numbers = [1, 2, 3, 4, 5]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))
```

Результат:

```Python
[2, 4]
```

---

# Особенности `filter()`

## 1. Возвращает итератор

Как и `map()`, `filter()` возвращает **итератор**.

```Python
numbers = [1, 2, 3]

result = filter(lambda x: x > 1, numbers)

print(result)
print(list(result))
```

---

## 2. Функция может быть любой

Можно использовать обычную функцию.

```Python
def is_even(x):
    return x % 2 == 0

numbers = [1, 2, 3, 4]

result = filter(is_even, numbers)

print(list(result))
```

Результат:

```Python
[2, 4]
```

---

## 3. Работает с любыми итерируемыми объектами

### Строка

```Python
text = "Python123"

result = filter(str.isalpha, text)

print(list(result))
```

Результат:

```Python
['P', 'y', 't', 'h', 'o', 'n']
```

---

### Кортеж

```Python
data = (1, 5, 10, 2)

result = list(filter(lambda x: x > 3, data))

print(result)
```

Результат:

```Python
[5, 10]
```

---

## 4. Ленивые вычисления

`filter()` вычисляет элементы **только во время итерации**.

Это делает его эффективным при работе с **большими данными**.

---

## 5. Использование `None`

Если передать `None`, `filter()` удалит все **ложные значения**.

К ложным значениям относятся:

```Python
False
None
0
''
[]
{}
```

---

### Пример

```Python
data = [0, 1, False, 2, "", 3]

result = filter(None, data)

print(list(result))
```

Результат:

```Python
[1, 2, 3]
```

---

# Комбинирование `map()` и `filter()`

Очень часто эти функции используются **вместе**.

---

### Пример

Найти квадраты **чётных чисел**.

```Python
numbers = [1, 2, 3, 4, 5]

result = map(lambda x: x**2,
             filter(lambda x: x % 2 == 0, numbers))

print(list(result))
```

Результат:

```Python
[4, 16]
```

---

# Главное, что нужно запомнить

- `map()` → **преобразует элементы**

- `filter()` → **фильтрует элементы**

- обе функции **возвращают итераторы**

- часто используются с **lambda**
