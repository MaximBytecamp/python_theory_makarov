## 1. Что такое `frozenset`

`frozenset` — это **неизменяемая версия множества** (`set`).

Если говорить очень коротко:

```Plain Text
set       → множество, которое можно менять
frozenset → множество, которое менять нельзя
```

---

### Интуитивное объяснение

Обычное множество — это как доска, на которую можно:

- дописывать элементы

- стирать элементы

- перестраивать содержимое

`frozenset` — это как уже напечатанная карточка:

- состав элементов зафиксирован

- после создания ничего добавить или удалить нельзя

> важная мысль
`frozenset` — это множество с логикой `set`, но с поведением immutable-объекта

---

## 2. Зачем вообще нужен `frozenset`

На первый взгляд может показаться, что это просто “ещё один тип множества”.

Но на практике он решает очень важную проблему:

- `set` удобен как математическое множество

- но `set` изменяемый

- а изменяемые объекты нельзя использовать в качестве ключей словаря и элементов других множеств

Именно здесь появляется `frozenset`.

Он позволяет сказать:

```Plain Text
мне нужна семантика множества,
но объект должен быть неизменяемым и хэшируемым
```

---

## 3. Создание `frozenset`

Синтаксис:

```Python
frozenset([iterable])
```

Где `iterable` — любой итерируемый объект:

- список

- кортеж

- строка

- множество

- другой `frozenset`

---

### 3.1 Из списка

```Python
fs = frozenset([1, 2, 3, 2, 1])
print(fs)
```

Вывод:

```Plain Text
frozenset({1, 2, 3})
```

Как и обычное множество, `frozenset`:

- удаляет дубликаты

- не хранит порядок

---

### 3.2 Из кортежа

```Python
fs = frozenset((10, 20, 30))
print(fs)
```

Вывод:

```Plain Text
frozenset({10, 20, 30})
```

---

### 3.3 Из строки

```Python
fs = frozenset("hello")
print(fs)
```

Вывод:

```Plain Text
frozenset({'h', 'e', 'l', 'o'})
```

Здесь строка разбирается посимвольно, а повторяющиеся символы убираются.

---

### 3.4 Пустой `frozenset`

```Python
fs = frozenset()
print(fs)
```

Вывод:

```Plain Text
frozenset()
```

---

## 4. Основные свойства `frozenset`

---

### 4.1 Неизменяемость

После создания `frozenset` нельзя изменить.

Это означает, что у него нет методов, которые меняют содержимое:

- `add()`

- `remove()`

- `discard()`

- `pop()`

- `update()`

- `intersection_update()`

- `difference_update()`

- `symmetric_difference_update()`

---

### 4.2 Уникальность элементов

Как и `set`, `frozenset` хранит только уникальные элементы.

```Python
fs = frozenset([1, 1, 2, 2, 3, 3])
print(fs)
```

Вывод:

```Plain Text
frozenset({1, 2, 3})
```

---

### 4.3 Неупорядоченность

Порядок элементов в `frozenset` не гарантируется.

```Python
fs = frozenset(["apple", "banana", "orange"])
print(fs)
```

Вывод может быть, например:

```Plain Text
frozenset({'banana', 'orange', 'apple'})
```

Или в другом порядке.

---

### 4.4 Хэшируемость

Вот это ключевое свойство.

Поскольку `frozenset` неизменяем, его можно хэшировать.

А значит, его можно использовать:

- как ключ словаря

- как элемент другого множества

- как часть составного ключа

> важная мысль
главная практическая ценность `frozenset` — в том, что это множество, которое можно использовать там, где `set` использовать нельзя

---

## 5. Почему обычный `set` нельзя использовать как ключ словаря

Ключи словаря должны быть:

- неизменяемыми

- хэшируемыми

Обычное множество не подходит, потому что оно изменяемо.

### Пример ошибки

```Python
d = {
    {1, 2, 3}: "value"
}
```

Вывод:

```Plain Text
TypeError: unhashable type: 'set'
```

---

## 6. Почему `frozenset` можно использовать как ключ словаря

Потому что после создания его нельзя изменить.

Следовательно:

- состав элементов стабилен

- хэш стабилен

- объект безопасен для хэш-таблицы словаря

### Пример

```Python
d = {
    frozenset([1, 2, 3]): "group A",
    frozenset([4, 5]): "group B"
}

print(d[frozenset([1, 2, 3])])
```

Вывод:

```Plain Text
group A
```

---

## 7. Использование `frozenset` как элемента другого множества

Обычное множество нельзя положить внутрь другого множества:

```Python
s = {
    {1, 2},
    {3, 4}
}
```

Это вызовет ошибку:

```Plain Text
TypeError: unhashable type: 'set'
```

Но `frozenset` можно:

```Python
s = {
    frozenset([1, 2]),
    frozenset([3, 4])
}

print(s)
```

Вывод:

```Plain Text
{frozenset({3, 4}), frozenset({1, 2})}
```

---

### Зачем это бывает нужно

Это полезно, когда нужно хранить **множество множеств**.

Например:

- группы разрешений

- наборы тегов

- комбинации признаков

- уникальные подмножества

---

## 8. Что `frozenset` умеет, а что не умеет

Теперь важно разделить методы на две группы.

---

## 9. Методы, которые `frozenset` **не поддерживает**

Поскольку объект неизменяемый, нельзя делать операции, меняющие содержимое.

### Пример

```Python
fs = frozenset([1, 2, 3])
fs.add(4)
```

Вывод:

```Plain Text
AttributeError: 'frozenset' object has no attribute 'add'
```

---

### Аналогично не работают

- `remove()`

- `discard()`

- `pop()`

- `clear()`

- `update()`

- `intersection_update()`

- `difference_update()`

- `symmetric_difference_update()`

---

## 10. Методы, которые `frozenset` поддерживает

Все **неизменяющие** операции работают.

То есть те методы, которые создают новый результат или просто проверяют отношения между множествами.

К ним относятся:

- `union()`

- `intersection()`

- `difference()`

- `symmetric_difference()`

- `issubset()`

- `issuperset()`

- `isdisjoint()`

---

## 11. `union()` с `frozenset`

```Python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 4, 5])

result = fs1.union(fs2)

print(result)
print(type(result))
```

Вывод:

```Plain Text
frozenset({1, 2, 3, 4, 5})
<class 'frozenset'>
```

---

## 12. `intersection()` с `frozenset`

```Python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([2, 3, 4])

result = fs1.intersection(fs2)

print(result)
```

Вывод:

```Plain Text
frozenset({2, 3})
```

---

## 13. `difference()` с `frozenset`

```Python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([2, 3])

result = fs1.difference(fs2)

print(result)
```

Вывод:

```Plain Text
frozenset({1})
```

---

## 14. `symmetric_difference()` с `frozenset`

```Python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 4])

result = fs1.symmetric_difference(fs2)

print(result)
```

Вывод:

```Plain Text
frozenset({1, 2, 4})
```

---

## 15. Проверки отношений между множествами

---

### 15.1 `issubset()`

```Python
fs1 = frozenset([1, 2])
fs2 = frozenset([1, 2, 3])

print(fs1.issubset(fs2))
```

Вывод:

```Plain Text
True
```

---

### 15.2 `issuperset()`

```Python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([1, 2])

print(fs1.issuperset(fs2))
```

Вывод:

```Plain Text
True
```

---

### 15.3 `isdisjoint()`

```Python
fs1 = frozenset([1, 2])
fs2 = frozenset([3, 4])

print(fs1.isdisjoint(fs2))
```

Вывод:

```Plain Text
True
```

|Свойство|`set`|`frozenset`|
|-|-|-|
|Изменяемость|да|нет|
|Уникальные элементы|да|да|
|Неупорядоченность|да|да|
|`add/remove`|да|нет|
|Можно как ключ `dict`|нет|да|

## 17. Где `frozenset` действительно нужен

Теперь разберём не просто синтаксис, а реальные сценарии применения.

---

## 18. `frozenset` как ключ словаря

Это самый важный кейс.

### Пример: права доступа как набор

```Python
permissions_map = {
    frozenset(["read"]): "guest",
    frozenset(["read", "write"]): "editor",
    frozenset(["read", "write", "delete"]): "admin"
}

print(permissions_map[frozenset(["read", "write"])])
```

Вывод:

```Plain Text
editor
```

---

### Почему здесь `frozenset` лучше кортежа

Потому что:

- порядок прав не важен

- важен сам набор

Например:

```Python
frozenset(["read", "write"]) == frozenset(["write", "read"])
```

Результат:

```Python
print(frozenset(["read", "write"]) == frozenset(["write", "read"]))
```

Вывод:

```Plain Text
True
```

А у кортежей порядок был бы важен.

---

## 19. `frozenset` как элемент другого множества

### Пример: множество групп тегов

```Python
tag_groups = {
    frozenset(["python", "backend"]),
    frozenset(["design", "figma"]),
    frozenset(["python", "redis"])
}

print(tag_groups)
```

Вывод может быть:

```Plain Text
{frozenset({'design', 'figma'}), frozenset({'python', 'redis'}), frozenset({'python', 'backend'})}
```

---

### Зачем это полезно

Когда нужно хранить не отдельные элементы, а **наборы элементов как отдельные единицы**.

---

## 20. `frozenset` и составные логические состояния

Иногда в backend или логике приложения важно не просто хранить список условий, а использовать набор условий как идентификатор состояния.

### Пример

```Python
state_handlers = {
    frozenset(["logged_in"]): "show_dashboard",
    frozenset(["logged_in", "premium"]): "show_premium_dashboard",
    frozenset(["guest"]): "show_landing"
}

print(state_handlers[frozenset(["premium", "logged_in"])])
```

Вывод:

```Plain Text
show_premium_dashboard
```

---

### Что здесь особенно ценно

Порядок условий не влияет на поиск.

Это делает `frozenset` очень естественным типом для таких задач.

---

## 21. `frozenset` и производительность

В целом `frozenset` по смыслу и возможностям поиска очень похож на обычный `set`.

То есть поддерживаемые операции:

- membership check

- пересечения

- объединения

- проверки отношений

работают очень быстро, потому что внутри сохраняется логика хэш-таблицы.

### Что важно понимать

Разница не в том, что `frozenset` “магически в разы быстрее”, а в том, что:

- он immutable

- его можно безопасно использовать в хэшируемых контекстах

- иногда это даёт архитектурное преимущество

> важная мысль
главное преимущество `frozenset` — не скорость как таковая, а возможность безопасно использовать множество как хэшируемый объект

---

## 22. `frozenset` и `hash()`

Поскольку `frozenset` хэшируем, мы можем явно вызвать `hash()`.

```Python
fs = frozenset([1, 2, 3])
print(hash(fs))
```

Вывод будет целым числом, например:

```Plain Text
-272375401224217160
```

Это ещё раз подтверждает, что `frozenset` можно использовать:

- как ключ словаря

- как элемент множества

- как часть составного ключа

---

## 23. Сравнение `frozenset` и `tuple`

Иногда возникает вопрос: если нужен хэшируемый объект, почему бы не использовать кортеж?

Ответ: зависит от смысла данных.

---

### Когда лучше `tuple`

Когда важен порядок:

```Python
("read", "write") != ("write", "read")
```

---

### Когда лучше `frozenset`

Когда важен именно набор:

```Python
frozenset(["read", "write"]) == frozenset(["write", "read"])
```

---

### Пример сравнения

```Python
print(("a", "b") == ("b", "a"))
print(frozenset(["a", "b"]) == frozenset(["b", "a"]))
```

Вывод:

```Plain Text
False
True
```

> важная мысль
`tuple` — это хэшируемая последовательность, а `frozenset` — хэшируемое множество

---

## 24. Итог

`frozenset` — это специальный тип данных для ситуаций, где нужна логика множества, но объект должен быть неизменяемым.

Он особенно полезен в трёх сценариях:

1. **ключи словарей**

2. **вложенные множества**

3. **представление набора признаков, где порядок не важен**

Если сказать совсем коротко:

> `frozenset` — это способ “заморозить множество”, чтобы его можно было безопасно использовать в хэш-таблицах и сложных структурах данных
