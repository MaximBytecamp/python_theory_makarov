> важная мысль
под списком в теории понимается **любая упорядоченная коллекция**, а не только `list` в Python

Когда мы сравниваем `set` и "список", мы на самом деле сравниваем:

```Plain Text

Неупорядоченная коллекция → set
```

## 2. Общие операции для коллекций

Множества поддерживают базовые операции, которые есть у большинства коллекций.

### 2.1 Длина коллекции

```Python
my_set = {1, 2, 3}
print(len(my_set))  # 3
```

---

### 2.2 Проверка наличия

```Python
users = {"alice", "bob"}

print("alice" in users)     # True
print("charlie" not in users)  # True
```

> важная мысль
в `set` операция `in` работает за **O(1)** благодаря хеш-таблице

---

### 2.3 Очистка множества

```Python
data = {1, 2, 3}
data.clear()
print(data)  # set()
```

---

### 2.4 Копирование

```Python
a = {1, 2, 3}
b = a.copy()

print(a is b)  # False
```

---

### 2.5 Итерация

```Python
data = {1, 2, 3}

for element in data:
    print(element)
```

или

```Python
iterator = iter(data)
print(next(iterator))
```

## 3. Метод add(element)

### 3.1 Назначение

Метод `add()` добавляет элемент в множество.

```Python
users = {"alice"}
users.add("bob")
```

---

### 3.2 Почему именно add, а не append

```Plain Text
list → append → добавление в конец
set  → add    → добавление без позиции
```

> важная мысль
в множестве нет "конца", поэтому append не имеет смысла

---

### 3.3 Поведение при дубликатах

```Python
data = {1, 2, 3}
data.add(3)

print(data)  # {1, 2, 3}
```

---

### 3.4 Ограничения: только immutable

```Python
my_set = set()

my_set.add((1, 2))   # OK
my_set.add([1, 2])   # Ошибка
```

Ошибка:

```Plain Text
TypeError: unhashable type: 'list'
```

---

### 3.5 Под капотом

```Plain Text
add(element):

1. hash(element)
2. поиск позиции в таблице
3. если пусто → вставка
4. если есть → игнор
```

---

### 3.6 Возвращаемое значение

```Python
result = my_set.add(10)
print(result)  # None
```

> важная мысль
методы изменения множества ничего не возвращают

---

### 3.7 Сложность

```Plain Text
add → O(1)
```

## 4. Метод remove(element)

### 4.1 Назначение

Удаляет элемент из множества.

```Python
data = {1, 2, 3}
data.remove(2)
```

---

### 4.2 Ошибка при отсутствии

```Python
data.remove(5)
```

Ошибка:

```Plain Text
KeyError
```

---

### 4.3 Отличие от списков

```Plain Text
list.remove(x) → ищет и удаляет (O(n))
set.remove(x)  → сразу удаляет (O(1))
```

---

### 4.4 Под капотом

```Plain Text
remove(element):

1. hash(element)
2. поиск ячейки
3. если найден → удаление
4. если нет → KeyError
```

---

## 5. Метод discard(element)

### 5.1 Назначение

Удаляет элемент, если он есть.

```Python
data = {1, 2, 3}
data.discard(2)
data.discard(5)  # нет ошибки
```

---

### 5.2 Ключевое отличие от remove

|Метод|Если элемента нет|
|-|-|
|remove|ошибка|
|discard|ничего|

---

### 5.3 Когда использовать

> важная мысль
discard используют, когда **не важно, есть элемент или нет**

---

### 5.4 Под капотом

```Plain Text
discard(element):

1. hash(element)
2. попытка найти
3. если найден → удалить
4. если нет → игнор
```

---

### 5.5 Возвращаемое значение

```Python
result = data.discard(1)
print(result)  # None
```

---

## 6. Метод pop()

### 6.1 Назначение

Удаляет и возвращает **произвольный элемент**

```Python
data = {10, 20, 30}
print(data.pop())
```

---

### 6.2 Почему "произвольный"

```Plain Text
set не имеет порядка → нельзя удалить "первый" или "последний"
```

---

### 6.3 Ошибка при пустом множестве

```Python
empty = set()
empty.pop()
```

Ошибка:

```Plain Text
KeyError
```

---

### 6.4 Применение

```Python
while data:
    element = data.pop()
    print(element)
```

---

### 6.5 Под капотом

```Plain Text
pop():

1. берётся первая доступная ячейка
2. элемент извлекается
3. удаляется из таблицы
```

---

## 7. Сравнение методов удаления

|Метод|Если элемента нет|Возвращает|
|-|-|-|
|remove|ошибка|None|
|discard|ничего|None|
|pop|ошибка (если пусто)|элемент|

---

## 8. Типичные ошибки

### Ошибка 1: ожидание порядка

```Python
data = {1, 2, 3}
print(data.pop())  # не предсказуемо
```

---

### Ошибка 2: использование remove без проверки

```Python
data.remove(x)  # может упасть
```

Лучше:

```Python
data.discard(x)
```

---

### Ошибка 3: попытка добавить list

```Python
my_set.add([1, 2])  # ошибка
```
