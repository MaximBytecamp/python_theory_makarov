## 1. Что такое кортеж

**Кортеж** (`tuple`) — это **упорядоченная неизменяемая последовательность элементов**.

Если совсем просто:

- список — это последовательность, которую можно менять

- кортеж — это последовательность, которую после создания менять нельзя

```Plain Text
list  → можно изменить
tuple → нельзя изменить
```

---

## 2. Основные свойства кортежей

---

### 2.1 Неизменяемость

После создания кортеж нельзя:

- изменить по индексу

- расширить

- удалить из него элемент

Пример:

```Python
t = (10, 20, 30)

print(t[1])
```

Вывод:

```Plain Text
20
```

Попытка изменить:

```Python
t[1] = 999
```

Вывод:

```Plain Text
TypeError: 'tuple' object does not support item assignment
```

> важная мысль
кортеж защищает структуру данных от случайного изменения

---

### 2.2 Упорядоченность

У элементов кортежа есть фиксированный порядок.

```Python
t = ("a", "b", "c")

print(t[0])
print(t[1])
print(t[2])
```

Вывод:

```Plain Text
a
b
c
```

То есть кортеж — это не “просто набор значений”, а именно **последовательность**, где важен порядок.

---

### 2.3 Разнородность

Кортеж может содержать элементы разных типов.

```Python
t = ("Max", 20, True, 4.5)

print(t)
```

Вывод:

```Plain Text
('Max', 20, True, 4.5)
```

Это удобно, когда нужно хранить логически связанную, но разнородную информацию.

---

### 2.4 Индексация и срезы

Кортежи поддерживают доступ по индексу и срезы, как списки.

```Python
t = ("a", "b", "c", "d")

print(t[0])
print(t[-1])
print(t[1:3])
```

Вывод:

```Plain Text
a
d
('b', 'c')
```

## 3. Создание кортежей

---

### 3.1 Через круглые скобки

```Python
t = (1, 2, 3)
print(t)
```

Вывод:

```Plain Text

```

---

### 3.2 Через `tuple()`

### 3.3 Пустой кортеж


## 4. Кортеж из одного элемента: важная особенность

Это один из самых частых источников путаницы.

```Python
t = (5)
print(t)
print(type(t))
```

Вывод:

```Plain Text
5
<class 'int'>
```

Это **не кортеж**, а просто число в скобках.

Чтобы создать кортеж из одного элемента, нужна запятая:

```Python
t = (5,)
print(t)
print(type(t))
```

Вывод:

```Plain Text
(5,)
<class 'tuple'>
```

> важная мысль
в singleton-кортеже ключевую роль играет не скобка, а запятая

## 8. Возврат нескольких значений из функции

## 9. Распаковка кортежей

Кортеж можно распаковать в несколько переменных.

```Python
t = ("Max", 20, "admin")

name, age, role = t

print(name)
print(age)
print(role)
```

Вывод:

```Plain Text
Max
20
admin
```

---

### Почему это удобно

Распаковка делает код:

- читаемым

- компактным

- естественным для Python

---

### Пример с функцией

```Python
def get_point():
    return 10, 20

x, y = get_point()

print(x)
print(y)
```

Вывод:

```Plain Text
10
20
```

> важная мысль
кортежи особенно сильны не сами по себе, а вместе с распаковкой

## 10. Сравнение кортежей

Кортежи, как и другие последовательности, сравниваются **лексикографически**.

Это значит:

1. сравниваются первые элементы

2. если они равны — вторые

3. если и они равны — третьи

4. и так далее

---

### Пример

```Python
print((1, 2, 3) < (1, 2, 4))
print((1, 5) > (1, 2, 100))
print((2, 0) > (1, 999))
```

Вывод:

```Plain Text
True
True
True
```

---

### Интуитивно

Это похоже на сравнение слов в словаре:

```Plain Text
("a", "b", "c") < ("a", "c", "a")
```

Потому что на втором различающемся элементе:

```Plain Text
"b" < "c"
```

## 11. Кортежи и словари: очень важная связь

Кортежи часто тесно связаны со словарями.

---

## 12. `dict.items()` и список кортежей

Метод `items()` возвращает пары:

```Plain Text
(ключ, значение)
```

### Пример

```Python
d = {"name": "Max", "role": "admin"}

print(list(d.items()))
```

Вывод:

```Plain Text
[('name', 'Max'), ('role', 'admin')]
```

Каждый элемент здесь — кортеж из двух значений.

---

## 13. Перебор словаря через кортежи

Это один из самых красивых и частых паттернов Python.

```Python
d = {"name": "Max", "role": "admin"}

for key, value in d.items():
    print(key, value)
```

Вывод:

```Plain Text
name Max
role admin
```

---

### Что здесь происходит

`d.items()` даёт кортежи:

```Plain Text
('name', 'Max')
('role', 'admin')
```

А `key, value` — это распаковка каждого кортежа.

---

> важная мысль
перебор словаря через `for key, value in d.items()` работает именно потому, что `items()` возвращает кортежи

---

## 14. Сортировка списка кортежей

Поскольку кортежи сравниваемы, список кортежей можно сортировать.

```Python
d = {"b": 2, "a": 1, "c": 3}

items_list = list(d.items())
print(items_list)

items_list.sort()
print(items_list)
```

Вывод:

```Plain Text
[('b', 2), ('a', 1), ('c', 3)]
[('a', 1), ('b', 2), ('c', 3)]
```

### Почему сортировка сработала

Потому что кортежи сравниваются по первому элементу, то есть по ключу.

---

## 15. Кортежи как ключи словаря

Это один из самых сильных практических кейсов.

Словарь требует, чтобы ключ был **хешируемым**.
Кортежи подходят для этого, если все их элементы тоже хешируемы.

### Пример

```Python
d = {
    (10, 20): "point A",
    (30, 40): "point B"
}

print(d[(10, 20)])
```

Вывод:

```Plain Text
point A
```

---

### Почему список нельзя, а кортеж можно

Список изменяемый:

```Python
# так нельзя
d = {[1, 2]: "value"}
```

Это вызовет ошибку:

```Plain Text
TypeError: unhashable type: 'list'
```

А кортеж неизменяемый, поэтому подходит как ключ.

---

## 16. Составные ключи

Кортежи особенно полезны для составных ключей.

Когда одного значения недостаточно, можно собрать несколько значений в один кортеж.

### Пример

```Python
sales = {
    ("2025", "January"): 100,
    ("2025", "February"): 150,
    ("2026", "January"): 200,
}

print(sales[("2025", "February")])
```

Вывод:

```Plain Text
150
```

---

### Где это полезно

- координаты `(x, y)`

- `(год, месяц)`

- `(страна, город)`

- `(user_id, course_id)`

- `(route, method)` в backend

---

## 17. Кортежи для группировки данных

Кортеж удобно использовать, когда нужно упаковать несколько связанных значений в одну структуру.

### Пример

```Python
student = ("Max", 20, [5, 4, 5])

print(student[0])
print(student[1])
print(student[2])
```

Вывод:

```Plain Text
Max
20
[5, 4, 5]
```

---

### Важное уточнение

Кортеж неизменяем, но если внутри него лежит изменяемый объект, сам этот объект можно менять.

```Python
t = (1, [2, 3], 4)

t[1].append(5)

print(t)
```

Вывод:

```Plain Text
(1, [2, 3, 5], 4)
```

### Почему так

Потому что:

- сам кортеж не изменился как структура

- но список внутри него изменился

> важная мысль
неизменяемость кортежа не делает автоматически неизменяемыми объекты, которые лежат внутри него

## 18. Почему и где используют кортежи

Теперь систематизируем реальные причины использования кортежей.

---

### 18.1 Неизменяемость данных

Когда данные не должны меняться, кортеж — хороший выбор.

Примеры:

- координаты

- RGB-цвета

- настройки

- фиксированные параметры

```Python
point = (50.1, 8.6)
color = (255, 100, 50)
```

---

### 18.2 Более структурированная запись

Кортеж позволяет собрать несколько значений в один логический блок.

```Python
user = ("Max", 20, "admin")
```

---

### 18.3 Возврат нескольких значений из функций

Это один из самых естественных сценариев использования в Python.

---

### 18.4 Ключи словарей

Кортежи часто используются в составных ключах.

---

### 18.5 Производительность и память

В общем случае кортежи легче и проще по модели, чем списки, потому что они неизменяемы.

Интуитивно:

```Plain Text
tuple → “готовая зафиксированная структура”
list  → “структура для изменений”
```

Из-за этого кортежи хорошо подходят там, где данные должны быть стабильны.

## 19. Универсальные функции для кортежей

Кортежи поддерживают многие функции, общие для других коллекций.

---

### `len()`

```Python
t = (10, 20, 30)
print(len(t))
```

Вывод:

```Plain Text
3
```

---

### `max()` и `min()`

```Python
t = (10, 20, 30)
print(max(t))
print(min(t))
```

Вывод:

```Plain Text
30
10
```

---

### `sum()`

```Python
t = (1, 2, 3, 4)
print(sum(t))
```

Вывод:

```Plain Text
10
```

---

### `sorted()`

`sorted()` возвращает список, а не кортеж.

```Python
t = (3, 1, 2)
print(sorted(t))
```

Вывод:

```Plain Text
[1, 2, 3]
```

---

### `all()` и `any()`

```Python
t = (1, 2, 0)

print(all(t))
print(any(t))
```

Вывод:

```Plain Text
False
True
```

---

### `enumerate()`

```Python
t = ("a", "b", "c")

for i, value in enumerate(t):
    print(i, value)
```

Вывод:

```Plain Text
0 a
1 b
2 c
```

---

### `zip()`

```Python
a = ("x", "y", "z")
b = (1, 2, 3)

print(list(zip(a, b)))
```

Вывод:

```Plain Text
[('x', 1), ('y', 2), ('z', 3)]
```

---

### `map()` и `filter()`

```Python
t = (1, 2, 3, 4)

print(list(map(lambda x: x * 10, t)))
print(list(filter(lambda x: x % 2 == 0, t)))
```

Вывод:

```Plain Text
[10, 20, 30, 40]
[2, 4]
```

---

### `reversed()`

```Python
t = (1, 2, 3)

print(tuple(reversed(t)))
```

Вывод:

```Plain Text
(3, 2, 1)
```

## 20. Методы, характерные для кортежей

У кортежей методов немного, потому что структура неизменяема.

Главные методы:

- `count()`

- `index()`

---

## 21. Метод `count()`

Считает количество вхождений элемента.

```Python
t = (1, 2, 1, 3, 1)

print(t.count(1))
print(t.count(2))
print(t.count(10))
```

Вывод:

```Plain Text
3
1
0
```

---

## 22. Метод `index()`

Возвращает индекс первого вхождения элемента.

```Python
t = ("a", "b", "c", "b")

print(t.index("b"))
```

Вывод:

```Plain Text
1
```

Если элемента нет:

```Python
print(t.index("x"))
```

Вывод:

```Plain Text
ValueError: tuple.index(x): x not in tuple
```

---

## 23. Типичные ошибки

### Ошибка 1. Путать кортеж с выражением в скобках

```Python
t = (5)
```

Это не кортеж.

---

### Ошибка 2. Пытаться изменить элемент кортежа

```Python
t[0] = 100
```

Так нельзя.

---

### Ошибка 3. Думать, что tuple полностью “замораживает” всё внутри

Если внутри лежит список, сам список всё ещё можно менять.

---

### Ошибка 4. Использовать список там, где нужен составной ключ словаря

Для составного ключа почти всегда лучше подходит кортеж.

---

## 24. Итог

Кортежи в Python — это простая, но очень важная структура данных.

Они нужны, когда важно:

- сохранить порядок

- зафиксировать структуру

- вернуть несколько значений

- использовать составной ключ

- группировать данные без лишней изменяемости

Если сказать совсем коротко:

> кортеж — это “лёгкая и стабильная упаковка данных”, особенно полезная в распаковке, словарях и функциях
