## 1. Что такое словарь

Словарь (`dict`) — это структура данных, которая хранит **пары ключ-значение**.

```Plain Text
ключ → значение
```

---

### Интуитивное объяснение

Представь:

- список — это просто последовательность элементов

- словарь — это “умная таблица”, где у каждого элемента есть имя

```Plain Text
список:
[10, 20, 30]

словарь:
"id"   → 10
"name" → "Max"
"role" → "admin"
```

---

> важная мысль
словарь — это отображение: ключ → значение

---

## 2. Отличие словаря от списка

|Свойство|Список|Словарь|
|-|-|-|
|Индексы|только числа|почти любые типы|
|Порядок|фиксированный|логически не важен|
|Доступ|по индексу|по ключу|
|Поиск|O(n)|O(1) в среднем|

---

## 3. Ключи и значения

---

### 3.1 Ключи

Ключи должны быть:

```Plain Text
immutable (неизменяемые)
```

Подходят:

- строки

- числа

- кортежи

Не подходят:

- списки

- словари

- множества

---

### 3.2 Значения

Значения могут быть **любыми объектами**:

```Python
data = {
    "name": "Max",
    "age": 20,
    "skills": ["python", "backend"],
    "meta": {"level": "middle"}
}
```

---

## 4. Создание словаря

---

### 4.1 Через литерал

```Python
user = {
    "name": "Max",
    "role": "admin"
}

print(user)
```

Вывод:

```Plain Text
{'name': 'Max', 'role': 'admin'}
```

---

### 4.2 Через `dict()`

```Python
user = dict(name="Max", role="admin")
print(user)
```

Вывод:

```Plain Text
{'name': 'Max', 'role': 'admin'}
```

---

### 4.3 Пустой словарь

```Python
empty = {}
print(empty)
```

Вывод:

```Plain Text
{}
```

---

## 5. Доступ к элементам

---

### 5.1 Через ключ

```Python
user = {"name": "Max", "role": "admin"}

print(user["name"])
```

Вывод:

```Plain Text
Max
```

---

### 5.2 Ошибка KeyError

```Python
print(user["age"])
```

Вывод:

```Plain Text
KeyError: 'age'
```

---

### 5.3 Безопасный доступ через `get()`

```Python
print(user.get("age"))
```

Вывод:

```Plain Text
None
```

---

### 5.4 Значение по умолчанию

```Python
print(user.get("age", 0))
```

Вывод:

```Plain Text
0
```

---

> важная мысль
`get()` — безопасный способ доступа к словарю

---

## 7. Удаление элементов

---

### 7.1 Через `del`

```Python
user = {"name": "Max", "role": "admin"}

del user["role"]
print(user)
```

Вывод:

```Plain Text
{'name': 'Max'}
```

---

### 7.2 Через `pop()`

```Python
user = {"name": "Max", "role": "admin"}

value = user.pop("role")

print(value)
print(user)
```

Вывод:

```Plain Text
admin
{'name': 'Max'}
```

---

### 7.3 Удаление последнего элемента (3.7+)

```Python
user = {"a": 1, "b": 2}

item = user.popitem()

print(item)
print(user)
```

Вывод:

```Plain Text
('b', 2)
{'a': 1}
```

---

## 8. Перебор словаря

---

### 8.1 Перебор ключей

```Python
user = {"name": "Max", "role": "admin"}

for key in user:
    print(key)
```

Вывод:

```Plain Text
name
role
```

---

### 8.2 Перебор значений

```Python
for value in user.values():
    print(value)
```

Вывод:

```Plain Text
Max
admin
```

---

### 8.3 Перебор пар

```Python
for key, value in user.items():
    print(key, value)
```

Вывод:

```Plain Text
name Max
role admin
```

## 11. Почему словарь быстрый

---

### Список

```Plain Text
поиск → перебор → O(n)
```

---

### Словарь

```Plain Text
поиск → hash → индекс → O(1)
```

---

### Схема

```Plain Text
ключ → hash(key) → индекс → значение
```

---

> важная мысль
словарь быстрый, потому что использует хэш-таблицу

---

## 12. Преобразования

---

### 12.1 Список кортежей → dict

```Python
pairs = [("a", 1), ("b", 2)]

d = dict(pairs)

print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 2}
```

---

### 12.2 Через zip

```Python
keys = ["a", "b"]
values = [1, 2]

d = dict(zip(keys, values))

print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 2}
```

---

### 12.3 Индексы как ключи

```Python
arr = ["a", "b", "c"]

d = dict(enumerate(arr))

print(d)
```

Вывод:

```Plain Text
{0: 'a', 1: 'b', 2: 'c'}
```

---

### 12.4 Множество → словарь

```Python
s = {"a", "b", "c"}

d = {x: i for i, x in enumerate(s)}

print(d)
```

Вывод (порядок может отличаться):

```Plain Text
{'b': 0, 'c': 1, 'a': 2}
```

## 13. Под капотом

---

### 13.1 Как работает словарь

```Plain Text
dict = хэш-таблица
```

---

### 13.2 Что происходит при доступе

```Plain Text
user["name"]

1. hash("name")
2. вычисляется индекс
3. переход к ячейке
4. возврат значения
```

---

### 13.3 Почему ключ должен быть immutable

Если ключ изменится:

```Plain Text
hash изменится → элемент потеряется
```

## 16. Мини-чеклист

- словарь = key → value

- ключи immutable

- значения любые

- доступ через ключ

- get() безопаснее

- in проверяет ключи

- работает через hash-table

- поиск → O(1) в среднем
