## 1. Что такое множество в Python

В Python **множество (`set`)** — это структура данных, представляющая собой **неупорядоченную коллекцию уникальных элементов**.

Интуитивно:

> множество — это как список гостей на мероприятии, где:

    - нельзя записать одного человека дважды

    - порядок не имеет значения

    - важно только наличие человека в списке

---

## 2. Основные свойства множества

### 2.1 Уникальность элементов

В множестве не может быть дубликатов.

```Python
numbers = {1, 2, 3, 3, 2, 1}
print(numbers)
```

Результат:

```Python
{1, 2, 3}
```

> важная мысль
множество автоматически удаляет дубликаты — это встроенное поведение

---

### 2.2 Неупорядоченность

Множество **не хранит порядок добавления элементов**.

```Python
data = {10, 5, 20}
print(data)
```

Результат может быть:

```Python
{20, 10, 5}
```

или

```Python
{5, 20, 10}
```

> важная мысль
порядок в множестве не гарантирован и может меняться между запусками

---

### 2.3 Изменяемость

Множество можно изменять:

```Python
users = {"alice", "bob"}

users.add("charlie")
users.remove("alice")

print(users)
```

---

## 3. Создание множества

### 3.1 Через фигурные скобки

```Python
my_set = {1, 2, 3}
```

### 3.2 Через функцию `set()`

```Python
my_set = set([1, 2, 3])
```

### 3.3 Пустое множество

```Python
empty_set = set()   # правильно
empty_dict = {}     # это словарь, не множество
```

> важная мысль
`{}` — это не set, а dict

---

## 4. Особенности работы с множествами

### 4.1 Нет индексации

```Python
my_set = {1, 2, 3}
print(my_set[0])
```

Ошибка:

```Plain Text
TypeError: 'set' object is not subscriptable
```

Почему:

> множество не хранит элементы по индексам — нет позиции, есть только факт наличия

---

### 4.2 Итерация по множеству

```Python
for item in {1, 2, 3}:
    print(item)
```

Порядок будет случайным.

---

## 5. Реальные кейсы использования

### 5.1 Удаление дубликатов

```Python
data = [1, 2, 2, 3, 3, 3]
unique = set(data)
```

---

### 5.2 Быстрая проверка наличия

```Python
blocked_users = {"user1", "user2"}

if user in blocked_users:
    deny_access()
```

---

### 5.3 Highload системы

Множества применяются:

- фильтрация запросов

- уникальные события (например, обработка Kafka сообщений)

- кеширование ключей

---

## 6. Почему нельзя хранить всё

В set можно хранить только **хешируемые объекты**:

```Python
my_set = {[1, 2]}  # ошибка
```

Почему:

- список изменяемый → его hash нестабилен

---

Правильно:

```Python
my_set = {(1, 2)}
```

---

> важная мысль
в set можно хранить только immutable объекты

---

Используй `set`, если:

- нужны уникальные значения

- важна скорость поиска

- порядок не важен

Не используй `set`, если:

- нужен порядок

- нужен доступ по индексу
