## 1. Введение: отличие от обычных операций

В предыдущей теме мы рассматривали:

```Plain Text
union / intersection / difference → создают новое множество
```

Теперь разберём их **изменяющие версии**:

```Plain Text
update / *_update → изменяют текущее множество
```

> важная мысль
если обычные методы — это "создать новое", то *_update — это "изменить текущее"

---

## 2. Метод `update()`

---

### 2.1 Что делает

Добавляет в текущее множество **все элементы из других коллекций**

---

### 2.2 Пример

```Python
a = {1, 2}
b = {2, 3}

a.update(b)

print(a)
```

Вывод:

```Plain Text
{1, 2, 3}
```

---

### 2.3 Схема

```Plain Text
A: {1, 2}
B: {2, 3}

A.update(B) → A = {1, 2, 3}
```

---

### 2.4 Работа с любыми итерируемыми

```Python
a = {1, 2}

a.update([3, 4], (5, 6), "78")

print(a)
```

Вывод:

```Plain Text
{1, 2, 3, 4, 5, 6, '7', '8'}
```

> важная мысль
строка разбивается на символы, так как это итерируемый объект

---

### 2.5 Дубликаты

```Python
a = {1, 2}
a.update([2, 3])

print(a)
```

Вывод:

```Plain Text
{1, 2, 3}
```

---

### 2.6 Возвращаемое значение

```Python
result = a.update([10])
print(result)
```

Вывод:

```Plain Text
None
```

---

### 2.7 Под капотом

```Plain Text
для каждого элемента:
    hash → проверка → вставка (если нет)
```

---

### 2.8 Сложность

```Plain Text
O(n) — по количеству добавляемых элементов
```

---

### 2.9 Backend-кейс

```Python
cache = {"u1", "u2"}
new_users = {"u2", "u3"}

cache.update(new_users)

print(cache)
```

Вывод:

```Plain Text
{'u1', 'u2', 'u3'}
```

---

## 3. Метод `difference_update()`

---

### 3.1 Что делает

Удаляет из текущего множества все элементы, которые есть в других коллекциях

---

### 3.2 Пример

```Python
a = {1, 2, 3, 4}
b = {2, 3}

a.difference_update(b)

print(a)
```

Вывод:

```Plain Text
{1, 4}
```

---

### 3.3 Схема

```Plain Text
A: {1, 2, 3, 4}
B: {2, 3}

A = A - B → {1, 4}
```

---

### 3.4 Работа с итерируемыми

```Python
a = {1, 2, 3}
a.difference_update([2])

print(a)
```

Вывод:

```Plain Text
{1, 3}
```

---

### 3.5 Возвращаемое значение

```Python
result = a.difference_update([1])
print(result)
```

Вывод:

```Plain Text
None
```

---

### 3.6 Под капотом

```Plain Text
для каждого элемента:
    hash → поиск → удаление
```

---

### 3.7 Backend-кейс

```Python
all_users = {"u1", "u2", "u3"}
blocked = {"u2"}

all_users.difference_update(blocked)

print(all_users)
```

Вывод:

```Plain Text
{'u1', 'u3'}
```

---

## 4. Метод `intersection_update()`

---

### 4.1 Что делает

Оставляет только те элементы, которые есть **во всех множествах**

---

### 4.2 Пример

```Python
a = {1, 2, 3}
b = {2, 3, 4}

a.intersection_update(b)

print(a)
```

Вывод:

```Plain Text
{2, 3}
```

---

### 4.3 Схема

```Plain Text
A: {1, 2, 3}
B: {2, 3, 4}

A = A ∩ B → {2, 3}
```

---

### 4.4 Несколько аргументов

```Python
a = {1, 2, 3}
a.intersection_update([2, 3], (2,))

print(a)
```

Вывод:

```Plain Text
{2}
```

---

### 4.5 Возвращаемое значение

```Python
result = a.intersection_update([2])
print(result)
```

Вывод:

```Plain Text
None
```

---

### 4.6 Под капотом

```Plain Text
проход по элементам:
    если нет во втором → удалить
```

---

### 4.7 Backend-кейс

```Python
active = {"u1", "u2", "u3"}
paid = {"u2", "u3"}

active.intersection_update(paid)

print(active)
```

Вывод:

```Plain Text
{'u2', 'u3'}
```

---

## 5. Метод `symmetric_difference_update()`

---

### 5.1 Что делает

Оставляет элементы, которые есть **только в одном из множеств**

---

### 5.2 Пример

```Python
a = {1, 2, 3}
b = {3, 4}

a.symmetric_difference_update(b)

print(a)
```

Вывод:

```Plain Text
{1, 2, 4}
```

---

### 5.3 Схема

```Plain Text
A: {1, 2, 3}
B: {3, 4}

A = (A ∪ B) - (A ∩ B)
→ {1, 2, 4}
```

---

### 5.4 Важное ограничение

```Plain Text
принимает только одно множество
```

---

### 5.5 Возвращаемое значение

```Python
result = a.symmetric_difference_update({1})
print(result)
```

Вывод:

```Plain Text
None
```

---

### 5.6 Под капотом

```Plain Text
если элемент есть в обоих → удалить
если только в одном → оставить
```

---

### 5.7 Backend-кейс

```Python
old = {"a", "b", "c"}
new = {"b", "c", "d"}

old.symmetric_difference_update(new)

print(old)
```

Вывод:

```Plain Text
{'a', 'd'}
```

---

## 6. Сравнение всех update-методов

|Метод|Что делает|
|-|-|
|update|объединяет|
|difference_update|вычитает|
|intersection_update|оставляет общее|
|symmetric_difference_update|оставляет различия|

---

## 7. Под капотом

Все методы работают через:

```Plain Text
элемент → hash → операция (добавить / удалить / проверить)
```

---

> важная мысль
отличие только в логике обработки элементов, но не в механике
