## 1. Введение

Словарь в Python — это структура данных вида:

```Plain Text
ключ → значение
```

Когда словарь уже создан, дальше обычно нужно делать одно из нескольких действий:

- получить все ключи

- получить все значения

- удалить элемент

- удалить последнюю добавленную пару

- безопасно добавить ключ, если его ещё нет

- обновить словарь новыми данными

Именно для этого используются методы:

- `keys()`

- `values()`

- `pop()`

- `popitem()`

- `setdefault()`

- `update()`

> важная мысль
эти методы нужны не для “теории ради теории”, а для реальной повседневной работы с данными

---

# 2. Метод `keys()`

## 2.1 Что делает

Метод `keys()` возвращает представление всех ключей словаря.

Это не копия и не обычный список, а специальный объект:

```Plain Text
dict_keys(...)
```

---

## 2.2 Пример получения ключей

```Python
d = {"name": "Max", "role": "admin", "age": 20}

print(d.keys())
```

Вывод:

```Plain Text
dict_keys(['name', 'role', 'age'])
```

---

## 2.3 Что значит “представление”

Когда мы говорим, что `keys()` возвращает представление, имеется в виду:

- данные не копируются

- объект связан с исходным словарём

- изменения словаря отражаются автоматически

---

## 2.4 “Живое” представление

```Python
d = {"a": 1, "b": 2}

view = d.keys()
print(view)

d["c"] = 3
print(view)
```

Вывод:

```Plain Text
dict_keys(['a', 'b'])
dict_keys(['a', 'b', 'c'])
```

### Что здесь важно

Объект `view` не “замер” в момент создания. Он показывает текущее состояние словаря.

> важная мысль
`keys()` возвращает “живой” объект, который динамически отражает изменения словаря

---

## 2.5 Итерация по ключам

```Python
d = {"name": "Max", "role": "admin", "age": 20}

for key in d.keys():
    print(key)
```

Вывод:

```Plain Text
name
role
age
```

---

## 2.6 Можно ли итерироваться без `keys()`

Да. Это один из важных практических моментов.

Эти два варианта эквивалентны по смыслу:

```Python
for key in d:
    print(key)
```

```Python
for key in d.keys():
    print(key)
```

То есть словарь по умолчанию итерируется именно по ключам.

---

## 2.7 Использование `keys()` в условии

```Python
d = {"name": "Max", "role": "admin"}

print("name" in d.keys())
print("age" in d.keys())
```

Вывод:

```Plain Text
True
False
```

Но на практике чаще пишут так:

```Python
print("name" in d)
print("age" in d)
```

Вывод будет тем же:

```Plain Text
True
False
```

### Почему так лучше

Потому что запись:

```Python
"key" in d
```

короче и естественнее.

---

## 2.8 Преобразование в список

Иногда представление ключей нужно превратить в список.

```Python
d = {"name": "Max", "role": "admin", "age": 20}

keys_list = list(d.keys())
print(keys_list)
```

Вывод:

```Plain Text
['name', 'role', 'age']
```

### Когда это нужно

Например, если:

- нужен индексируемый объект

- нужно передать ключи куда-то как список

- требуется дальнейшая работа именно со списком

---

## 2.9 Вывод по `keys()`

> `keys()` нужен, когда мы хотим явно работать с набором ключей словаря, помнить про “живое” представление и при необходимости преобразовать его в список

# 3. Метод `pop(key[, default])`

## 3.1 Что делает

Метод `pop()`:

1. удаляет ключ из словаря

2. возвращает значение, которое было связано с этим ключом

---

## 3.2 Пример удаления существующего ключа

```Python
d = {"name": "Max", "role": "admin"}

value = d.pop("role")

print(value)
print(d)
```

Вывод:

```Plain Text
admin
{'name': 'Max'}
```

---

## 3.3 Почему это удобно

Метод `pop()` полезен, когда нужно не просто удалить элемент, а ещё и обработать его значение.

Например:

```Python
d = {"token": "abc123", "user": "Max"}

token = d.pop("token")
print("Удалённый токен:", token)
print(d)
```

Вывод:

```Plain Text
Удалённый токен: abc123
{'user': 'Max'}
```

---

## 3.4 Если ключа нет

Если ключ отсутствует и значение по умолчанию не указано, возникает ошибка:

```Python
d = {"a": 1}

print(d.pop("b"))
```

Вывод:

```Plain Text
KeyError: 'b'
```

---

## 3.5 Безопасное удаление с `default`

```Python
d = {"a": 1}

value = d.pop("b", 0)

print(value)
print(d)
```

Вывод:

```Plain Text
0
{'a': 1}
```

### Что произошло

- ключ `"b"` не найден

- вместо ошибки возвращено значение по умолчанию `0`

---

## 3.6 Когда `pop()` особенно полезен

Он удобен в сценариях:

- забрать и удалить параметр

- вынуть временное поле из словаря

- обработать данные и очистить словарь

- реализовать пошаговый разбор структуры

---

## 3.7 Сравнение `del` и `pop()`

### `del`

```Python
d = {"a": 1}
del d["a"]
```

- удаляет

- ничего не возвращает

### `pop()`

```Python
d = {"a": 1}
value = d.pop("a")
```

- удаляет

- возвращает значение

> важная мысль
`pop()` — это “удалить и сразу получить”, а `del` — просто “удалить”

---

## 3.8 Вывод по `pop()`

> `pop()` — один из самых удобных методов словаря, когда удаление связано с последующей обработкой значения

---

# 4. Метод `popitem()`

## 4.1 Что делает

Метод `popitem()` удаляет и возвращает **последнюю добавленную пару** `(key, value)`.

Это важно для современных версий Python, где словарь сохраняет порядок вставки.

---

## 4.2 Пример

```Python
d = {"a": 1, "b": 2, "c": 3}

item = d.popitem()

print(item)
print(d)
```

Вывод:

```Plain Text
('c', 3)
{'a': 1, 'b': 2}
```

---

## 4.3 Что именно возвращается

Возвращается кортеж:

```Plain Text
(key, value)
```

Поэтому можно сразу распаковать результат:

```Python
d = {"a": 1, "b": 2}

key, value = d.popitem()

print(key)
print(value)
print(d)
```

Вывод:

```Plain Text
b
2
{'a': 1}
```

---

## 4.4 Если словарь пуст

```Python
d = {}
print(d.popitem())
```

Вывод:

```Plain Text
KeyError: 'popitem(): dictionary is empty'
```

---

## 4.5 Где `popitem()` применяется

Этот метод полезен, когда нужно:

- обрабатывать словарь по одному элементу

- “разбирать” словарь до пустоты

- работать с последними вставленными элементами

### Пример

```Python
d = {"a": 1, "b": 2, "c": 3}

while d:
    print(d.popitem())
```

Вывод:

```Plain Text
('c', 3)
('b', 2)
('a', 1)
```

---

## 4.6 Вывод по `popitem()`

> `popitem()` — это способ извлекать пары из словаря по одной, начиная с последней добавленной

---

# 5. Метод `setdefault(key[, default])`

## 5.1 Что делает

Метод `setdefault()` работает так:

- если ключ уже есть — возвращает его значение

- если ключа нет — добавляет его со значением `default` и возвращает это значение

---

## 5.2 Пример: ключ уже существует

```Python
d = {"a": 10}

value = d.setdefault("a", 0)

print(value)
print(d)
```

Вывод:

```Plain Text
10
{'a': 10}
```

### Что произошло

Ключ `"a"` уже был в словаре, поэтому:

- словарь не изменился

- вернулось старое значение `10`

---

## 5.3 Пример: ключ отсутствует

```Python
d = {"a": 10}

value = d.setdefault("b", 0)

print(value)
print(d)
```

Вывод:

```Plain Text
0
{'a': 10, 'b': 0}
```

---

## 5.4 Пример без указания `default`

```Python
d = {}

value = d.setdefault("name")

print(value)
print(d)
```

Вывод:

```Plain Text
None
{'name': None}
```

---

## 5.5 Зачем это нужно

`setdefault()` полезен, когда нужно:

- проверить наличие ключа

- и если ключа нет — сразу создать его

То есть он объединяет две операции в одну.

---

## 5.6 Классический пример: группировка

```Python
data = [
    ("admin", "Max"),
    ("user", "Anna"),
    ("admin", "Ivan"),
]

groups = {}

for role, name in data:
    groups.setdefault(role, []).append(name)

print(groups)
```

Вывод:

```Plain Text
{'admin': ['Max', 'Ivan'], 'user': ['Anna']}
```

---

## 5.7 Что здесь происходит

Для каждой роли:

- если ключ уже есть — берётся существующий список

- если нет — создаётся новый пустой список

- затем в этот список добавляется имя

---

## 5.8 Почему это удобно

Без `setdefault()` пришлось бы писать больше кода:

```Python
groups = {}

for role, name in data:
    if role not in groups:
        groups[role] = []
    groups[role].append(name)
```

Оба варианта корректны, но `setdefault()` делает запись компактнее.

---

## 5.9 Осторожно с пониманием

`setdefault()` не просто “читает” значение.
Он **может изменить словарь**, если ключа не было.

Это важное отличие от `get()`.

### `get()`

```Python
d.get("x", [])
```

- не меняет словарь

### `setdefault()`

```Python
d.setdefault("x", [])
```

- может создать новый ключ в словаре

> важная мысль
`get()` безопасно читает, а `setdefault()` может создавать ключ

---

## 5.10 Вывод по `setdefault()`

> `setdefault()` особенно полезен для группировки, накопления и инициализации вложенных структур

---

# 6. Метод `update([other])`

## 6.1 Что делает

Метод `update()` обновляет словарь, добавляя пары ключ-значение из другого источника.

Если ключ уже существует, его значение будет перезаписано.

---

## 6.2 Обновление словарём

```Python
d = {"a": 1, "b": 2}
other = {"b": 20, "c": 30}

d.update(other)

print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 20, 'c': 30}
```

### Что произошло

- ключ `"b"` уже был → значение обновилось

- ключ `"c"` отсутствовал → добавился

---

## 6.3 Обновление итерируемым объектом пар

```Python
d = {"a": 1}

d.update([("b", 2), ("c", 3)])

print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 2, 'c': 3}
```

---

## 6.4 Обновление через именованные аргументы

```Python
d = {"a": 1}

d.update(b=2, c=3)

print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 2, 'c': 3}
```

---

## 6.5 Что возвращает `update()`

Ничего полезного не возвращает.
Точнее, возвращает `None`.

```Python
d = {"a": 1}

result = d.update({"b": 2})

print(result)
print(d)
```

Вывод:

```Plain Text
None
{'a': 1, 'b': 2}
```

---

## 6.6 Почему это важно

Иногда начинающие ожидают, что `update()` создаст новый словарь. Но это не так.

Он изменяет словарь **на месте**.

---

## 6.7 Где `update()` полезен

- объединение конфигураций

- наложение параметров

- обновление данных пользователя

- сборка итогового словаря из нескольких источников

### Пример

```Python
base = {"host": "localhost", "port": 8000}
override = {"port": 9000}

base.update(override)

print(base)
```

Вывод:

```Plain Text
{'host': 'localhost', 'port': 9000}
```

---

## 6.8 Вывод по `update()`

> `update()` — это удобный способ объединить данные, но важно помнить: он изменяет исходный словарь

---

# 7. Метод `values()`

## 7.1 Что делает

Метод `values()` возвращает представление всех значений словаря.

Результат имеет вид:

```Plain Text
dict_values(...)
```

---

## 7.2 Пример

```Python
d = {"name": "Max", "role": "admin", "age": 20}

print(d.values())
```

Вывод:

```Plain Text
dict_values(['Max', 'admin', 20])
```

---

## 7.3 Итерация по значениям

```Python
d = {"name": "Max", "role": "admin", "age": 20}

for value in d.values():
    print(value)
```

Вывод:

```Plain Text
Max
admin
20
```

---

## 7.4 Преобразование в список

```Python
d = {"a": 1, "b": 2, "c": 3}

values_list = list(d.values())
print(values_list)
```

Вывод:

```Plain Text
[1, 2, 3]
```

---

## 7.5 “Живое” представление

Как и `keys()` и `items()`, метод `values()` возвращает “живой” объект.

```Python
d = {"a": 1}
view = d.values()

print(view)

d["b"] = 2

print(view)
```

Вывод:

```Plain Text
dict_values([1])
dict_values([1, 2])
```

---

## 7.6 Где `values()` часто используется

### Сумма значений

```Python
d = {"a": 10, "b": 20, "c": 30}

print(sum(d.values()))
```

Вывод:

```Plain Text
60
```

### Проверка логических значений

```Python
flags = {"x": True, "y": True, "z": False}

print(all(flags.values()))
print(any(flags.values()))
```

Вывод:

```Plain Text
False
True
```

---

## 7.7 Важное замечание

В отличие от ключей, значения словаря не обязаны быть уникальными.

```Python
d = {"a": 1, "b": 1, "c": 1}
print(list(d.values()))
```

Вывод:

```Plain Text
[1, 1, 1]
```

То есть `values()` — это не множество значений, а именно представление текущих значений, в котором дубликаты сохраняются.

---

## 7.8 Вывод по `values()`

> `values()` удобно использовать для анализа данных словаря, когда сами ключи уже не важны

---

# 8. Связь между `keys()`, `values()` и `items()`

Очень полезно видеть эти методы как три разных “окна” в один и тот же словарь.

```Plain Text
keys()   → только ключи
values() → только значения
items()  → пары (ключ, значение)
```

### Пример

```Python
d = {"name": "Max", "role": "admin"}

print(d.keys())
print(d.values())
print(d.items())
```

Вывод:

```Plain Text
dict_keys(['name', 'role'])
dict_values(['Max', 'admin'])
dict_items([('name', 'Max'), ('role', 'admin')])
```

---

# 9. Типичные ошибки

## Ошибка 1. Считать `keys()` и `values()` обычными списками

Нет. Это специальные view-объекты.

---

## Ошибка 2. Забывать, что `pop()` может вызвать `KeyError`

Если ключа нет и `default` не указан, будет ошибка.

---

## Ошибка 3. Путать `get()` и `setdefault()`

- `get()` не меняет словарь

- `setdefault()` может добавить ключ

---

## Ошибка 4. Ожидать, что `update()` возвращает новый словарь

Нет. Он изменяет текущий словарь на месте.

---

## Ошибка 5. Не понимать смысл `popitem()`

Этот метод работает не “случайно”, а с последней добавленной парой.

---

# 10. Итог

Методы `keys()`, `pop()`, `popitem()`, `setdefault()`, `update()` и `values()` закрывают почти все базовые сценарии работы со словарями:

- просмотр структуры

- безопасное удаление

- поэтапная обработка

- инициализация

- объединение данных

- работа со значениями

Если сформулировать кратко:

> `keys()` и `values()` помогают смотреть на словарь с разных сторон, `pop()` и `popitem()` — удалять данные, `setdefault()` — удобно инициализировать, а `update()` — объединять и обновлять словари
