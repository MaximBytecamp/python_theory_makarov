## 1. Введение

Когда студенты впервые видят словарь, часто кажется, что это “особая структура”, к которой подходят только специальные методы вроде `get()`, `items()`, `keys()` и `values()`.

На практике это не совсем так.

Словарь в Python — это **коллекция**, а значит, с ним можно использовать многие общие функции, которые работают и с другими итерируемыми объектами:

- списками

- кортежами

- множествами

- строками

- словарями

Но есть важная особенность:

> важная мысль
когда универсальная функция применяется к словарю напрямую, она обычно работает **по ключам**, а не по значениям

Это фундаментальный момент. Именно из-за него поведение `len(d)`, `max(d)`, `sorted(d)` и `enumerate(d)` может отличаться от того, что ожидает начинающий программист.

## 2. Универсальные функции для словаря и других коллекций

Ниже разберём функции, которые можно использовать со словарями и другими коллекциями.

## 3. `len()` — количество элементов

Функция `len()` возвращает размер коллекции.

Для словаря это **количество пар ключ-значение**, то есть количество ключей.

### Пример

```Python
d = {"a": 10, "b": 20, "c": 30}

print(len(d))
```

Вывод:

```Plain Text
3
```

### Что здесь происходит

В словаре три ключа:

```Plain Text
"a", "b", "c"
```

Поэтому длина словаря равна 3.

### Сравнение с другими коллекциями

```Python
print(len([1, 2, 3]))       # список
print(len((1, 2, 3)))       # кортеж
print(len({1, 2, 3}))       # множество
print(len("abc"))           # строка
```

Вывод:

```Plain Text
3
3
3
3
```

### Вывод по разделу

> `len()` — одна из самых универсальных функций в Python. Для словаря она считает число ключей.

---

## 4. `max()` и `min()`

Функции `max()` и `min()` ищут максимальный и минимальный элемент коллекции.

Если передать в них словарь напрямую, они будут работать **по ключам**.

### Пример

```Python
d = {"b": 2, "a": 1, "c": 3}

print(max(d))
print(min(d))
```

Вывод:

```Plain Text
c
a
```

### Почему именно так

Потому что Python сравнивает ключи:

```Plain Text
"a", "b", "c"
```

а не значения `1`, `2`, `3`.

### Если нужен максимум по значениям

```Python
d = {"b": 2, "a": 1, "c": 3}

print(max(d.values()))
print(min(d.values()))
```

Вывод:

```Plain Text
3
1
```

### Если нужен ключ с максимальным значением

```Python
d = {"b": 2, "a": 1, "c": 3}

key = max(d, key=d.get)
print(key)
print(d[key])
```

Вывод:

```Plain Text
c
3
```

### Что здесь важно понять

```Python
max(d, key=d.get)
```

означает:

- перебирай ключи словаря

- сравнивай их не по самим ключам

- а по значениям `d[key]`

### Вывод по разделу

> `max(d)` и `min(d)` работают по ключам. Если нужны значения, нужно явно использовать `values()` или параметр `key=`.

---

## 5. `sum()`

Функция `sum()` складывает элементы коллекции.

Если применить её к словарю напрямую, Python попытается сложить **ключи**.

### Пример

```Python
d = {1: "a", 2: "b", 3: "c"}

print(sum(d))
```

Вывод:

```Plain Text
6
```

Потому что суммируются ключи:

```Plain Text
1 + 2 + 3 = 6
```

### Более частый практический случай

Обычно суммируют значения:

```Python
d = {"a": 10, "b": 20, "c": 30}

print(sum(d.values()))
```

Вывод:

```Plain Text
60
```

### Важное ограничение

Если значения не числа, `sum()` работать не будет.

```Python
d = {"a": "x", "b": "y"}
print(sum(d.values()))
```

Это вызовет ошибку.

### Вывод по разделу

> `sum()` полезна для словарей, когда значения числовые. Обычно используется как `sum(d.values())`.

---

## 6. `sorted()`

Функция `sorted()` возвращает новый отсортированный список.

Если передать словарь напрямую, сортировка выполняется **по ключам**.

### Пример

```Python
d = {"b": 2, "c": 3, "a": 1}

print(sorted(d))
```

Вывод:

```Plain Text
['a', 'b', 'c']
```

### Если нужны пары ключ-значение

```Python
d = {"b": 2, "c": 3, "a": 1}

print(sorted(d.items()))
```

Вывод:

```Plain Text
[('a', 1), ('b', 2), ('c', 3)]
```

### Сортировка по значениям

```Python
d = {"b": 2, "c": 3, "a": 1}

result = sorted(d.items(), key=lambda item: item[1])
print(result)
```

Вывод:

```Plain Text
[('a', 1), ('b', 2), ('c', 3)]
```

### Что означает `item[1]`

Каждый элемент `d.items()` — это кортеж:

```Plain Text
(ключ, значение)
```

Значит:

- `item[0]` — ключ

- `item[1]` — значение

### Вывод по разделу

> `sorted()` со словарём напрямую сортирует ключи. Для сортировки по значениям почти всегда используют `d.items()`.

---

## 7. `all()` и `any()`

Эти функции работают с логической истинностью элементов.

### `all()`

Возвращает `True`, если **все** элементы истинны.

### `any()`

Возвращает `True`, если **хотя бы один** элемент истинен.

---

### Пример со значениями словаря

```Python
d = {"a": 1, "b": 0, "c": 5}

print(all(d.values()))
print(any(d.values()))
```

Вывод:

```Plain Text
False
True
```

### Почему

- `all(...)` возвращает `False`, потому что `0` считается ложью

- `any(...)` возвращает `True`, потому что есть `1` и `5`

### Ещё пример

```Python
d = {"x": 0, "y": 0}

print(all(d.values()))
print(any(d.values()))
```

Вывод:

```Plain Text
False
False
```

### Вывод по разделу

> `all()` и `any()` особенно полезны, когда словарь хранит флаги, проверки или числовые статусы.

---

## 8. `enumerate()`

Функция `enumerate()` добавляет счётчик к итерируемому объекту.

Если применить её к словарю напрямую, она будет перебирать **ключи**.

### Пример

```Python
d = {"a": 10, "b": 20, "c": 30}

for index, key in enumerate(d):
    print(index, key)
```

Вывод:

```Plain Text
0 a
1 b
2 c
```

### Если нужны пары ключ-значение

```Python
d = {"a": 10, "b": 20, "c": 30}

for index, item in enumerate(d.items()):
    print(index, item)
```

Вывод:

```Plain Text
0 ('a', 10)
1 ('b', 20)
2 ('c', 30)
```

### Вывод по разделу

> `enumerate(d)` работает по ключам. Для более содержательного перебора обычно используют `enumerate(d.items())`.

---

## 9. `zip()`

Функция `zip()` объединяет несколько итерируемых объектов по позициям.

Это особенно полезно для создания словаря.

### Пример: два списка → словарь

```Python
keys = ["name", "role", "age"]
values = ["Max", "admin", 20]

d = dict(zip(keys, values))
print(d)
```

Вывод:

```Plain Text
{'name': 'Max', 'role': 'admin', 'age': 20}
```

### Что здесь происходит

```Plain Text
"name" → "Max"
"role" → "admin"
"age"  → 20
```

### Вывод по разделу

> `zip()` — один из самых удобных способов создать словарь из двух последовательностей.

---

## 10. `map()` и `filter()`

Эти функции часто используют с `keys()`, `values()` и `items()`.

---

### `map()`

Применяет функцию к каждому элементу.

```Python
d = {"a": 1, "b": 2, "c": 3}

result = list(map(lambda x: x * 10, d.values()))
print(result)
```

Вывод:

```Plain Text
[10, 20, 30]
```

---

### `filter()`

Оставляет только те элементы, для которых условие истинно.

```Python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

result = list(filter(lambda x: x % 2 == 0, d.values()))
print(result)
```

Вывод:

```Plain Text
[2, 4]
```

### Более полезный пример — фильтрация пар

```Python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

result = dict(filter(lambda item: item[1] % 2 == 0, d.items()))
print(result)
```

Вывод:

```Plain Text
{'b': 2, 'd': 4}
```

### Вывод по разделу

> `map()` и `filter()` редко применяют к словарю напрямую. Обычно работают через `values()` или `items()`.

---

## 11. `reversed()`

Функция `reversed()` переворачивает порядок обхода.

Для словарей её обычно применяют после преобразования в список.

### Пример

```Python
d = {"a": 1, "b": 2, "c": 3}

print(list(reversed(list(d))))
```

Вывод:

```Plain Text
['c', 'b', 'a']
```

### Более осмысленный вариант

```Python
d = {"a": 1, "b": 2, "c": 3}

print(list(reversed(list(d.items()))))
```

Вывод:

```Plain Text
[('c', 3), ('b', 2), ('a', 1)]
```

### Вывод по разделу

> `reversed()` со словарём обычно используют не напрямую, а через `list(d)` или `list(d.items())`.

---

## 12. Про `count` и `pop`

Здесь важно аккуратно различать **функции**, **методы** и **типы коллекций**.

### `count`

Метод `count()` есть у:

- строк

- списков

- кортежей

Но у обычного словаря метода `count()` **нет**.

```Python
data = [1, 2, 1, 1]
print(data.count(1))
```

Вывод:

```Plain Text
3
```

Для словаря вместо `count()` часто используют `get()` и ручной подсчёт.

---

### `pop`

Метод `pop()` есть у многих коллекций, но работает по-разному.

- у списка `pop()` удаляет элемент по индексу

- у словаря `pop()` удаляет элемент по ключу

Пример со словарём:

```Python
d = {"a": 10, "b": 20}

value = d.pop("a")
print(value)
print(d)
```

Вывод:

```Plain Text
10
{'b': 20}
```

> важная мысль
одинаковое имя метода в разных коллекциях не означает полностью одинаковое поведение

## 13. `fromkeys(seq[, value])`

### 13.1 Что делает

Метод `fromkeys()` создаёт **новый словарь**:

- ключи берутся из `seq`

- значения у всех ключей одинаковые

### Общая схема

```Plain Text
последовательность ключей → новый словарь
```

---

### 13.2 Пример с `None`

```Python
keys = ["a", "b", "c"]

d = dict.fromkeys(keys)
print(d)
```

Вывод:

```Plain Text
{'a': None, 'b': None, 'c': None}
```

---

### 13.3 Пример с заданным значением

```Python
d = dict.fromkeys(["x", "y", "z"], 0)
print(d)
```

Вывод:

```Plain Text
{'x': 0, 'y': 0, 'z': 0}
```

---

### 13.4 Использование кортежа

```Python
d = dict.fromkeys(("name", "role"), "unknown")
print(d)
```

Вывод:

```Plain Text
{'name': 'unknown', 'role': 'unknown'}
```

---

### 13.5 Использование строки

```Python
d = dict.fromkeys("abc", 1)
print(d)
```

Вывод:

```Plain Text
{'a': 1, 'b': 1, 'c': 1}
```

### Что здесь происходит

Строка — это итерируемый объект, поэтому Python берёт её посимвольно:

```Plain Text
"a", "b", "c"
```

---

### 13.6 Очень важная ловушка: изменяемое значение

```Python
d = dict.fromkeys(["a", "b", "c"], [])

d["a"].append(100)

print(d)
```

Вывод:

```Plain Text
{'a': [100], 'b': [100], 'c': [100]}
```

### Почему так произошло

Потому что всем ключам был выдан **один и тот же список**, а не отдельная копия списка для каждого ключа.

Схема:

```Plain Text
"a" ─┐
"b" ─┼→ один и тот же объект []
"c" ─┘
```

---

### 13.7 Когда `fromkeys()` действительно удобен

Он хорошо подходит, когда нужно быстро создать словарь:

- с фиксированным набором ключей

- с одинаковыми простыми значениями

- для инициализации конфигурации или флагов

### Вывод по разделу

> `fromkeys()` удобен, но с изменяемыми объектами нужно быть очень осторожным

---

## 14. `get(key[, default])`

### 14.1 Что делает

Возвращает значение по ключу, если ключ существует.
Если ключа нет, возвращает `default`.

Если `default` не указан, возвращается `None`.

---

### 14.2 Пример с существующим ключом

```Python
d = {"a": 10, "b": 20}

print(d.get("a"))
```

Вывод:

```Plain Text
10
```

---

### 14.3 Пример с отсутствующим ключом

```Python
d = {"a": 10, "b": 20}

print(d.get("c"))
```

Вывод:

```Plain Text
None
```

---

### 14.4 Пример со значением по умолчанию

```Python
d = {"a": 10, "b": 20}

print(d.get("c", 0))
```

Вывод:

```Plain Text
0
```

---

### 14.5 Чем `get()` лучше, чем `[]`

Если написать так:

```Python
d = {"a": 10}
print(d["b"])
```

получим ошибку:

```Plain Text
KeyError: 'b'
```

А `get()` работает безопасно:

```Python
d = {"a": 10}
print(d.get("b"))
```

Вывод:

```Plain Text
None
```

---

### 14.6 Классический паттерн подсчёта

```Python
text = "banana"
counter = {}

for ch in text:
    counter[ch] = counter.get(ch, 0) + 1

print(counter)
```

Вывод:

```Plain Text
{'b': 1, 'a': 3, 'n': 2}
```

### Что здесь происходит

Для каждой буквы:

- если ключ уже есть — берётся текущее значение

- если нет — берётся `0`

- затем прибавляется `1`

---

### 14.7 Почему этот приём так важен

Это один из самых часто встречающихся шаблонов в Python:

- подсчёт частот

- агрегация событий

- сбор статистики

- построение словарей по данным

### Вывод по разделу

> `get()` — безопасный доступ к словарю и один из главных инструментов для подсчёта и агрегации

## 15. `items()`

### 15.1 Что делает

Метод `items()` возвращает представление всех пар:

```Plain Text
(ключ, значение)
```

---

### 15.2 Пример

```Python
d = {"name": "Max", "role": "admin"}

print(d.items())
```

Вывод:

```Plain Text
dict_items([('name', 'Max'), ('role', 'admin')])
```

---

### 15.3 Перебор в цикле

```Python
d = {"name": "Max", "role": "admin"}

for key, value in d.items():
    print(key, value)
```

Вывод:

```Plain Text
name Max
role admin
```

---

### 15.4 Преобразование в список

```Python
d = {"a": 1, "b": 2}

result = list(d.items())
print(result)
```

Вывод:

```Plain Text
[('a', 1), ('b', 2)]
```

---

### 15.5 Использование `items()` для создания нового словаря

```Python
d = {"a": 1, "b": 2, "c": 3}

result = {k: v * 10 for k, v in d.items()}
print(result)
```

Вывод:

```Plain Text
{'a': 10, 'b': 20, 'c': 30}
```

---

## 16. “Живое” представление (`view`)

Это один из самых важных моментов.

Метод `items()` возвращает не список-копию, а **представление**.

Это значит:

- данные не копируются

- объект связан с исходным словарём

- изменения словаря сразу видны в представлении

---

### Пример

```Python
d = {"a": 1}
view = d.items()

print(view)

d["b"] = 2

print(view)
```

Вывод:

```Plain Text
dict_items([('a', 1)])
dict_items([('a', 1), ('b', 2)])
```

### Почему это называется “живым”

Потому что представление показывает **текущее состояние** словаря, а не снимок на момент вызова.

---

### Это относится не только к `items()`

То же самое верно для:

- `keys()`

- `values()`

### Вывод по разделу

> `items()` возвращает “живое” представление словаря, а не отдельную копию данных

---

## 17. Где `items()` особенно полезен

### 17.1 Перебор словаря

```Python
for k, v in d.items():
    ...
```

Это самый естественный способ работать сразу и с ключами, и со значениями.

---

### 17.2 Сортировка по значениям

```Python
d = {"a": 3, "b": 1, "c": 2}

result = sorted(d.items(), key=lambda item: item[1])
print(result)
```

Вывод:

```Plain Text
[('b', 1), ('c', 2), ('a', 3)]
```

---

### 17.3 Фильтрация

```Python
d = {"a": 3, "b": 1, "c": 2}

result = dict(filter(lambda item: item[1] >= 2, d.items()))
print(result)
```

Вывод:

```Plain Text
{'a': 3, 'c': 2}
```

---

### 17.4 Преобразование данных

```Python
d = {"a": 1, "b": 2}

result = {k.upper(): v * 100 for k, v in d.items()}
print(result)
```

Вывод:

```Plain Text
{'A': 100, 'B': 200}
```

### Вывод по разделу

> `items()` особенно полезен, когда нужно анализировать, фильтровать или преобразовывать словарь целиком

---

## 18. Кратко о `keys()` и `values()`

Хотя в присланном тексте основной акцент сделан на `items()`, важно связать его с соседними методами.

---

### `keys()`

Возвращает представление всех ключей.

```Python
d = {"a": 1, "b": 2}
print(d.keys())
```

Вывод:

```Plain Text
dict_keys(['a', 'b'])
```

---

### `values()`

Возвращает представление всех значений.

```Python
d = {"a": 1, "b": 2}
print(d.values())
```

Вывод:

```Plain Text
dict_values([1, 2])
```

Они тоже являются **живыми представлениями**.

---

## 19. Типичные ошибки

### Ошибка 1. Считать, что универсальные функции работают со словарём по значениям

Например:

```Python
max(d)
```

работает по ключам, а не по значениям.

---

### Ошибка 2. Считать, что `items()` возвращает список

Нет. Он возвращает `dict_items` — специальный view-объект.

---

### Ошибка 3. Использовать `fromkeys()` с изменяемым объектом, не понимая последствий

```Python
dict.fromkeys(keys, [])
```

очень часто приводит к неожиданному поведению.

---

### Ошибка 4. Использовать `[]` там, где ключ может отсутствовать

В таких случаях `get()` безопаснее.

## 20. Итог

Словарь в Python — это не просто контейнер с парами “ключ-значение”, а полноценная структура, с которой можно работать через:

- универсальные функции коллекций

- безопасные методы доступа

- представления ключей, значений и пар

- удобные шаблоны инициализации и обработки данных

Если сформулировать совсем коротко:

> `get()` нужен для безопасного чтения, `fromkeys()` — для быстрой инициализации, `items()` — для полноценной работы со словарём как с набором пар “ключ-значение”
