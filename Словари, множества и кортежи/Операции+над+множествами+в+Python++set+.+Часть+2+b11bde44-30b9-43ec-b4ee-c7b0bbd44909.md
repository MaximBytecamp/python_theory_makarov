## 1. Введение: зачем нужны операции над множествами

Множества — это не просто структура хранения данных. Это инструмент для **логической обработки данных**:

```Plain Text
Client → Backend → Set operations → Result
```

Например:

- объединить пользователей из разных источников

- найти общих пользователей

- исключить заблокированных

- определить изменения между версиями данных

> важная мысль
операции над множествами — это фундамент фильтрации и агрегации данных в backend

---

## 2. Объединение — `union()`

### 2.1 Что делает

Метод `union()` возвращает новое множество, содержащее **все уникальные элементы** из всех переданных коллекций.

---

### 2.2 Пример

```Python
a = {1, 2, 3}
b = {3, 4, 5}

result = a.union(b)

print("a:", a)
print("b:", b)
print("union:", result)
```

Вывод:

```Plain Text
a: {1, 2, 3}
b: {3, 4, 5}
union: {1, 2, 3, 4, 5}
```

---

### 2.3 Через оператор `|`

```Python
a = {1, 2, 3}
b = {3, 4, 5}

result = a | b
print(result)
```

Вывод:

```Plain Text
{1, 2, 3, 4, 5}
```

---

### 2.4 Несколько коллекций

```Python
a = {1, 2}
b = {3}
c = [4, 5]

result = a.union(b, c)

print(result)
```

Вывод:

```Plain Text
{1, 2, 3, 4, 5}
```

---

### 2.5 Важные особенности

- исходные множества **не изменяются**

- можно передавать **любые итерируемые объекты**

---

### 2.6 Интуитивн

```Plain Text
A ∪ B → всё, что есть хотя бы в одном
```

---

### 2.7 Backend-кейс

```Python
api_users = {"u1", "u2"}
db_users = {"u2", "u3"}

all_users = api_users | db_users

print(all_users)
```

Вывод:

```Plain Text
{'u1', 'u2', 'u3'}
```

---

## 3. Пересечение — `intersection()`

### 3.1 Что делает

Возвращает элементы, которые есть **во всех множествах**

---

### 3.2 Пример

```Python
a = {1, 2, 3}
b = {2, 3, 4}

result = a.intersection(b)

print("intersection:", result)
```

Вывод:

```Plain Text
intersection: {2, 3}
```

---

### 3.3 Через оператор `&`

```Python
a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)
```

Вывод:

```Plain Text
{2, 3}
```

---

### 3.4 Несколько аргументов

```Python
a = {1, 2, 3}
b = {2, 3}
c = [2]

print(a.intersection(b, c))
```

Вывод:

```Plain Text
{2}
```

---

### 3.5 Если есть пустое множество

```Python
print(a & set())
```

Вывод:

```Plain Text
set()
```

---

### 3.6 Интуитивно

```Plain Text
A ∩ B → только общие элементы
```

---

### 3.7 Backend-кейс

```Python
active = {"u1", "u2", "u3"}
paid = {"u2", "u3"}

result = active & paid

print(result)
```

Вывод:

```Plain Text
{'u2', 'u3'}
```

---

## 4. Разность — `difference()`

### 4.1 Что делает

Возвращает элементы, которые есть в первом множестве, но отсутствуют во втором.

---

### 4.2 Пример

```Python
a = {1, 2, 3}
b = {2, 3}

result = a.difference(b)

print("difference:", result)
```

Вывод:

```Plain Text
difference: {1}
```

---

### 4.3 Через оператор `-`

```Python
print(a - b)
```

Вывод:

```Plain Text
{1}
```

---

### 4.4 Интуитивно

```Plain Text
A - B → убрать всё, что есть в B
```

---

### 4.5 Backend-кейс

```Python
all_users = {"u1", "u2", "u3"}
blocked = {"u2"}

allowed = all_users - blocked

print(allowed)
```

Вывод:

```Plain Text
{'u1', 'u3'}
```

---

## 5. Симметрическая разность — `symmetric_difference()`

### 5.1 Что делает

Возвращает элементы, которые есть **только в одном из множеств**

---

### 5.2 Пример

```Python
a = {1, 2, 3}
b = {3, 4}

result = a.symmetric_difference(b)

print(result)
```

Вывод:

```Plain Text
{1, 2, 4}
```

---

### 5.3 Через оператор `^`

```Python
print(a ^ b)
```

Вывод:

```Plain Text
{1, 2, 4}
```

---

### 5.4 Интуитивно

```Plain Text
(A ∪ B) - (A ∩ B)
```

---

### 5.5 Backend-кейс

```Python
old = {"a", "b", "c"}
new = {"b", "c", "d"}

changes = old ^ new

print(changes)
```

Вывод:

```Plain Text
{'a', 'd'}
```

---

## 6. Проверка подмножества — `issubset()`

### 6.1 Что делает

Проверяет, все ли элементы одного множества содержатся в другом

---

### 6.2 Пример

```Python
a = {1, 2}
b = {1, 2, 3}

print(a.issubset(b))
```

Вывод:

```Plain Text
True
```

---

### 6.3 Через оператор

```Python
print(a <= b)
```

Вывод:

```Plain Text
True
```

---

### 6.4 Строгое подмножество

```Python
print(a < b)
```

Вывод:

```Plain Text
True
```

---

### 6.5 Особый случай

```Python
print(set().issubset({1, 2}))
```

Вывод:

```Plain Text
True
```

---

### 6.6 Backend-кейс

```Python
required = {"read", "write"}
user = {"read", "write", "delete"}

print(required <= user)
```

Вывод:

```Plain Text
True
```

---

## 7. Проверка надмножества — `issuperset()`

### 7.1 Что делает

Проверяет, содержит ли множество все элементы другого

---

### 7.2 Пример

```Python
a = {1, 2, 3}
b = {1, 2}

print(a.issuperset(b))
```

Вывод:

```Plain Text
True
```

---

### 7.3 Через оператор

```Python
print(a >= b)
```

Вывод:

```Plain Text
True
```

---

### 7.4 Backend-кейс

```Python
permissions = {"read", "write", "delete"}
required = {"read", "write"}

print(permissions >= required)
```

Вывод:

```Plain Text
True
```

---

## 8. Проверка отсутствия пересечений — `isdisjoint()`

### 8.1 Что делает

Проверяет, есть ли общие элементы

---

### 8.2 Пример

```Python
a = {1, 2}
b = {3, 4}

print(a.isdisjoint(b))
```

Вывод:

```Plain Text
True
```

---

### 8.3 Пример с пересечением

```Python
a = {1, 2}
b = {2, 3}

print(a.isdisjoint(b))
```

Вывод:

```Plain Text
False
```

---

### 8.4 Backend-кейс

```Python
banned = {"1.1.1.1"}
request = {"2.2.2.2"}

print(banned.isdisjoint(request))
```

Вывод:

```Plain Text
True
```

## 9. Под капотом

Все операции работают через хеш-таблицу:

```Plain Text
элемент → hash → поиск → сравнение
```

Например, пересечение:

```Plain Text
берём меньший set
→ проверяем каждый элемент во втором (O(1))
```

---

> важная мысль
эффективность set основана на быстрой проверке `in`

## 10. Типичные ошибки

### Ошибка 1

```Python
a.union(b)
```

Ожидание: `a` изменится
Реальность: нет

---

### Ошибка 2

```Python
a - b != b - a
```
