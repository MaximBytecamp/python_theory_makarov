**Итератор** — это объект, который позволяет **перебирать элементы последовательности по одному**.

Итераторы лежат в основе работы:

- `for`

- `range()`

- `map()`

- `filter()`

- `zip()`

- генераторов

- большинства коллекций Python

---

# Основная идея

Итератор — это объект, который умеет:

```Python
1. возвращать следующий элемент
2. сообщать, что элементы закончились
```

---

# Пример простого перебора

```Python
numbers = [10, 20, 30]

for n in numbers:
    print(n)
```

Результат:

```Python
10
20
30
```

Но внутри Python делает примерно следующее.

---

# Как работает цикл `for`

Цикл `for` внутри использует **итератор**.

Пример того, что делает Python:

```Python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

Результат:

```Python
10
20
30
```

---

# Когда элементы заканчиваются

Возникает исключение:

```Python
StopIteration
```

Пример:

```Python
numbers = [10, 20]

it = iter(numbers)

print(next(it))
print(next(it))
print(next(it))
```

Результат:

```Python
10
20
StopIteration
```

---

# Протокол итератора

Чтобы объект считался **итератором**, он должен иметь два метода:

```Python
__iter__()
__next__()
```

---

# Метод `__iter__`

Метод `__iter__()` возвращает сам итератор.

---

# Метод `__next__`

Метод `__next__()`:

- возвращает следующий элемент

- вызывает `StopIteration`, когда элементы закончились

---

# Что происходит внутри

Метод `for`:

```Python
1. вызывает __iter__()
2. вызывает __next__()
3. получает значения
4. повторяет пока не будет StopIteration
```

# Итераторы и итерируемые объекты

Нужно понимать разницу.

|тип|описание|
|-|-|
|iterable|объект по которому можно итерироваться|
|iterator|объект который возвращает элементы|

---

# Iterable (итерируемый объект)

Это объект, у которого есть:

```Python
__iter__()
```

Примеры:

- list

- tuple

- set

- dict

- string

- range

---

# Iterator

Это объект, у которого есть:

```Python
__next__()
```

---

# Проверка

```Python
numbers = [1,2,3]

print(iter(numbers))
```

Результат:

```Python
<list_iterator object ...>
```

---

# Range — пример итератора

```Python
r = range(5)

it = iter(r)

print(next(it))
print(next(it))
print(next(it))
```

Результат:

```Python
0
1
2
```

---

# Генераторы — это итераторы

Очень важно понимать:

```Python
Генератор = итератор
```

Пример:

```Python
gen = (x*x for x in range(5))

print(next(gen))
print(next(gen))
```

Результат:

```Python
0
1
```

# Итераторы используются в Python везде

Они лежат в основе:

```Python
for
map
filter
zip
enumerate
generators
```

---

# Пример с zip

```Python
names = ["Tom","Bob","Alice"]
scores = [90,80,95]

for name,score in zip(names,scores):
    print(name,score)
```

Результат:

```Python
Tom 90
Bob 80
Alice 95
```

---

# Пример с enumerate

```Python
words = ["python","java","go"]

for i,word in enumerate(words):
    print(i,word)
```

Результат:

```Python
0 python
1 java
2 go
```
