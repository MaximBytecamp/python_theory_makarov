Термин **"тернарный"** происходит от латинского слова ***ternarius***, что означает **«состоящий из трёх»**.

Тернарный оператор называется так, потому что он состоит из **трёх частей**:

1️⃣ **Условие (condition)** — логическое выражение
2️⃣ **Значение если True (value_if_true)**
3️⃣ **Значение если False (value_if_false)**

---

# Синтаксис тернарного оператора

```Python
value_if_true if condition else value_if_false
```

Python сначала проверяет **условие**.

- если условие **True** → возвращается `value_if_true`

- если условие **False** → возвращается `value_if_false`

---

# Простой пример

```Python
a = 5
b = 10

max_value = a if a > b else b

print(max_value)
```

Результат:

```Python
10
```

Потому что:

```Python
условие: 5 > 10 → False
поэтому выбирается значение b
```

---

# Аналог через обычный `if`

```Python
a = 5
b = 10

if a > b:
    max_value = a
else:
    max_value = b
```

Тернарный оператор — это **сокращённая форма такого условия**.

---

# Использование в выражениях

Тернарный оператор можно использовать прямо внутри выражений.

```Python
number = 7

result = "четное" if number % 2 == 0 else "нечетное"

print(result)
```

Результат:

```Python
нечетное
```

---

# Использование внутри `print`

```Python
x = -5

print("положительное" if x > 0 else "отрицательное")
```

Результат:

```Python
отрицательное
```

---

# Пример с функциями

```Python
age = 20

status = "совершеннолетний" if age >= 18 else "несовершеннолетний"

print(status)
```

Результат:

```Python
совершеннолетний
```

# Сравнение операторов

|тип оператора|количество операндов|пример|
|-|-|-|
|унарный|1|`-a`|
|бинарный|2|`a + b`|
|тернарный|3|`a if cond else b`|

# Вложенные тернарные операторы

Тернарные операторы можно **вкладывать друг в друга**.

---

## Пример: найти максимальное из трёх чисел

```Python
a = 5
b = 8
c = 3

max_value = a if a > b and a > c else (b if b > c else c)

print(max_value)
```

Результат:

```Python
8
```

---

# Как работает этот код

Python выполняет:

```Python
если a > b и a > c
    результат = a
иначе
    если b > c
        результат = b
    иначе
        результат = c
```

---

# Аналог через обычный `if`

```Python
if a > b and a > c:
    max_value = a
else:
    if b > c:
        max_value = b
    else:
        max_value = c
```

# Пример использования в списках

```Python
numbers = [1,2,3,4,5]

result = ["четное" if x % 2 == 0 else "нечетное" for x in numbers]

print(result)
```

Результат:

```Python
['нечетное', 'четное', 'нечетное', 'четное', 'нечетное']
```

# Когда использовать тернарный оператор

Тернарный оператор хорошо подходит когда:

- условие **очень простое**

- код должен быть **коротким**

- выражение используется **внутри других выражений**

---

# Когда лучше использовать `if`

Если:

- условие сложное

- есть несколько веток

- код становится трудно читать

Тогда лучше использовать обычный `if`.

---

# Плохой пример

```Python
result = a if x > 10 else b if x > 5 else c if x > 0 else d
```

Такой код трудно читать.

---

# Лучше написать

```Python
if x > 10:
    result = a
elif x > 5:
    result = b
elif x > 0:
    result = c
else:
    result = d
```
