**Генераторы** — это специальный тип функций или выражений, которые позволяют **создавать последовательность значений по одному**, а не хранить всю последовательность в памяти сразу.

Главная идея генераторов:

```Python
вычисление значений по мере необходимости
```

Это делает генераторы **очень эффективными по памяти**, особенно при работе с большими данными.

---

# Почему генераторы важны

Обычные структуры данных (например списки) **сразу создают все элементы**.

```Python
numbers = [x for x in range(1000000)]
```

Python создаёт **миллион элементов в памяти**.

---

Генератор делает иначе:

```Python
numbers = (x for x in range(1000000))
```

Он **создает элементы по одному**, когда они нужны.

---

# Два способа создания генераторов

В Python генераторы создаются двумя способами:

1️⃣ **Генераторная функция (`yield`)**
2️⃣ **Генераторное выражение**

---

# 1. Генераторная функция

Это функция, которая использует ключевое слово **yield** вместо `return`.

---

## Пример

```Python
def generator():
    yield 1
    yield 2
    yield 3

g = generator()

print(g)
```

Результат:

```Python
<generator object generator at 0x...>
```

---

# Получение значений генератора

```Python
print(next(g))
print(next(g))
print(next(g))
```

Результат:

```Python
1
2
3
```

---

# Как работает yield

Ключевое слово **yield**:

- возвращает значение

- **останавливает выполнение функции**

- сохраняет состояние функции

Когда вызывается `next()` — выполнение продолжается **с того же места**.

---

# Пример пошаговой работы

```Python
def numbers():
    print("start")
    yield 1

    print("middle")
    yield 2

    print("end")
    yield 3

g = numbers()

print(next(g))
print(next(g))
print(next(g))
```

Результат:

```Python
start
1
middle
2
end
3
```

---

# Генераторы в циклах

Чаще всего генераторы используются в циклах.

```Python
def count(n):
    for i in range(n):
        yield i

for num in count(5):
    print(num)
```

Результат:

```Python
0
1
2
3
4
```

---

# Пример генератора бесконечной последовательности

```Python
def infinite():
    i = 0
    while True:
        yield i
        i += 1
```

Использование:

```Python
g = infinite()

print(next(g))
print(next(g))
print(next(g))
```

Результат:

```Python
0
1
2
```

# 2. Генераторные выражения

Это сокращённая форма генератора.

Синтаксис похож на **list comprehension**, но используются **круглые скобки**.

---

## Синтаксис

```Python
(expression for element in iterable)
```

---

## Пример

```Python
gen = (x**2 for x in range(5))

print(gen)
```

Результат:

```Python
<generator object ...>
```

---

# Получение значений

```Python
for value in gen:
    print(value)
```

Результат:

```Python
0
1
4
9
16
```

---

# Сравнение list comprehension и generator expression

## Список

```Python
squares = [x**2 for x in range(5)]
```

Создается список:

```Python
[0,1,4,9,16]
```

---

## Генератор

```Python
squares = (x**2 for x in range(5))
```

Создается генератор.

Элементы создаются **по одному**.

---

# Генераторы и память

Сравним память.

### список

```Python
numbers = [x for x in range(1000000)]
```

Создает **1 000 000 элементов в памяти**

---

### генератор

```Python
numbers = (x for x in range(1000000))
```

Создает **один элемент за раз**

# Использование генераторов в функциях

Часто генераторы используют вместе с функцией **sum()**

```Python
result = sum(x*x for x in range(10))

print(result)
```

Результат:

```Python
285
```

---

# Генератор для чтения файлов

Очень полезно при работе с большими файлами.

```Python
def read_file(file):
    for line in file:
        yield line.strip()
```

Использование:

```Python
for line in read_file(open("data.txt")):
    print(line)
```

Файл читается **построчно**, а не полностью.

---

# Отличие yield от return

|return|yield|
|-|-|
|завершает функцию|приостанавливает|
|возвращает одно значение|может возвращать много|
|функция заканчивается|функция продолжается|

---

# StopIteration

Когда генератор заканчивается, возникает исключение:

```Python
StopIteration
```

Пример:

```Python
g = (x for x in range(2))

print(next(g))
print(next(g))
print(next(g))
```

Результат:

```Python
0
1
StopIteration
```

---

# Когда использовать генераторы

Генераторы полезны когда:

- данные **очень большие**

- нужна **ленивая загрузка**

- требуется **экономия памяти**

- нужна **потоковая обработка**

---

# Где используются генераторы

Генераторы активно используются в:

- **FastAPI**

- **Django**

- **pandas**

- **async frameworks**

- **обработке файлов**

- **стриминге данных**
