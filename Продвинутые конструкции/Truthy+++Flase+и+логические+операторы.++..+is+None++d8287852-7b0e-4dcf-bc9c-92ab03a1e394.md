# Логический оператор `or`

Оператор `or` возвращает:

```Python
первое истинное значение
или
последнее ложное
```

---

## Пример

```Python
print(0 or 10)
```

Результат

```Python
10
```

Потому что:

```Python
0 → False
10 → True
```

`or` возвращает **первое истинное значение**.

---

## Еще пример

```Python
print("" or "Python")
```

Результат

```Python
Python
```

---

# Практическое применение `or`

Очень распространённый Python-паттерн:

```Python
name = ""
username = name or "Anonymous"

print(username)
```

Результат

```Python
Anonymous
```

Потому что пустая строка — **Falsy**.

---

# Truthy / Falsy в `if`

```Python
data = []

if data:
    print("Есть данные")
else:
    print("Пусто")
```

Результат

```Python
Пусто
```

---

# Почему лучше писать `is None`

Очень важная особенность Python.

Правильно:

```Python
if data is None:
```

Неправильно:

```Python
if data == None:
```

---

# Причина

`None` — это **единственный специальный объект**.

В Python существует **только один объект None**.

Поэтому его проверяют **по идентичности**, а не по равенству.

---

# Разница между `is` и `==`

|оператор|что проверяет|
|-|-|
|`==`|равенство значений|
|`is`|одинаковый объект в памяти|

---

# Пример

```Python
a = None
b = None

print(a is b)
```

Результат

```Python
True
```

Потому что это **один и тот же объект**.

---

# Пример с `==`

```Python
print(a == b)
```

Результат

```Python
True
```

Но смысл проверки **другой**.

---

# Почему `== None` может быть опасным

Некоторые объекты могут **переопределять оператор `==`**.

Пример:

```Python
class Test:
    def __eq__(self, other):
        return True

obj = Test()

print(obj == None)
```

Результат

```Python
True
```

Хотя объект **не равен None**.

---

# Проверка `is None`

```Python
print(obj is None)
```

Результат

```Python
False
```

Это корректная проверка.

---

# Официальная рекомендация Python (PEP 8)

Всегда писать:

```Python
if value is None
```

и

```Python
if value is not None
```

---

# Когда использовать `None`

`None` часто используется как:

```Python
отсутствие значения
пустой результат
неинициализированная переменная
```

---

# Пример

```Python
def find_user(user_id):

    if user_id == 1:
        return "Max"

    return None
```

Использование:

```Python
user = find_user(2)

if user is None:
    print("Пользователь не найден")
```

---

# Truthy / Falsy и `None`

Важно понимать:

```Python
None → False
```

Поэтому

```Python
if value:
```

и

```Python
if value is not None:
```

**НЕ одно и то же.**

---

# Пример

```Python
value = 0

if value:
    print("True")
else:
    print("False")
```

Результат

```Python
False
```

Но значение **не None**.

---

# Правильная проверка

```Python
if value is not None:
```

---

# Итог

Truthy / Falsy позволяет писать короткий Python-код:

```Python
if data:
```

Но для проверки отсутствия значения нужно писать:

```Python
if value is None
```

или

```Python
if value is not None
```

---

Если хочешь, я могу разобрать **одну из самых важных тем Python**, которая напрямую связана с этим и часто вызывает путаницу:

**LEGB правило (области видимости переменных)** — как Python ищет переменные внутри функций, циклов и классов.

В Python логические операторы работают не только с `True` и `False`, но и с **любыми объектами**, используя правило **Truthy / Falsy**.

Напомним:

**Falsy значения:**

```Python
False
None
0
0.0
''
[]
{}
set()
```

Все остальные значения считаются **Truthy**.
