# 1. Распаковка списка или кортежа `*`

Символ `*` позволяет **распаковать последовательность** (list, tuple, range) в отдельные аргументы.

## Пример

```Python
def add(a, b, c):
    print(a + b + c)

numbers = [1, 2, 3]

add(*numbers)
```

Вывод:

```Python
6
```

Что происходит:

```Python
*numbers → 1, 2, 3
```

Фактически Python делает:

```Python
add(1,2,3)
```

---

# 2. Без распаковки будет ошибка

```Python
numbers = [1,2,3]

add(numbers)
```

Ошибка:

```Python
TypeError: missing arguments
```

Потому что функция ожидает **3 аргумента**, а получает **1 список**.

---

# 3. Распаковка кортежа

```Python
def show(a, b, c):
    print(a, b, c)

data = (10, 20, 30)

show(*data)
```

Результат:

```Python
10 20 30
```

---

# 4. Распаковка в циклах

Очень часто используется при работе со списками кортежей.

```Python
pairs = [(1,2), (3,4), (5,6)]

for a, b in pairs:
    print(a, b)
```

Python делает распаковку автоматически.

---

# 5. Распаковка словаря `**`

`**` используется для **распаковки словаря в именованные аргументы**.

## Пример

```Python
def greet(name, age):
    print(name, age)

person = {
    "name": "Алиса",
    "age": 30
}

greet(**person)
```

Результат:

```Python
Алиса 30
```

Python делает:

```Python
greet(name="Алиса", age=30)
```

---

# 6. Без `**` будет ошибка

```Python
greet(person)
```

Ошибка:

```Python
TypeError
```

Потому что функция ожидает **два аргумента**, а получает **один словарь**.

# 7. Распаковка нескольких списков

```Python
list1 = [1,2,3]
list2 = [4,5,6]

numbers = [*list1, *list2]

print(numbers)
```

Результат:

```Python
[1,2,3,4,5,6]
```

---

# 8. Распаковка нескольких словарей

```Python
dict1 = {"a":1}
dict2 = {"b":2}

result = {**dict1, **dict2}

print(result)
```

Результат:

```Python
{'a':1, 'b':2}
```

---

# 9. Распаковка при вызове функции

```Python
def func(a, b, c, d):
    print(a,b,c,d)

numbers = [1,2]
more = [3,4]

func(*numbers, *more)
```

Результат:

```Python
1 2 3 4
```

---

```Python
def show(a, b, c, name):
    print(a,b,c,name)

numbers = [1,2,3]
data = {"name":"Max"}

show(*numbers, **data)
```

Результат:

```Python
1 2 3 Max
```

# 11. Распаковка внутри присваивания

Python умеет распаковывать элементы при присваивании.

```Python
a, b, c = [10,20,30]

print(a,b,c)
```

Результат:

```Python
10 20 30
```

---

# 12. Использование `*` для остатка элементов

```Python
a, *rest = [1,2,3,4,5]

print(a)
print(rest)
```

Результат:

```Python
1
[2,3,4,5]
```

---

# 13. Распаковка в середине

```Python
a, *middle, b = [1,2,3,4,5]

print(a)
print(middle)
print(b)
```

Результат:

```Python
1
[2,3,4]
5
```

---

# Где это используется в реальных проектах

Очень часто используется в:

- FastAPI

- Django

- SQLAlchemy

- dataclasses

- dependency injection

- конфигурациях

Например:

```Python
Model(**data_from_json)
```

где JSON превращается в аргументы конструктора.

---

# Важная связь

Очень важно понимать:

```Python
*args   ← собирает аргументы
*list   → распаковывает аргументы
```

```Python
**kwargs ← собирает словарь
**dict   → распаковывает словарь
```

---

# Главное правило

```Python
*  → работает с последовательностями
** → работает со словарями
```

---

✅ **Коротко**

```Python
*args  → tuple
**kwargs → dict
*list → распаковка списка
**dict → распаковка словаря
```
