# `*args` и `**kwargs`

В Python функции могут принимать **разные типы аргументов**. Это делает функции гибкими и позволяет создавать универсальные интерфейсы.

---

# 1. Позиционные аргументы

Позиционные аргументы передаются **в строгом порядке**.

```Python
def greet(name, age):
    print("Имя:", name)
    print("Возраст:", age)

greet("Алиса", 30)
```

Вывод:

```Python
Имя: Алиса
Возраст: 30
```

Python связывает значения **по позиции**:

```Python
"Алиса" → name
30 → age
```

---

# 2. Именованные (ключевые) аргументы

Можно явно указать **имя параметра**.

```Python
def greet(name, age):
    print("Имя:", name)
    print("Возраст:", age)

greet(age=30, name="Алиса")
```

Вывод:

```Python
Имя: Алиса
Возраст: 30
```

Порядок аргументов **уже не важен**.

---

# 3. Аргументы со значением по умолчанию

Можно задать значение, которое будет использоваться **если аргумент не передан**.

```Python
def greet(name, age=20):
    print("Имя:", name)
    print("Возраст:", age)

greet("Алиса")
```

Вывод:

```Python
Имя: Алиса
Возраст: 20
```

Если аргумент передать:

```Python
greet("Алиса", 25)
```

Вывод:

```Python
Имя: Алиса
Возраст: 25
```

---

# 4. Произвольное количество позиционных аргументов — `*args`

Иногда заранее **неизвестно количество аргументов**.

Для этого используется `*args`.

```Python
def greet(*names):
    for name in names:
        print("Привет,", name)

greet("Алиса", "Боб", "Чарли")
```

Вывод:

```Python
Привет, Алиса
Привет, Боб
Привет, Чарли
```

### Как работает `*args`

Все переданные аргументы собираются в **кортеж**.

```Python
names = ("Алиса", "Боб", "Чарли")
```

Пример:

```Python
def show(*args):
    print(args)

show(1,2,3,4)
```

Вывод:

```Python
(1, 2, 3, 4)
```

---

# 5. Произвольное количество именованных аргументов — `**kwargs`

Если неизвестно количество **именованных аргументов**, используется `**kwargs`.

```Python
def show(**info):
    for key, value in info.items():
        print(key, ":", value)

show(name="Алиса", age=30, city="Москва")
```

Вывод:

```Python
name : Алиса
age : 30
city : Москва
```

### Как работает `**kwargs`

Все аргументы собираются в **словарь**.

```Python
info = {
    "name": "Алиса",
    "age": 30,
    "city": "Москва"
}
```

---

# 6. Использование `*args` и `**kwargs` вместе

Можно принимать **и позиционные, и именованные аргументы**.

```Python
def greet(*names, **info):

    for name in names:
        print("Привет,", name)

    for key, value in info.items():
        print(key, ":", value)

greet("Алиса", "Боб", age=30, city="Москва")
```

Вывод:

```Python
Привет, Алиса
Привет, Боб
age : 30
city : Москва
```

---

# 7. Аргументы только для позиции `/`

С Python **3.8** появился синтаксис `/`.

Все параметры **до `/`** можно передавать **только по позиции**.

```Python
def greet(name, /):
    print("Привет", name)

greet("Алиса")
```

Нельзя:

```Python
greet(name="Алиса") ❌
```

Ошибка.

---

# 8. Аргументы только по имени `*`

Все параметры **после `*`** должны передаваться **по имени**.

```Python
def greet(name, *, age):
    print(name, age)

greet("Алиса", age=30)
```

Нельзя:

```Python
greet("Алиса", 30) ❌
```

---

# 9. Комбинация всех типов аргументов

Python поддерживает **полную комбинацию**.

```Python
def greet(greeting, /, name, *friends, age=30, **info):

    print(greeting, name)

    for friend in friends:
        print("Друг:", friend)

    print("Возраст:", age)

    for key, value in info.items():
        print(key, value)
```

Вызов:

```Python
greet(
    "Привет",
    "Алиса",
    "Боб",
    "Чарли",
    age=25,
    city="Москва",
    job="Developer"
)
```

# Порядок параметров в функции

Очень важно помнить **правильный порядок**:

```Python
позиционные
позиционные/именованные
*args
именованные
**kwargs
```

Общая схема:

```Python
def func(positional_only, /,
         positional_or_keyword,
         *args,
         keyword_only,
         **kwargs):
```

---

# Краткая таблица

|Тип аргумента|Пример|Что создается|
|-|-|-|
|позиционный|`func(10)`|обычное значение|
|именованный|`func(x=10)`|обычное значение|
|значение по умолчанию|`x=10`|если аргумент не передан|
|`*args`|`func(1,2,3)`|кортеж|
|`**kwargs`|`func(a=1,b=2)`|словарь|
|`/`|positional-only|только позиция|
|`*`|keyword-only|только имя|

---

# Важно понимать

```Python
*args  → собирает позиционные аргументы → tuple
**kwargs → собирает именованные аргументы → dict
```

---

**Главная идея**

`*args` и `**kwargs` позволяют писать **универсальные функции**, которые могут принимать **любое количество аргументов**.
