# 5. Функция с несколькими параметрами

### Задача

Напишите функцию, которая возвращает большее из двух чисел.

### Решение

```Python
def max_number(a, b):
    if a > b:
        return a
    else:
        return b

print(max_number(10, 5))
print(max_number(3, 9))
```

# 6. Функция, вызывающая другую функцию

### Задача

Создайте функцию `square()`, а затем функцию `sum_of_squares()`, которая складывает квадраты двух чисел.

### Решение

```Python
def square(x):
    return x * x


def sum_of_squares(a, b):
    return square(a) + square(b)


print(sum_of_squares(3, 4))
```

Результат:

```Python
25
```

# 8. Использование вложенной функции для вычислений

### Задача

Создайте функцию для вычисления площади прямоугольника.
Внутри неё создайте функцию для вычисления произведения чисел.

### Решение

```Python
def rectangle_area(a, b):

    def multiply(x, y):
        return x * y

    return multiply(a, b)


print(rectangle_area(5, 3))
```

# 9. Функция, вызывающая несколько функций

### Задача

Создайте программу, которая вычисляет:

- квадрат числа

- куб числа

### Решение

```Python
def square(x):
    return x * x


def cube(x):
    return x * x * x


def calculate(x):
    print("Квадрат:", square(x))
    print("Куб:", cube(x))


calculate(3)
```

# 10. Функция для анализа числа

### Задача

Создайте функцию, которая:

- проверяет чётность

- находит абсолютное значение

- находит квадрат

### Решение

```Python
def analyze_number(n):

    def is_even(x):
        return x % 2 == 0

    def square(x):
        return x * x

    print("Четное:", is_even(n))
    print("Абсолютное значение:", abs(n))
    print("Квадрат:", square(n))


analyze_number(-4)
```

# 11. Разбор числа на цифры (через функции)

### Задача

Создать функцию, которая выводит:

- последнюю цифру числа

- число без последней цифры

### Решение

```Python
def analyze_number(n):

    def last_digit(x):
        return x % 10

    def remove_last_digit(x):
        return x // 10

    print("Последняя цифра:", last_digit(n))
    print("Без последней цифры:", remove_last_digit(n))


analyze_number(12345)
```

# 12. Функция-меню (частая практика)

### Задача

Создать простое меню с функциями.

### Решение

```Python
def add(a, b):
    return a + b


def multiply(a, b):
    return a * b


def calculator():
    x = int(input("Введите первое число: "))
    y = int(input("Введите второе число: "))

    print("Сумма:", add(x, y))
    print("Произведение:", multiply(x, y))


calculator()
```
