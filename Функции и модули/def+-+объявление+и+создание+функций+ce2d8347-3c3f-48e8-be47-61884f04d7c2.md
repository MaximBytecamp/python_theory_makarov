В Python ключевое слово `def` используется для **создания (объявления) функций**.

Функция — это **именованный блок кода**, который выполняет определённую задачу.
Функции помогают **структурировать программу и повторно использовать код**.

---

# Общий синтаксис

```Python
def имя_функции():
    блок_кода
```

- `def` — ключевое слово для объявления функции

- `имя_функции` — имя функции

- `()` — скобки для параметров

- `:` — двоеточие после объявления

- далее идёт **блок кода с отступом**

---

# Простой пример

```Python
def hello():
    print("Привет, мир!")
```

Функция **объявлена**, но ещё не выполнена.

Чтобы её выполнить, нужно **вызвать функцию**.

```Python
hello()
```

Результат:

```Python
Привет, мир!
```

---

# Функции с параметрами

Функции могут принимать **параметры (входные данные)**.

Пример:

```Python
def greet(name):
    print("Привет,", name)
```

Вызов функции:

```Python
greet("Алексей")
```

Результат:

```Python
Привет, Алексей
```

Здесь `name` — параметр функции.

---

# Функции с несколькими параметрами

```Python
def add(a, b):
    print(a + b)
```

Вызов:

```Python
add(5, 3)
```

Результат:

```Python
8
```

---

# Возврат значения (`return`)

Функции могут **возвращать результат** с помощью ключевого слова `return`.

Пример:

```Python
def add(a, b):
    return a + b
```

Использование:

```Python
result = add(5, 3)
print(result)
```

Результат:

```Python
8
```

---

# Зачем нужны функции

Функции позволяют:

```Python
разделять программу на логические части
повторно использовать код
упрощать структуру программы
```

Например, вместо повторения одного и того же кода можно создать функцию и вызывать её несколько раз.

---

# Пример повторного использования

```Python
def square(x):
    return x * x

print(square(3))
print(square(5))
print(square(10))
```

Результат:

```Python
9
25
100
```

---

# Итог

Функция в Python создаётся с помощью ключевого слова:

```Python
def
```

Общий вид:

```Python
def имя_функции(параметры):
    блок_кода
```

Функции позволяют **писать более понятный, удобный и повторно используемый код**.
