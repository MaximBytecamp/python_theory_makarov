# ФУНКЦИЯ `abs()`

Функция `abs()` в Python используется для **нахождения абсолютного значения числа**.

Абсолютное значение — это **значение числа без учёта знака**.

Например:

```Python
|-5| = 5
|3| = 3
```

---

# Синтаксис

```Python
abs(число)
```

Функция принимает **один аргумент** — число.

Это может быть:

- целое число (`int`)

- число с плавающей точкой (`float`)

---

# Пример

```Python
print(abs(-5))
print(abs(3))
print(abs(-7.2))
```

Результат:

```Python
5
3
7.2
```

---

# Практическое применение

`abs()` часто используется:

- при работе с расстояниями

- при вычислении разницы между числами

- при математических вычислениях

Пример:

```Python
a = 10
b = 4

difference = abs(a - b)

print(difference)
```

Результат:

```Python
6
```

# ФУНКЦИИ `max()` И `min()`

Функции `max()` и `min()` используются для нахождения:

```Python
max() — наибольшего значения
min() — наименьшего значения
```

---

# 1. Использование с несколькими значениями

Функции могут принимать **несколько аргументов**.

Пример:

```Python
print(max(3, 7, 2, 9))
print(min(3, 7, 2, 9))
```

Результат:

```Python
9
2
```

---

# 2. Использование с коллекцией

Функции также могут принимать **одну коллекцию** (например, список).

Пример:

```Python
numbers = [3, 7, 2, 9]

print(max(numbers))
print(min(numbers))
```

Результат:

```Python
9
2
```

---

# 3. Работа со строками

Функции могут работать и со строками.

Пример:

```Python
print(max("python"))
print(min("python"))
```

Результат будет зависеть от **алфавитного порядка символов**.

---

# Важное замечание

Функции `max()` и `min()` работают **не только с числами**, но и с другими типами данных.

Некоторые примеры могут содержать элементы, которые будут изучаться позже. Они приведены для того, чтобы показать, что возможности этих функций **не ограничиваются только простыми числами**.

# Итог

Основные функции:


Они часто используются при:
