Библиотека (или модуль) в Python — это **обычный файл с расширением `.py`**, который содержит код на языке Python.

Внутри такого файла могут находиться:

```Python
переменные
функции
классы
другие объекты
```

Этот код можно **использовать в других программах**, подключая модуль.

---

# Зачем нужны модули

Модули позволяют:

```Python
организовывать код
разделять программу на части
повторно использовать код
```

В Python можно использовать:

- **стандартные библиотеки** (встроенные в Python)

- **сторонние библиотеки**, которые устанавливаются через менеджер пакетов `pip`.

---

# Ключевое слово `import`

Ключевое слово `import` используется для **подключения модуля к программе**.

После подключения его функции и переменные становятся доступными для использования.

---

# Пример подключения модуля

В Python есть встроенный модуль `math`, который содержит математические функции.

```Python
import math
```

Теперь можно использовать функции из этого модуля.

Пример:

```Python
print(math.sqrt(16))
```

Результат:

```Python
4.0
```

---

# Обращение через точку `.`

Точка (`.`) используется для **обращения к объектам внутри модуля**.

Например:

```Python
math.sqrt(16)
```

означает:

```Python
использовать функцию sqrt() из модуля math
```

Общий принцип:

```Python
модуль.объект
```

---

# Импорт конкретного объекта

Иногда нет необходимости подключать **весь модуль**, можно импортировать только нужную функцию.

Для этого используется конструкция:

```Python
from ... import ...
```

Пример:

```Python
from math import sqrt
```

Теперь функцию можно использовать **без имени модуля**.

```Python
print(sqrt(16))
```

Результат:

```Python
4.0
```

---

# Использование псевдонимов (`as`)

Иногда для удобства модулю или функции задают **псевдоним (алиас)**.

Для этого используется ключевое слово `as`.

---

# Пример №1 — псевдоним для модуля

```Python
import math as m

print(m.sqrt(25))
```

---

# Пример №2 — псевдоним для функции

```Python
from math import sqrt as square_root

print(square_root(25))
```

---

# Пример №3 — псевдоним для всей библиотеки

Очень часто используется:

```Python
import numpy as np
```

Это просто **сокращённое имя библиотеки**.

---

# Итог

Модуль — это файл `.py`, содержащий код, который можно использовать в других программах.

Основные способы импорта:

```Python
import module
from module import object
import module as alias
from module import object as alias
```

Импорт модулей позволяет **использовать готовые функции и упрощать разработку программ**.
