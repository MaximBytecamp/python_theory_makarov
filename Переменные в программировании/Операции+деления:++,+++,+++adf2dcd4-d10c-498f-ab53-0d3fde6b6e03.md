В Python существует несколько видов деления:

```Python
/   — обычное деление
//  — целочисленное деление
%   — остаток от деления
```

---

# 1. КЛАССИЧЕСКОЕ ДЕЛЕНИЕ `/`

Оператор `/` выполняет **обычное математическое деление**.

Результат **всегда имеет тип `float`**, даже если делятся два целых числа.

### Пример

```Python
print(5 / 2)    # 2.5
print(6 / 3)    # 2.0
print(45 / 4)   # 11.25
```

Даже если явно указать тип `int`, результат всё равно будет `float`:

```Python
print(int(5) / int(2))   # 2.5
print(int(6) / int(3))   # 2.0
print(int(45) / int(4))  # 11.25
```

Это поведение появилось в **Python 3**.
В более старой версии языка (Python 2) деление двух целых чисел возвращало целое число.

Иногда результат может быть **периодической дробью**:

```Python
print(1 / 3)
```

Результат:

```Python
0.3333333333333333
```

Поэтому при необходимости результат **округляют** или используют **целочисленное деление**.

---

# 2. ДЕЛЕНИЕ БЕЗ ОСТАТКА `//`

Оператор `//` выполняет **целочисленное деление**.

Он возвращает **целую часть результата**, отбрасывая дробную.

### Пример

```Python
print(5 // 2)    # 2
print(6 // 3)    # 2
print(45 // 4)   # 11
```

Если одно из чисел имеет тип `float`, результат тоже будет `float`:

```Python
print(5 // 2.0)   # 2.0
print(5.0 // 2)   # 2.0
```

Если результат должен быть **обязательно целым числом**, можно использовать `int()`:

```Python
print(5 // int(2.0))      # 2
print(int(5.0 // 2))      # 2
```

---

# 3. ОСТАТОК ОТ ДЕЛЕНИЯ `%`

Оператор `%` возвращает **остаток от деления**.

### Пример

```Python
print(10 % 3)
```

Результат:

```Python
1
```

Потому что:

```Python
10 = 3 * 3 + 1
```

---

# Использование `%` для работы с цифрами

Оператор `%` часто используется для получения **последних цифр числа**.

### Последняя цифра

```Python
number = 12345
last_digit = number % 10

print(last_digit)
```

Результат:

```Python
5
```

---

### Последние две цифры

```Python
number % 100
```

Результат:

```Python
45
```

---

### Последние три цифры

```Python
number % 1000
```

Результат:

```Python
345
```

---

### Правило

```Python
n % 10     → последняя цифра
n % 100    → последние две цифры
n % 1000   → последние три цифры
```

То есть `%` **выделяет последние цифры числа**.

---

# Использование `//` для удаления цифр

Оператор `//` позволяет **удалять последние цифры числа**.

### Удаление последней цифры

```Python
number = 12345
number_without_last_digit = number // 10

print(number_without_last_digit)
```

Результат:

```Python
1234
```

---

### Удаление двух последних цифр

```Python
number // 100
```

Результат:

```Python
123
```

---

### Удаление трёх последних цифр

```Python
number // 1000
```

Результат:

```Python
12
```

---

### Правило

```Python
n // 10     → убрать последнюю цифру
n // 100    → убрать две последние цифры
n // 1000   → убрать три последние цифры
```

То есть `//` **отрезает последние цифры числа**.

---

# Итог

Основные операции деления:

```Python
/   → обычное деление (результат float)

//  → целочисленное деление (без дробной части)

%   → остаток от деления
```

Практическое использование:

```Python
%  → получение последних цифр числа
// → удаление последних цифр числа
```
