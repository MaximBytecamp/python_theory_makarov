**Переменная** — это имя, которое используется для обращения к данным в программе.

Она позволяет:

- хранить данные

- изменять их

- использовать в разных частях программы

Проще говоря:

```Python
переменная = имя → значение
```

---

# Аналогия с коробками

Представьте, что программа — это **комната**, а переменные — это **коробки с ярлыками**.

```Python
distance   → [ 500 ]
fuel_price → [ 45.5 ]
cost_home  → [ 2500 ]
```

Вы можете:

- открыть коробку

- взять значение

- положить новое

---

# Пример переменных

```Python
distance = 500
fuel_price = 45.5
fuel_efficiency = 12
cost_home = 2500
```

Здесь переменные хранят:

|переменная|значение|
|-|-|
|distance|расстояние|
|fuel_price|цена топлива|
|fuel_efficiency|расход топлива|
|cost_home|стоимость проживания|

---

# Пример программы

```Python
# Данные
distance = 500
fuel_price = 45.5
fuel_efficiency = 12
cost_home = 2500

# Расчёт стоимости топлива
fuel_cost = (distance / fuel_efficiency) * fuel_price

# Общая стоимость
total_cost = fuel_cost + cost_home

print("Стоимость путешествия:")
print(f"Расходы на топливо: {fuel_cost} руб.")
print(f"Расходы на проживание: {cost_home} руб.")
print(f"Общая стоимость: {total_cost} руб.")
```

---

Стоимость путешествия:

# Почему переменные полезны

Переменные позволяют:

```Python
хранить промежуточные результаты
упрощать код
повторно использовать данные
```

---

# Пример без переменной

```Python
print("Сумма чисел 2, 3 и 4:", 2 + 3 + 4)
```

Работает.

Но если вычисление сложное — код становится плохо читаемым.

---

# Пример с переменной

```Python
summ = 2 + 3 + 4
print("Сумма:", summ)
```

---

# Изменение значения переменной

Переменную можно изменять.

```Python
summ = 2 + 3 + 4
summ += 5
summ *= 2

print("Результат:", summ)
```

---

# Без переменной код становится сложным

```Python
print("Сумма:", 2 + 3 + 4)
print("Сумма +5:", 2 + 3 + 4 + 5)
print("Результат:", (2 + 3 + 4 + 5) * 2)
```

Код становится:

```Python
длинным
повторяющимся
сложным для изменения
```

---

# Главное назначение print()

Функция `print()` должна:

```Python
выводить результат
```

А не выполнять сложные вычисления.
