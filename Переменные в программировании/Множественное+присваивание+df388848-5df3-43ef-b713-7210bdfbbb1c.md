Множественное присваивание в Python — это способ **присвоить значения сразу нескольким переменным в одной строке кода**.

Это позволяет сделать код **короче и удобнее для чтения**.

---

# Простой пример

Обычное присваивание:

```Python
a = 1
b = 2
c = 3
```

То же самое можно записать с помощью множественного присваивания:

```Python
a, b, c = 1, 2, 3
```

Теперь:

```Python
a = 1
b = 2
c = 3
```

---

# Обмен значениями переменных

Одно из самых популярных применений множественного присваивания — **обмен значениями переменных**.

Пример:

```Python
a = 1
b = 2
```

Поменяем значения местами:

```Python
a, b = b, a
```

Теперь:

```Python
a = 2
b = 1
```

При этом **не требуется дополнительная переменная**.

---

# Пример с тремя переменными

Пусть:

```Python
a = 1
b = 2
c = 3
```

Выполним:

```Python
a, b, c = c, b, a
```

---

# Что происходит при выполнении

Сначала Python **вычисляет правую часть выражения**:

```Python
c, b, a
```

То есть формируется набор значений:

```Python
3, 2, 1
```

Затем эти значения **одновременно присваиваются переменным слева**:

```Python
a = 3
b = 2
c = 1
```

---

# Итоговые значения

После выполнения:

```Python
a, b, c = c, b, a
```

переменные будут иметь значения:

```Python
a = 3
b = 2
c = 1
```

---

# Важная особенность

Присваивание происходит **одновременно**, поэтому переменные в правой части используют **старые значения**, которые существовали до выполнения операции.

Именно поэтому обмен значениями работает корректно.

---

# Итог

Множественное присваивание позволяет:

```Python
• присваивать значения нескольким переменным одновременно
• сокращать код
• легко менять значения переменных местами
```

Пример:

```Python
a, b = 5, 10
a, b = b, a
```

Теперь:

```Python
a = 10
b = 5
```
