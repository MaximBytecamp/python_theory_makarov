Функция `print()` используется для **вывода данных на экран (в консоль)**.
Это одна из самых часто используемых функций в Python, так как она позволяет отображать результаты работы программы.

Общий синтаксис:

```Python
print(значение)
```

---

# Простой пример

```Python
print("Hello, world!")
```

Результат:

```Python
Hello, world!
```

Функция выводит строку в консоль.

---

# Вывод переменных

Функция `print()` может выводить **значения переменных**.

Пример:

```Python
name = "Alice"
print(name)
```

Результат:

```Python
Alice
```

---

# Вывод нескольких значений

Можно вывести несколько значений одновременно.

```Python
name = "Alice"
age = 25

print(name, age)
```

Результат:

```Python
Alice 25
```

По умолчанию между значениями добавляется **пробел**.

---

# Вывод чисел

`print()` может выводить числа.

```Python
x = 10
y = 5

print(x + y)
```

Результат:

```Python
15
```

---

# Вывод разных типов данных

`print()` может выводить разные типы данных одновременно.

```Python
name = "Alice"
age = 25

print("Имя:", name, "Возраст:", age)
```

Результат:

```Python
Имя: Alice Возраст: 25
```

---

# Форматирование строк (f-строки)

Часто используется **f-строка**, которая позволяет вставлять переменные прямо в текст.

Пример:

```Python
name = "Alice"
age = 25

print(f"Имя: {name}, возраст: {age}")
```

Результат:

```Python
Имя: Alice, возраст: 25
```

---

# Итог

Функция `print()` используется для:

- вывода текста

- вывода переменных

- отображения результатов вычислений

- взаимодействия программы с пользователем
