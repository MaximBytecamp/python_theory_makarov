Тип данных определяет **какие значения может хранить переменная и какие операции можно с ними выполнять**.

В Python тип переменной определяется **автоматически** при присваивании значения.

Пример:

```Python
x = 10      # int
y = 3.14    # float
name = "Alice"  # str
```

Чтобы узнать тип переменной используется функция:

```Python
print(type(x))
```

---

# 1. int (integer)

**Целые числа** — это числа без дробной части.

Они могут быть:

- положительными

- отрицательными

- равными нулю

Примеры:

```Python
-10
0
5
100
```

Пример использования:

```Python
x = 10
y = -5
z = 0
```

С целыми числами можно выполнять операции:

```Python
+  сложение
-  вычитание
*  умножение
/  деление
// целочисленное деление
%  остаток от деления
** степень
```

Пример:

```Python
a = 10
b = 3

print(a + b)
print(a * b)
print(a // b)
```

---

# 2. float (floating-point)

**Float** — это числа с дробной частью.

Дробная часть отделяется **точкой**.

Примеры:

```Python
3.14
-0.5
10.0
0.001
```

Пример использования:

```Python
x = 3.14
y = -0.5
```

С float можно выполнять те же арифметические операции:

```Python
a = 5.5
b = 2.0

print(a + b)
print(a * b)
print(a / b)
```

Float используется, когда требуется **более точное представление чисел** (например, в научных расчетах).

# 3. str (string)

**Строка** — это последовательность символов.

Строки записываются в:

```Python
"двойных кавычках"
'одинарных кавычках'
"""тройных кавычках"""
```

Примеры:

```Python
name = "Alice"
message = "Привет, мир!"
number = "123"
```

Со строками можно выполнять операции:

### Конкатенация (объединение)

```Python
first = "Hello"
second = "World"

print(first + " " + second)
```

Результат:

```Python
Hello World
```

### Повторение строки

```Python
print("ha" * 3)
```

Результат:

```Python
hahaha
```

### Длина строки

```Python
print(len("Python")) #6
```

---

# Важное отличие типов

Даже если строка содержит цифры, она **не является числом**.

Пример:

```Python
x = "10"
y = 10
```

Это разные типы:

```Python
print(type(x))  # str
print(type(y))  # int
```
