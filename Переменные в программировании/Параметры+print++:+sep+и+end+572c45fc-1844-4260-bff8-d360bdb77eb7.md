Функция `print()` в Python имеет несколько параметров, которые позволяют **управлять форматом вывода**.
Наиболее часто используются параметры:

```Python
sep
end
```

---

# 1. Параметр `sep` (separator)

Параметр `sep` задаёт **разделитель между значениями**, которые выводятся функцией `print()`.

По умолчанию разделитель:

```Python
' '
```

то есть **обычный пробел**.

---

### Пример без `sep`

```Python
print("яблоко", "бабочки", "огурцы")
```

Результат:

```Python
яблоко бабочки огурцы
```

---

### Пример с `sep`

```Python
print("яблоко", "бабочки", "огурцы", sep="!! ")
```

Результат:

```Python
яблоко!! бабочки!! огурцы
```

Можно использовать **любой символ или строку**.

Пример:

```Python
print(1, 2, 3, sep=" - ")
```

Результат:

```Python
1 - 2 - 3
```

---

# 2. Параметр `end`

Параметр `end` определяет **какой символ будет добавлен в конце вывода**.

По умолчанию используется:

```Python
'\n'
```

Это означает **перенос строки**.

---

### Пример обычного поведения

```Python
print("Hello")
print("world")
```

Результат:

```Python
Hello
world
```

Каждый `print()` выводится **с новой строки**.

---

### Пример с `end`

```Python
print("Hello, ", end="")
print("world!")
```

Результат:

```Python
Hello, world!
```

В данном случае перенос строки **не выполняется**.

---

### Ещё пример

```Python
print("Python", end=" ")
print("Java", end=" ")
print("C++")
```

Результат:

```Python
Python Java C++
```

---

# Итог

Параметры функции `print()`:

```Python
sep — задаёт разделитель между выводимыми элементами
end — задаёт символ или строку в конце вывода
```

По умолчанию:

```Python
sep = " "
end = "\n"
```

Эти параметры позволяют **гибко управлять форматированием вывода в консоль**.
