Функция `input()` используется для **получения данных от пользователя с клавиатуры**.

Программа останавливает выполнение и **ожидает, пока пользователь введёт данные**, после чего продолжает выполнение.

Общий синтаксис:

```Python
input("текст для пользователя")
```

Текст внутри `input()` называется **подсказкой** — он объясняет пользователю, что нужно ввести.

---

# Пример использования

```Python
name = input("Введите ваше имя: ")
print(name)
```

Пример работы программы:

```Python
Введите ваше имя: Алексей
Алексей
```

Здесь происходит следующее:

1. Программа выводит сообщение **"Введите ваше имя:"**

2. Пользователь вводит текст

3. Введённое значение сохраняется в переменной `name`

4. Программа выводит значение переменной

---

# Важная особенность `input()`

Функция `input()` **всегда возвращает строку (`str`)**.

Даже если пользователь вводит число.

Пример:

```Python
age = input("Введите ваш возраст: ")
print(age)
print(type(age))
```

Ввод пользователя:

```Python
18
```

Результат:

```Python
18
<class 'str'>
```

То есть Python считает это **строкой**, а не числом.

---

# Преобразование типов

Чтобы работать с числами, нужно **явно преобразовать строку в нужный тип**.

Для этого используются функции:

```Python
int()
float()
str()
```

---

# Преобразование в `int`

```Python
age = int(input("Введите ваш возраст: "))
print("Ваш возраст:", age)
print(type(age))
```

Результат:

```Python
Ваш возраст: 18
<class 'int'>
```

Теперь значение можно использовать в математических вычислениях.

---

# Преобразование в `float`

```Python
weight = float(input("Введите ваш вес: "))
print(weight)
```

Пример ввода:

```Python
72.5
```

Теперь значение будет иметь тип:

```Python
float
```

---

# Пример использования в вычислениях

```Python
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))

average = (num1 + num2) / 2

print("Среднее значение:", average)
```

---

# Получение целого среднего

Если нужно **целое значение**, можно использовать `int()`:

```Python
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))

average = int((num1 + num2) / 2)

print("Среднее целое значение:", average)
```

---

# Пример преобразования типов

### Строка → число

```Python
num_str = "123"
num_int = int(num_str)

print(num_str)
print(num_int)
```

---

### Число → строка

```Python
num_int = 123
num_str = str(num_int)

print(num_int)
print(num_str)
```

---

# Главное правило

Важно запомнить:

```Python
input() всегда возвращает строку (str)
```

Если нужно работать с числами, необходимо использовать:

```Python
int()
float()
```

# Итог

Функция `input()` используется для:

- получения данных от пользователя

- взаимодействия программы с пользователем

- ввода чисел, текста и других данных

Но все данные сначала поступают как:

```Python
str
```

Поэтому при необходимости их нужно **преобразовывать в нужный тип**.
