Умение составлять логические условия — важный навык для любого программиста.
Часто необходимо проверять **несколько условий одновременно**, используя логические операторы.

Наиболее распространённые составные условия:

```Python
1. Только одно
2. Каждое
3. Хотя бы одно
```

---

# 1. ТОЛЬКО ОДНО

Это условие означает, что **истинным должен быть только один из вариантов**.

Рассмотрим пример:
нужно проверить, что **одно число чётное, а другое нечётное**.

Условие:

```Python
(A % 2 == 0 and B % 2 != 0) or (A % 2 != 0 and B % 2 == 0)
```

Разберём подробнее.

### Первая часть

```Python
A % 2 == 0 and B % 2 != 0
```

Это означает:

- `A % 2 == 0` → число **A чётное**

- `B % 2 != 0` → число **B нечётное**

Оператор `and` означает, что **оба условия должны быть истинными**.

---

### Вторая часть

```Python
A % 2 != 0 and B % 2 == 0
```

Это означает:

- `A` — нечётное

- `B` — чётное

---

### Полное условие

```Python
(A % 2 == 0 and B % 2 != 0) or (A % 2 != 0 and B % 2 == 0)
```

Оператор `or` означает:

```Python
истинно первое условие ИЛИ второе
```

То есть **ровно одно число должно быть чётным**.

---

# 2. КАЖДОЕ

Это условие означает, что **все условия должны быть истинными**.

Пример:
проверить, что числа **A, B и C кратны трём**.

Условие:

```Python
(A % 3 == 0) and (B % 3 == 0) and (C % 3 == 0)
```

---

### Как работает проверка

Выражение

```Python
A % 3 == 0
```

означает:

- `A % 3` — остаток от деления A на 3

- если остаток равен `0`, значит число **делится на 3 без остатка**

Аналогичная проверка выполняется для `B` и `C`.

Оператор `and` требует, чтобы **все условия были истинными**.

---

# 3. ХОТЯ БЫ ОДНО

Это условие означает, что **достаточно истинности хотя бы одного условия**.

Пример:
проверить, есть ли среди чисел **A, B, C отрицательное число**.

Условие:

```Python
(A < 0) or (B < 0) or (C < 0)
```

Здесь оператор `or` означает:

```Python
истинно, если хотя бы одно условие True
```

---

# Пример

```Python
A = -5
B = 10
C = 3

print((A < 0) or (B < 0) or (C < 0))
```

Результат:

```Python
True
```

Потому что **число A меньше нуля**.

---

# Итог

Три основных типа составных условий:

```Python
ТОЛЬКО ОДНО
— используется комбинация AND и OR

КАЖДОЕ
— используется оператор AND

ХОТЯ БЫ ОДНО
— используется оператор OR
```

Такие условия позволяют **строить более сложную логику проверки данных в программе**.
