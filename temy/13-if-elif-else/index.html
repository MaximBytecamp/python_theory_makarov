Операторы ветвления:

§1Что такое ветвление

Ветвление — конструкция, которая выбирает действия по результату условия. Если условие равно True, выполняется один блок; если False, этот блок пропускается или выбирается другая ветка.

Условием может быть любое выражение, которое даёт логический результат: age >= 18, password == expected, is_ready.

§2Оператор if

if переводится как «если». Блок под ним выполняется только при истинном условии.

Последний print() стоит без отступа, поэтому не относится к if и выполняется при любом результате проверки.

§3Двоеточие и отступ

После условия ставится двоеточие. Все строки выбранного блока имеют одинаковый отступ — обычно четыре пробела.

Отступ — часть синтаксиса

В Python отступ не украшает код, а показывает, какие строки входят в блок. Случайный лишний или пропущенный отступ меняет логику либо вызывает ошибку.

§4Ветка else

else означает «иначе» и выполняется, когда условие if ложно. У else нет собственного условия.

В конструкции if / else выполняется ровно одна ветка: обе одновременно выполниться не могут.

§5Дополнительные ветки elif

elif означает «иначе, если». Он добавляет ещё одну проверку между if и необязательным else.

§6Порядок проверок

Python проверяет ветки сверху вниз и останавливается на первой истинной. Поэтому частные или более строгие условия ставят раньше общих.

Если начать с score >= 70, то значение 95 попадёт в первую ветку и до проверки на 90 программа не дойдёт.

§9Проверьте себя

Что выполнится, если условие после if равно False и ветки else нет?

Блок if будет пропущен, затем программа продолжит работу со строки без отступа после конструкции.

Сколько веток выполнится в одной цепочке if / elif / else?

Не более одной: первой, условие которой истинно. Если ни одно условие не подошло, выполнится else, если он есть.

Обязателен ли else?

Нет. Можно использовать только if или цепочку if / elif.

Итог главы

if начинает проверку, elif добавляет варианты, else обрабатывает оставшийся случай. Двоеточие открывает блок, а отступ показывает его границы. Цепочка просматривается сверху вниз и выполняет не более одной ветки.
