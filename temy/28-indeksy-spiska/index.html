3.5

Перебор списка
по индексам

for index in range(len(items)) перебирает не элементы, а их позиции. Такой подход нужен для изменения списка, сравнения соседей и алгоритмов, зависящих от индекса.

§1Разбор конструкции

Пусть numbers = [10, 20, 30, 40]. Выражение len(numbers) даёт 4, а range(4) — индексы 0, 1, 2, 3.

§2Индекс и элемент

index хранит позицию, а numbers[index] получает элемент на этой позиции.

§4Изменение элементов

При обычном переборе переменная получает значение. Для замены элемента нужно присваивание именно в позицию списка.

§5Соседние элементы

Индекс позволяет одновременно получить текущий и следующий элементы.

§6Почему len() − 1

В списке из четырёх элементов последний индекс равен 3. Для него выражение numbers[index + 1] потребовало бы несуществующий индекс 4. Поэтому цикл останавливают на предпоследней позиции.

Общее правило

Если внутри используется смещение index + k, диапазон нужно сократить так, чтобы последний индекс со смещением оставался допустимым.

enumerate() подробно разбирается в главе 3.7. Он удобнее, когда индекс нужно лишь вывести или проверить, но не использовать для изменения позиции.

§8Когда нужны индексы

  • изменить элементы исходного списка;
  • обратиться к предыдущему или следующему элементу;
  • сравнить позиции в алгоритме сортировки или поиска;
  • обработать только определённый диапазон позиций.

Если ни одна из этих причин не подходит, обычный перебор элементов читается проще.

§10Проверьте себя

Что создаёт range(len(numbers))?

Допустимые индексы списка от нуля до len(numbers) - 1.

Зачем сокращать диапазон при обращении к index + 1?

Чтобы для последней итерации следующий индекс продолжал существовать.

Когда лучше обычный for number in numbers?

Когда нужен только сам элемент и позиция не используется.

§11Шпаргалка

Все индексыrange(len(items))
Текущий элементitems[index]
Следующийitems[index + 1]
Соседние парыrange(len(items) - 1)

Итог главы

len() даёт размер, range() превращает его в допустимые индексы, а items[index] получает или изменяет элемент. Индексный перебор нужен не всегда: используйте его, когда задача действительно зависит от позиции.
