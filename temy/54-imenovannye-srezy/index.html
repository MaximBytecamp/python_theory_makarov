§1Двоеточия создают объект с параметрами среза

Когда Python видит data[1:7:2], он передаёт объекту data правило выбора, эквивалентное slice(1, 7, 2). Функция slice() позволяет сохранить это правило отдельно от данных.

data[1:7:2]↔data[slice(1, 7, 2)]

§2Создание объекта slice

ЗаписьСоответствующий срез
slice(stop)[:stop]
slice(start, stop)[start:stop]
slice(start, stop, step)[start:stop:step]

§3Обычный и объектный срез эквивалентны

slice не хранит последовательность и не извлекает элементы сам. Он только хранит три параметра, которые последовательность применит позже.

§4Параметры доступны как атрибуты

Атрибуты доступны только для чтения: после создания объект slice не меняется.

§5Пропущенная часть записывается как None

§6Отрицательный шаг меняет направление

Шаг не может быть нулём: slice(None, None, 0) создаётся, но применение такого среза вызывает ValueError.

§8Имя объясняет смысл границ

Заглавные имена показывают, что правила считаются константами проекта. Теперь числа определены один раз, а место использования читается по смыслу.

§10indices() приводит границы к длине

Метод учитывает длину конкретной последовательности, отрицательные границы и направление шага. Обычно Python делает это сам, но indices() полезен при реализации собственных последовательностей.

§11Практический пример: поля фиксированного формата

Такой подход оправдан для действительно фиксированного формата. Для CSV, JSON и строк с разделителями следует применять инструменты этих форматов.

§13Проверьте себя

Что хранит объект slice?

Три параметра: start, stop и step. Самих элементов последовательности в нём нет.

Чему эквивалентен slice(None, None, -1)?

Обычному срезу [::-1], который читает последовательность в обратном направлении.

Когда именованный срез улучшает код?

Когда одни границы повторяются или имеют предметный смысл, который можно выразить понятным именем.

Итог главы

slice хранит правило выбора элементов отдельно от последовательности. Именованный срез полезен, когда границы повторяются, передаются в функцию или выражают поле фиксированного формата.
