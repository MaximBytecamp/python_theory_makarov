5.4

Кодирование строк:
encode() и decode()

Текст в программе имеет тип str, а файл или сеть передаёт байты. encode() кодирует символы в bytes, decode() восстанавливает текст по той же кодировке.

§1str хранит текст, bytes — числа от 0 до 255

ТипСодержимоеПример
strсимволы Unicode"Привет"
bytesпоследовательность байтовb"hello"

Кодировка задаёт соответствие между символами и байтами. Один символ Unicode может занимать в UTF-8 несколько байтов.

§2encode() переводит str в bytes

Запись text.encode() равнозначна text.encode("utf-8").

§3decode() переводит bytes в str

decode() — метод объекта bytes, а не строки.

§4Для обратимости нужна та же кодировка

strencode →bytes
bytesdecode →str

§5Длина строки и байтов может различаться

Ограничение в байтах нельзя проверять только через len(text). Сначала нужен результат кодирования.

§6UTF-8 — основной выбор для обмена текстом

КодировкаЧто поддерживаетЗамечание
utf-8весь Unicodeстандартный выбор для новых текстовых форматов
ascii128 базовых символовкириллица и большинство знаков не входят
latin-1256 кодовых позицийкаждый байт декодируется, но не как UTF-8

Конкретная система может требовать другую кодировку. Её имя должно быть частью формата обмена, а не догадкой при чтении.

§8Неверная кодировка ломает декодирование

Иногда неверная кодировка не вызывает исключение, но возвращает искажённый текст. Поэтому отсутствие ошибки ещё не доказывает правильность выбора.

§9errors задаёт реакцию на несовместимые данные

strict используется по умолчанию и вызывает исключение. ignore теряет данные, поэтому его нельзя выбирать без явного требования.

§11Проверьте себя

Какой тип возвращает encode()?

bytes.

Почему кодировку нужно знать при декодировании?

Одни байты могут означать разные символы в разных кодировках.

Чем опасен errors="ignore"?

Метод молча удаляет данные, которые нельзя преобразовать.

Итог главы

encode() создаёт байты из строки, decode() создаёт строку из байтов. Обратимость требует согласованной кодировки, а режим errors определяет, будет ли несовместимость исключением или потерей данных.
