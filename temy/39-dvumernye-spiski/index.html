Двумерные списки

Двумерный список — список строк, где каждая строка тоже является списком. Такая структура представляет таблицу, игровое поле или матрицу и требует двух индексов: строки и столбца.

§1Список, элементы которого — списки

Внешний список хранит строки. Число столбцов определяется длиной конкретной строки; Python не требует, чтобы все строки имели одинаковую длину.

§2Доступ через два индекса

matrix[row][column] выполняется слева направо: сначала выбирается список-строка, затем значение внутри него.

§3Перебор значений

Внешний цикл получает строки, внутренний — значения выбранной строки.

§4Перебор по индексам

Индексы нужны, если важно изменить ячейки или узнать их координаты. Длина внутреннего range() берётся у текущей строки.

§5Создание матрицы

Цикл создаёт новый список для каждой строки. Включение записывает ту же схему компактнее.

§6Почему [[0] * columns] * rows опасно

Умножение внешнего списка повторяет одну и ту же внутреннюю строку. Поэтому изменение одной ячейки проявляется во всех строках.

§7Изменение структуры

§8Срезы двумерного списка

Срез внешнего списка выбирает целые строки. Срез одной строки выбирает столбцы только в этой строке.

§9Поверхностная и глубокая копия

matrix.copy() создаёт новый внешний список, но внутренние строки остаются общими. Для полной независимости всех уровней применяется copy.deepcopy().

§10Три и больше измерений

Каждый дополнительный уровень списка добавляет индекс: cube[layer][row][column]. Используйте такую структуру только когда смысл каждого уровня понятен.

§11Где применяются двумерные списки

  • таблицы и небольшие матрицы;
  • игровые поля и карты;
  • пиксели небольшого изображения;
  • строки табличного файла;
  • расписания и сетки значений.

Для крупных числовых матриц и векторных операций обычно выбирают специализированную библиотеку вроде NumPy; обычный список остаётся удобным универсальным контейнером.

§13Проверьте себя

Что сначала выбирает matrix[2][1]?

Строку с индексом 2, затем элемент этой строки с индексом 1.

Почему нельзя создавать строки выражением [[0] * 3] * 3?

Внешний список повторяет одну внутреннюю строку, поэтому её изменение видно во всех позициях.

Чем поверхностная копия отличается от глубокой?

Поверхностная копирует только внешний контейнер; глубокая рекурсивно создаёт независимые вложенные объекты.

Итог главы

Двумерный список хранит списки-строки. Доступ к ячейке требует двух последовательных индексов, а полный перебор — двух циклов. Каждую строку при создании нужно формировать отдельно; для полной копии вложенной структуры используется глубокое копирование.
