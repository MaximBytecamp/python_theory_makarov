§1reverse(): изменить порядок

reverse() разворачивает исходный список на месте и возвращает None.

Для сортировки по убыванию точнее писать numbers.sort(reverse=True), а не сначала сортировать и затем разворачивать.

§2Новый обратный список

Если исходный порядок нужно сохранить, можно использовать срез с шагом -1 или функцию reversed().

§3copy(): поверхностная копия

copy() создаёт новый внешний список. Для обычных значений его можно менять независимо от исходного.

§4Вложенные списки и deepcopy()

Поверхностная копия копирует только внешний список. Вложенные изменяемые элементы остаются общими для оригинала и копии.

Для независимого копирования всех уровней используют deepcopy().

§5len(): количество элементов

len(collection) — встроенная функция, а не метод списка. Она возвращает количество элементов и работает со строками, кортежами, словарями и множествами.

§6del: удаление

del — оператор. Он может удалить элемент по индексу, срез или само имя переменной.

del numbers удаляет имя. Если тот же список доступен через другое имя, он остаётся доступным через него. Отдельные элементы строк и кортежей удалить нельзя, потому что эти типы неизменяемы.

§7in и not in

in проверяет наличие равного элемента, а not in — его отсутствие. Результат всегда логический.

§8Подсписок как элемент

Для списка оператор in не ищет непрерывный фрагмент. Он сравнивает проверяемое значение с каждым отдельным элементом.

§10Проверьте себя

Меняет ли reverse() исходный список?

Да. Метод работает на месте и возвращает None.

Почему вложенный список меняется и в поверхностной копии?

Новый только внешний список; вложенный изменяемый объект остаётся общим.

Является ли len() методом списка?

Нет, это встроенная функция: len(items).
