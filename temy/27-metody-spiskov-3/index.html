§1reverse(): изменить порядок

reverse() разворачивает исходный список на месте и возвращает None.

Метод не сортирует, а только переворачивает: элементы идут в обратном порядке относительно того, в каком лежали. Для сортировки по убыванию точнее писать numbers.sort(reverse=True), а не сортировать и затем разворачивать.

§2Новый обратный список

Если исходный порядок нужно сохранить, используют срез с шагом -1: он строит новый список, не трогая старый.

ЗаписьИсходный списокРезультат
items.reverse()изменяетсяNone
items[::-1]не изменяетсяновый список
reversed(items)не изменяетсяобъект для перебора, не список

reversed() удобен прямо в заголовке цикла: for item in reversed(items). Чтобы получить из него именно список, его оборачивают в list().

§3copy(): поверхностная копия

copy() создаёт новый список с теми же элементами. Как показала глава 3.10, простое присваивание такого эффекта не даёт — оно лишь добавляет второе имя.

§4Три способа скопировать

Одинаковый результат дают три разные записи. Выбор между ними — вопрос привычки и читаемости.

ЗаписьОсобенность
items.copy()самая явная, читается как «копия»
list(items)работает с любой коллекцией, не только со списком
items[:]короткая, но неочевидная для начинающих

Все три создают поверхностную копию — новый внешний список с теми же самыми элементами внутри. Что это значит на практике, показывают §6 и §7.

§5== и is

Есть два разных вопроса: «одинаковое ли содержимое?» и «один ли это объект?». Для них существуют два разных оператора.

ОператорЧто проверяетКогда использовать
==совпадает ли содержимоепочти всегда
isэто один и тот же объектпроверить, копия перед вами или второе имя

Строка a is c даёт True — это и есть признак того, что c = a копией не было. Оператор is в обычном коде нужен редко; его основное штатное применение — проверка if value is None.

§6Вложенные списки

Поверхностная копия копирует только внешний список. Элементы в неё переносятся как есть — а если элемент сам является списком, обе коллекции продолжают ссылаться на один и тот же вложенный объект.

При этом внешние списки всё-таки независимы. Добавление элемента в копию оригинала не касается:

Где именно проходит граница

Копия защищает от изменений первого уровня: copied[0] = ..., copied.append(...), copied.remove(...). Изменения внутри элементов — copied[0][0] = ..., copied[0].append(...) — видны в обеих коллекциях.

§7deepcopy(): все уровни

Когда нужна независимость на всех уровнях вложенности, берут deepcopy() из модуля copy. Он проходит структуру целиком и создаёт новые объекты для каждого уровня.

СпособВнешний списокВложенные списки
copied = originalобщийобщие
copied = original.copy()новыйобщие
copied = copy.deepcopy(original)новыйновые

Для плоского списка чисел или строк copy() достаточно: числа и строки неизменяемы, и «поделиться» ими безопасно. deepcopy() нужен там, где внутри лежат списки, словари или другие изменяемые объекты.

§8len(): количество элементов

len(collection) — встроенная функция, а не метод списка. Она возвращает количество элементов и работает со строками, кортежами, словарями и множествами.

Третий пример показывает важное: для вложенного списка len() считает только верхний уровень — в нём два элемента, и каждый из них список. Та же функция работает с кортежами, словарями и множествами из модуля 4. Записи items.len() не существует — это функция, а не метод.

§9del: удаление

del — оператор, а не метод, поэтому и записывается иначе: ключевое слово перед тем, что удаляют. Он может убрать элемент по индексу, целый срез или само имя переменной.

Второе удаление работает уже с изменённым списком: срез 1:3 убирает из [1, 3, 4, 5] элементы 3 и 4. Правая граница среза не включается — как и в range().

del numbers без индекса удаляет само имя. Если тот же список доступен под другим именем, он остаётся доступным через него. Отдельные элементы строк и кортежей удалить нельзя: эти типы неизменяемы.

§10in и not in

in проверяет наличие равного элемента, а not in — его отсутствие. Результат всегда логический, поэтому его удобно ставить прямо в условие.

Третья строка показывает важное различие: для строки оператор in ищет непрерывный фрагмент, а не отдельный символ. Для списка правило другое — о нём следующий параграф.

§11Подсписок как элемент

Для списка in не ищет непрерывный фрагмент. Он сравнивает проверяемое значение с каждым отдельным элементом целиком.

В первом случае элементы списка — числа 1, 2, 3, 4, и ни один из них не равен списку [2, 3]. Во втором случае такой элемент действительно есть.

ПроверкаЧто ищет in
"th" in "Python"непрерывную подстроку
[2, 3] in [1, 2, 3]элемент, равный списку [2, 3]

§13Метод, функция или оператор

За три главы набралось три разные формы записи. Различать их полезно: от формы зависит и синтаксис, и то, меняется ли исходная коллекция.

ФормаКак выглядитПримеры
методitems.действие()append(), sort(), reverse(), copy()
функциядействие(items)len(), sum(), sorted(), reversed()
операторключевое слово или знакdel, in, not in, +, is

Закономерность почти без исключений: методы списка меняют его на месте и возвращают None, а функции ничего не меняют и возвращают новый результат. Пара sort() / sorted() — самая наглядная иллюстрация этого правила.

§15Проверьте себя

Меняет ли reverse() исходный список?

Да. Метод работает на месте и возвращает None. Новый список даёт срез items[::-1].

В чём разница между == и is?

== сравнивает содержимое, is проверяет, что это один и тот же объект. У копии содержимое равно, а объект другой.

Почему вложенный список меняется и в поверхностной копии?

Новый создаётся только внешний список; вложенные изменяемые объекты остаются общими.

Когда copy() достаточно, а когда нужен deepcopy()?

copy() хватает для плоских списков из чисел и строк. deepcopy() нужен, если внутри лежат списки, словари или другие изменяемые объекты.

Чему равна len([[1, 2], [3, 4]])?

2: считается только верхний уровень.

Является ли len() методом списка?

Нет, это встроенная функция: len(items).

Итог главы

reverse() меняет порядок исходного списка, copy() создаёт поверхностную копию, len() считает элементы верхнего уровня, del удаляет по позиции или срезу, а in проверяет наличие отдельного элемента. Поверхностная копия защищает только внешний уровень: для вложенных структур нужен deepcopy().
