Значения and,
or и None

and и or возвращают один из своих операндов, а не обязательно логический тип. Это позволяет задавать запасное значение, но требует отличать Falsy-данные от специального отсутствия — None.

§1Какое значение возвращает and

and идёт слева направо и возвращает первое Falsy-значение. Если все операнды истинны, результатом становится последний.

§2Короткое вычисление and

После первого ложного операнда итог уже известен, поэтому выражения справа не вычисляются.

§3Какое значение возвращает or

or возвращает первое Truthy-значение. Если все операнды ложны, возвращается последний.

§4Запасное значение через or

Шаблон value or default выбирает запасной вариант, если первое значение Falsy.

Ноль может быть данными

Если 0, пустая строка или пустой список являются допустимыми значениями, value or default ошибочно заменит их. Тогда проверяйте value is None.

§5Короткое вычисление or

После первого истинного операнда остальная цепочка не нужна.

§6Что означает None

None обозначает отсутствие значения. Его часто возвращает функция, когда результата нет, или использует параметр, для которого значение пока не задано.

§7Проверка is None

Для None принята проверка идентичности: value is None и value is not None. Она точно выражает намерение и не зависит от правил равенства других типов.

§8Falsy — не то же самое, что None

None является Falsy, но не каждое Falsy-значение означает отсутствие. Число 0 может быть полноценным результатом.

§9is и == решают разные задачи

ОператорВопросОбычное применение

Не заменяйте обычное сравнение чисел или строк оператором is. Для равенства данных используется ==.

§11Проверьте себя

Что вернёт "" or "гость"?

Строку "гость", потому что первый операнд пуст и считается Falsy.

Почему if value: не заменяет if value is not None:?

Первая проверка отклоняет все Falsy-значения, включая допустимые 0, "" и [].

Когда используется ==, а когда is?

== сравнивает значения; is в этой теме нужен для точной проверки None.

§12Шпаргалка

andпервое ложное или последнее истинное
orпервое истинное или последнее ложное
Нет значенияvalue is None
Значение заданоvalue is not None

Итог главы

and возвращает первый ложный операнд либо последний истинный, а or — первый истинный либо последний ложный. Оба оператора останавливаются, как только результат определён. Проверка истинности отвечает на вопрос о содержимом, а is None — о специальном отсутствии значения.
