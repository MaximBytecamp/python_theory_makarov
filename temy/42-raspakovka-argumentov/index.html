6.6

Распаковка
аргументов * и **

При вызове функции * превращает итерируемый объект в отдельные позиционные аргументы, а ** — отображение в именованные. Похожие записи объединяют коллекции и разделяют последовательность между переменными.

§2Звёздочка при вызове функции

Работают список, кортеж, range и другие итерируемые объекты. Количество полученных значений должно подходить сигнатуре функции.

§3Две звёздочки при вызове

Ключи отображения становятся именами аргументов, значения — передаваемыми данными. Для обычной функции ключи должны быть строками и совпадать с допустимыми именами параметров.

§4* и ** в одном вызове

Сначала передаются позиционные аргументы, затем именованные. Один параметр не должен получить значение дважды.

§5Несколько распаковок в вызове

§6Распаковка внутри списка

Звёздочка добавляет в новый список каждый элемент указанного итерируемого объекта.

§7Распаковка внутри словаря

Две звёздочки копируют пары «ключ — значение». Если ключ повторяется, более позднее значение заменяет предыдущее.

§8Распаковка при присваивании

Количество имён должно совпадать с количеством значений.

§9Звёздочка собирает остаток

В присваивании только одно имя может иметь звёздочку. Оно получает список из всех значений, не распределённых между остальными именами.

§10Автоматическая распаковка в цикле

Цикл может сразу разделить каждый элемент на несколько имён. Звёздочка не нужна, если число частей известно.

§12Проверьте себя

Что делает *items в вызове функции?

Передаёт каждый элемент итерируемого объекта как отдельный позиционный аргумент.

Что требуется от словаря в function(**data)?

Его ключи должны быть строками и подходить именам параметров функции, если она не принимает произвольные **kwargs.

Какой тип получает имя со звёздочкой при присваивании?

Список со всеми оставшимися элементами.

Итог главы

В вызове функции * распаковывает итерируемый объект в позиционные аргументы, а ** — отображение в именованные. В литералах эти символы объединяют коллекции, а звёздочка в присваивании собирает оставшиеся элементы в список.
