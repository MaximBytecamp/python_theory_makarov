6.5

Виды аргументов
и упаковка

Параметры описываются в определении функции, а аргументы передаются при вызове. Python умеет связывать их по позиции и имени, задавать значения по умолчанию и собирать произвольное количество значений через *args и **kwargs.

§1Параметр и аргумент

Параметр — имя во время описания функции. Аргумент — конкретное значение во время вызова. Разные способы передачи определяют, как Python свяжет их друг с другом.

§2Позиционные аргументы

Значения связываются с параметрами слева направо, поэтому порядок меняет смысл.

§3Именованные аргументы

Имя параметра можно указать в вызове. Тогда порядок именованных аргументов не влияет на связывание.

После первого именованного аргумента нельзя добавлять обычный позиционный: greet(name="Алиса", 30) — синтаксическая ошибка.

§4Значения параметров по умолчанию

Если аргумент не передан, используется значение из сигнатуры. Обязательные параметры записываются раньше параметров со значением по умолчанию.

Изменяемое значение по умолчанию

Не используйте [] или {} как изменяемое значение по умолчанию: оно создаётся один раз и сохраняется между вызовами. Обычно берут None, а новую коллекцию создают внутри.

§5Произвольные позиционные аргументы: *args

Параметр со звёздочкой собирает оставшиеся позиционные аргументы в кортеж. Имя args принято по соглашению, но технически может быть другим.

§6Произвольные именованные аргументы: **kwargs

Параметр с двумя звёздочками собирает оставшиеся именованные аргументы в словарь.

§7*args и **kwargs вместе

§8Параметры только для позиции: /

Параметры слева от / разрешено передавать только позиционно. Сам символ не является параметром.

§9Параметры только по имени: *

Параметры справа от отдельной * нужно указывать по имени. Это делает вызов с несколькими похожими настройками понятнее.

§12Проверьте себя

Чем параметр отличается от аргумента?

Параметр записан в определении функции, аргумент — конкретное значение в её вызове.

Во что упаковываются *args и **kwargs?

*args — в кортеж, **kwargs — в словарь.

Что означает отдельная звёздочка в сигнатуре?

Следующие за ней параметры можно передавать только по имени.

§13Шпаргалка

Итог главы

Аргументы связываются с параметрами по позиции или имени. Значение по умолчанию делает аргумент необязательным, *args собирает лишние позиционные значения в кортеж, а **kwargs — именованные в словарь. Символы / и * ограничивают допустимый способ вызова.
