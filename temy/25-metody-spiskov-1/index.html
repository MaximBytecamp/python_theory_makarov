Методы списков:
добавление и удаление

append(), extend(), insert() и remove() изменяют исходный список: добавляют один элемент, расширяют набор, вставляют по позиции или удаляют по значению.

§1Что такое метод

Метод — действие, принадлежащее объекту. Сначала пишется список, затем точка и вызов метода: список.метод(аргументы).

§2append(): один элемент

append(value) добавляет один объект в конец списка.

Аргумент может быть списком, строкой, словарём или другим объектом. В любом случае добавляется ровно один элемент.

§3append() и результат None

append() меняет список и не возвращает новый. Результат вызова равен None.

Частый сценарий — постепенно строить список в цикле.

§4extend(): несколько элементов

extend(iterable) перебирает переданный объект и добавляет каждый его элемент отдельно.

Строка тоже итерируема, поэтому extend("abc") добавит три отдельных символа.

§5append() или extend()

ВызовЧто добавляетсяРезультат

§6insert(): вставка по индексу

insert(index, value) вставляет один элемент перед указанной позицией.

insert(0, value) добавляет в начало. Слишком большой положительный индекс приводит к вставке в конец. Отрицательные индексы отсчитывают позицию с конца.

§7remove(): удаление значения

remove(value) ищет и удаляет только первое равное значение.

Если значения нет, возникает ValueError. Когда отсутствие допустимо, сначала используют проверку in.

§8Изменение на месте

Все четыре метода меняют исходный список и обычно возвращают None. В отличие от них выражение numbers + [4] создаёт новый список.

Не присваивайте результат обратно

Запись numbers = numbers.append(4) сначала изменит список, а затем заменит переменную значением None.

§10Проверьте себя

Чем append() отличается от extend()?

append() добавляет один объект, а extend() добавляет отдельно все элементы переданного итерируемого объекта.

Что возвращает insert()?

None: метод меняет список на месте.

Что удаляет remove(value)?

Первое вхождение указанного значения.

Итог главы

append() добавляет один объект, extend() — элементы итерируемого объекта, insert() вставляет по индексу, а remove() удаляет первое совпавшее значение. Все методы изменяют список на месте.
