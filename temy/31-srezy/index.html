Срезы в Python

Срез выбирает сразу несколько элементов последовательности. Три позиции — начало, граница и шаг — позволяют получить диапазон, каждый второй элемент или последовательность в обратном порядке.

§1Что такое срез

Срез — выбор части последовательности по записи sequence[start:stop:step]. Обычный срез создаёт новую последовательность и не меняет исходную.

ЧастьСмыслПо умолчанию
startиндекс первого выбранного элементаначало последовательности
stopграница, которая не входит в результатконец последовательности
stepшаг между элементами1

§2Начало входит, граница не входит

В срезе [1:4] элемент с индексом 1 попадёт в результат, а элемент с индексом 4 уже нет.

§3Шаг среза

Третья позиция задаёт расстояние между выбранными элементами. Пропущенные start и stop означают всю последовательность.

§4Отрицательные индексы

Отрицательные индексы отсчитываются с конца: -1 — последний элемент, -2 — предпоследний. Срез [-3:] выбирает последние три элемента.

§5Обратный порядок

Отрицательный шаг идёт справа налево. Запись [::-1] создаёт перевёрнутую копию всей последовательности.

§6Выход за границы

Один индекс вне диапазона вызывает IndexError, а срез спокойно ограничивается доступными элементами.

§7Изменение части списка

Слева от = срез обозначает участок исходного списка. Количество новых элементов может отличаться, поэтому список способен стать длиннее или короче.

Два разных действия

part = numbers[1:3] создаёт новую последовательность. numbers[1:3] = values изменяет исходный список.

§8Удаление через срез

del удаляет обозначенный срез из изменяемого списка.

§9Копирование списка

Полный срез items[:] создаёт новый внешний список. То же делают items.copy() и list(items).

Поверхностная копия

Если внутри лежат другие изменяемые списки, полный срез не копирует каждый вложенный список отдельно. Глубокое копирование — отдельная тема.

§10Строки и кортежи

Синтаксис одинаков для разных последовательностей. Строка возвращает строку, кортеж — кортеж, список — список.

§12Проверьте себя

Какие индексы выберет items[2:5]?

2, 3 и 4: начало входит, граница 5 — нет.

Меняет ли items[::-1] исходный список?

Нет. Выражение возвращает новую последовательность в обратном порядке.

Чем получение среза отличается от присваивания в срез?

Получение возвращает новую последовательность, а присваивание заменяет часть исходного списка.

Итог главы

Срез выбирает часть последовательности по правилу [start:stop:step]. Начало входит в результат, граница не входит, а шаг управляет направлением и частотой выбора. Получение среза создаёт новую последовательность; присваивание и del со срезом изменяют список.
