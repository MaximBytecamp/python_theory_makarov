§1Два значения: True и False

Логический тип (bool, от boolean) — тип данных, у которого всего два возможных значения: True — истина и False — ложь. Третьего не дано, и в этом вся его польза: такое значение — готовый ответ на вопрос «да или нет», по которому программа выбирает, что делать дальше.

Пишутся оба слова с заглавной буквы и без кавычек. Это не текст, а значения языка — такие же полноценные, как 10 или 3.14.

true и false — не то же самое

Строчная запись true вызовет NameError: name 'true' is not defined: язык ищет переменную с таким именем и не находит. А "True" в кавычках — это строка из четырёх букв, а вовсе не истина. В других языках принято иначе, поэтому ошибка живучая: в Python верна только запись True и False.

§2Откуда берутся булевы значения

Записывать True руками приходится редко. Обычно логическое значение получается само — как результат сравнения.

Выражение age > 18 не «спрашивает» ничего у пользователя — оно вычисляется и превращается в одно из двух значений, как 2 + 3 превращается в 5. Операторов сравнения шесть:

ОператорПроверяетПримерРезультат
==равно5 == 5True
!=не равно5 != 5False
>больше7 > 3True
<меньше7 < 3False
>=больше или равно5 >= 5True
<=меньше или равно4 <= 3False

Не путайте = и ==. Один знак — присваивание, «положить значение в переменную». Два знака — сравнение, «проверить, совпадают ли». Это разные операции, и подменять одну другой язык не станет.

§3bool — это подкласс int

Одна особенность реализации объясняет многое из того, что вы увидите дальше: в Python логический тип является подклассом целых чисел. Проще говоря, True равно единице, а False — нулю.

Выводятся они при этом по-своему — True и False, а не 1 и 0. Практическая польза от этого свойства есть: сумма логических значений равна количеству истинных среди них. Складывать True с True просто ради результата 2 не нужно, но знать, почему это работает, полезно.

Обратное преобразование тоже определено: функция bool() приводит к логическому типу любое значение. Правило одно — «пусто или ноль» считается ложью, всё остальное истиной.

§4Оператор and

Из простых проверок собирают составные — для этого есть три логические операции. Первая, and (И), даёт True только тогда, когда истинны оба условия.

ВыражениеРезультат
True and TrueTrue
True and FalseFalse
False and TrueFalse
False and FalseFalse

Такая таблица называется таблицей истинности — она перечисляет все возможные сочетания и результат для каждого. Житейский образ точный: «пойду, если будет тепло и не будет дождя». Хватит одного невыполненного условия, чтобы всё выражение стало ложным.

Здесь проверяется сразу двумя условиями: возраст больше 18 и человек является студентом. Первое даёт True, второе — тоже, значит и всё выражение истинно.

§5Оператор or

Операция or (ИЛИ) даёт True, если истинно хотя бы одно из условий.

ВыражениеРезультат
True or TrueTrue
True or FalseTrue
False or TrueTrue
False or FalseFalse

Результат истинный, потому что одно из условий выполнено: температура выше двадцати. Дождя при этом нет, но or и не требует, чтобы выполнялись оба.

Учтите, что or в языке означает не то же, что «или» в разговоре. Житейское «чай или кофе» подразумевает выбор одного, а or истинно и тогда, когда верны оба условия сразу. Как записать настоящее «ровно одно из двух» — разберём в следующей главе.

§6Оператор not

Операция not (НЕ) работает с одним значением и меняет его на противоположное.

ВыражениеРезультат
not TrueFalse
not FalseTrue

С not легко переусердствовать. Выражение not (age < 18) верно, но age >= 18 говорит то же самое прямо и читается быстрее. Отрицание хорошо там, где условие уже лежит в переменной с говорящим именем: not rain — понятно с первого взгляда.

На полях: порядок операций

Приоритет у трёх операций разный: сначала выполняется not, затем and, затем or. Поэтому a or b and c означает a or (b and c). Держать это в голове необязательно — надёжнее расставить скобки. Скобки не замедляют программу, но избавляют читателя от необходимости вспоминать таблицу приоритетов.

§7Проверки на живых данных

Соберём главу в одну программу. Условия здесь ещё ничего не решают — мы просто выводим результат проверки, — но именно эти выражения станут условиями ветвления в следующих главах.

Приём, который стоит перенять: результат проверки положен в переменную с говорящим именем. Строка is_adult and is_experienced читается как обычная фраза, тогда как age >= 18 and experience >= 3 требует разбирать числа. Имена для логических переменных обычно начинают с is_ или has_ — так сразу видно, что внутри «да или нет».

§9Проверьте себя

Что выведет print(5 > 3) и какого типа будет результат?

True, тип bool. Сравнение — это выражение: оно вычисляется и превращается в одно из двух логических значений.

Каким будет результат True and False or True?

True. Сначала выполняется and: True and False даёт False. Затем False or True даёт True. Чтобы не полагаться на приоритеты, ту же мысль лучше записать со скобками: (True and False) or True.

Почему print(True + True) выводит 2?

Потому что bool — подкласс int, и True равно единице. В арифметическом выражении логическое значение ведёт себя как число. На практике это свойство используют, чтобы посчитать количество истинных проверок.

Как записать проверку «возраст от 18 до 65 включительно»?

Двумя способами: age >= 18 and age <= 65 либо короче — 18 <= age <= 65. Цепочку сравнений Python поддерживает, и читается она как в математике.

Задача для практики: пользователь вводит число. Выведите True, если оно чётное и положительное.

Два условия объединяются через and, чётность проверяется остатком из главы 1.8:

  • number = int(input("Число: "))
  • print(number % 2 == 0 and number > 0)

Понятнее будет с промежуточными именами: is_even = number % 2 == 0, is_positive = number > 0, а затем print(is_even and is_positive).

§10Шпаргалка

Сравнения == != > < >= <= # результат — bool
and — оба True and True → True True and False → False

not — наоборот not True → False not False → True
Приоритет not → and → or # надёжнее — скобки

Итог главы

Логический тип хранит одно из двух значений — True или False, — и чаще всего они получаются сами, как результат сравнения. Три операции собирают из простых проверок составные: and требует истинности обоих условий, or довольствуется одним, not меняет значение на противоположное. Пока мы только выводим результат на экран, но именно эти выражения станут условиями, по которым программа выбирает путь.
