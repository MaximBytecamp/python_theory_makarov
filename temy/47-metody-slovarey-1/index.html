§1Функция или метод

Со словарём работают два вида инструментов, и различать их полезно по форме записи — как в главе 3.12.

ФормаПримерСмысл
универсальная функцияlen(data)работает со многими коллекциями
метод словаряdata.get(key)описывает операцию именно словаря

Функций из первой строки вы уже знаете почти все — они разбирались в главе 3.14 для списков. Со словарём они работают так же, но с одной оговоркой, которой посвящён следующий параграф.

§2По умолчанию — ключи

Когда словарь передают функции напрямую, перебираются его ключи. Не значения и не пары.

Это правило действует везде: в for, в sorted(), в max(), в sum(), в list(). Прежде чем вызвать любую функцию, стоит задать себе один вопрос: с чем она должна работать — и дописать .values() или .items(), если ответ не «с ключами».

§3len(): число пар

Здесь двусмысленности нет: ключей и значений поровну, поэтому len(prices), len(prices.values()) и len(prices.items()) дадут одно и то же.

§5Ключ с наибольшим значением

Обычно нужен именно третий вариант: не имя и не балл по отдельности, а имя того, у кого балл наибольший.

Разберём запись. Перебираются по-прежнему ключи, но параметр key сообщает: «сравнивай их не напрямую, а по результату scores.get от каждого». Метод get передаётся без скобок — как значение, а не как вызов. Подробно этот приём разбирается в главе 6.10.

§6sum()

Складывать имеет смысл значения, поэтому values() здесь обязателен.

Забытый values() здесь как раз заметен сразу — Python попытается складывать строки с числом.

Повезло не всегда: если ключи числовые, ошибки не будет — просто сложатся не те числа.

§7sorted(): три варианта

Функция возвращает список и не меняет словарь. Что окажется в списке — снова зависит от области.

Третья строка сортирует пары, а кортежи сравниваются по первому элементу — то есть по ключу. Чтобы упорядочить по значению, нужен key.

§8Сортировка по значению

Первый способ короче, но даёт только ключи. Второй сохраняет и значение: item — это пара (ключ, значение), а item[1] — её значение. Запись lambda разбирается в главе 6.9; пока достаточно читать её как «взять из пары второй элемент».

§9all() и any()

Эти функции сворачивают набор проверок в одно значение и почти всегда применяются к values().

Истинность считается по правилам главы 3.16, поэтому годятся не только True и False: пустая строка, ноль и пустой список тоже ложны. У пустой коллекции результаты запоминают отдельно: all([]) — True, any([]) — False.

§10enumerate() и reversed()

Обе функции опираются на порядок добавления пар, который словарь сохраняет.

Здесь снова перебираются ключи: reversed(stages) разворачивает именно их. Для пар в обратном порядке нужен reversed(stages.items()).

§11zip(): из двух списков

Самый частый способ построить словарь из параллельных данных.

zip() заканчивает работу вместе с самой короткой последовательностью — лишние элементы молча отбрасываются. Если списки должны быть одинаковой длины, это стоит проверить заранее.

§12map() и filter()

Эти функции тоже перебирают переданный объект, поэтому и здесь нужно указать область.

Обратите внимание на разницу: map() по значениям теряет ключи, поэтому результат — список. filter() по парам их сохраняет, и результат можно снова свернуть в словарь. Ту же работу короче делает словарное включение из главы 4.10.

§13dict.fromkeys()

Метод создаёт словарь из набора ключей с одинаковым начальным значением.

Второй аргумент необязателен: без него все значения станут None. Обратите внимание на форму записи — dict.fromkeys() вызывается у самого типа, а не у существующего словаря.

§14Ловушка общего значения

Метод ставит во все пары один и тот же объект. Для None и чисел это незаметно — они неизменяемы. Для списка последствия наглядны.

Это та же история, что с двумя именами одного списка из главы 3.10: список создан один раз, а ссылок на него теперь две. Решение — словарное включение, которое создаёт новый список на каждом шаге.

§15get() не создаёт ключ

Метод get() разбирался в главе 4.2, но одну его особенность стоит подчеркнуть отдельно: он только читает.

Запасное значение существует только внутри выражения. Поэтому счётчик из главы 4.2 и записывают в две операции: counts[word] = counts.get(word, 0) + 1 — сначала прочитать, потом присвоить. Метод, который читает и сразу создаёт ключ, называется setdefault() и разбирается в главе 4.4.

§16items() — представление

items() возвращает не список, а представление — динамическое окно в словарь.

Для перебора циклом представления достаточно, и это самый частый случай.

Если нужен именно список — с индексами и срезами, — представление оборачивают: list(prices.items()). Чем «динамическое» отличается от обычного и почему это важно, разбирается в главе 4.4.

§18Проверьте себя

Что перебирает sorted(data), если data — словарь?

Ключи. Для значений нужен sorted(data.values()), для пар — sorted(data.items()).

Чем max(scores) отличается от max(scores, key=scores.get)?

Первое сравнивает сами ключи и вернёт последний по алфавиту. Второе тоже перебирает ключи, но сравнивает их по значениям, и вернёт ключ с наибольшим значением.

Почему key=scores.get пишется без скобок?

Передаётся сама функция, а вызывать её для каждого элемента будет max(). Со скобками метод выполнился бы сразу и без аргумента.

Меняет ли get() словарь?

Нет. Метод только читает существующее значение или возвращает запасное — новый ключ при этом не появляется.

Почему dict.fromkeys(keys, []) опасен?

Все ключи получают один и тот же список, поэтому изменение через один ключ видно через остальные.

Почему prices.items()[0] не работает?

items() возвращает представление, а не список: у него нет индексов. Нужен list(prices.items())[0].

Итог главы

Универсальные функции работают со словарём так же, как со списком, но по умолчанию перебирают ключи — и решение «ключи, значения или пары» нужно принимать перед каждым вызовом. Параметр key позволяет перебирать одно, а сравнивать по другому: так находят ключ с наибольшим значением и сортируют словарь по значениям. dict.fromkeys() кладёт во все пары один и тот же объект, поэтому для изменяемых значений нужно включение, а get() только читает и ключей не создаёт.
