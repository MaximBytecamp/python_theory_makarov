§1Функция принимает словарь, метод принадлежит ему

ФормаПримерСмысл

При прямой передаче словаря большинство универсальных функций перебирает его ключи. Если нужны значения или пары, это нужно указать через values() или items().

§3min() и max(): сначала выбираем область

max(scores) сравнивает строки-ключи. В третьей строке кандидаты всё ещё ключи, но параметр key сообщает: сравнивай их по соответствующим баллам.

§4sum() обычно применяют к значениям

sum(cart) попытался бы складывать строковые ключи и завершился бы TypeError.

§5sorted() возвращает новый список

Исходный словарь не меняется. В item[1] находится значение пары (ключ, значение).

§6all() и any() сворачивают проверки

all() требует истинности всех элементов, any() — хотя бы одного. Для пустой последовательности результаты равны True и False соответственно.

§7enumerate() и reversed() работают с порядком

§8zip() соединяет ключи со значениями

zip() заканчивает работу вместе с самой короткой входной последовательностью.

map() и filter() получают выбранное представление

Эти функции тоже перебирают переданный объект. Поэтому для преобразования значений передают values(), а для фильтрации пар — items().

§9dict.fromkeys() создаёт одинаковые начальные значения

Общий изменяемый объект

dict.fromkeys(keys, []) поставит во все пары один и тот же список. Для независимых списков используйте включение: {key: [] for key in keys}.

§10get() читает без KeyError

get() не добавляет отсутствующий ключ. Он только возвращает запасное значение для текущего выражения.

§11items() выдаёт пары для перебора

items() возвращает динамическое представление, связанное со словарём, а не готовый список. Если список действительно нужен, используйте list(prices.items()).

§13Проверьте себя

Что перебирает функция sorted(data), если data — словарь?

Ключи. Для пар используют sorted(data.items()), для значений — sorted(data.values()).

Меняет ли get() словарь?

Нет. Метод только читает существующее значение или возвращает запасное.

Почему fromkeys(keys, []) опасен?

Все ключи получают один и тот же изменяемый список, поэтому изменение через один ключ видно через остальные.

Итог главы

Перед универсальной функцией важно выбрать, что именно обрабатывать: ключи, значения или пары. Методы fromkeys(), get() и items() решают отдельные задачи создания, безопасного чтения и перебора словаря.
