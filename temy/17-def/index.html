§1Что такое функция

Функция — именованный блок кода для одной понятной задачи. Вместо повторения нескольких строк мы один раз описываем действие, а затем обращаемся к нему по имени.

Функции помогают разделять программу на части, повторно использовать код и читать программу по названиям её действий.

§2Объявление через def

Ключевое слово def сообщает Python, что дальше начинается объявление функции.

  • def начинает объявление;
  • после него пишется имя функции;
  • в круглых скобках указываются параметры;
  • после скобок ставится двоеточие;
  • тело функции записывается с отступом в четыре пробела.

§3Объявление и вызов

Объявление создаёт функцию, но не выполняет её тело. Для запуска нужно отдельно написать имя функции с круглыми скобками.

Скобки запускают функцию

hello — имя функции, а hello() — её вызов. Без вызова строки внутри тела не выполнятся.

§4Порядок выполнения

Python читает файл сверху вниз. К моменту вызова объявление функции уже должно быть выполнено, поэтому обычно сначала пишут функции, а ниже — код, который их вызывает.

§5Параметр и аргумент

Параметр — имя внутри объявления функции. Аргумент — конкретное значение, которое передаётся при вызове.

В объявлении name — параметр. При первом вызове аргументом служит строка "Алексей", при втором — "Мария".

§6Несколько параметров

Если функции нужно несколько входных значений, параметры перечисляются через запятую. При обычном вызове аргументы сопоставляются с ними слева направо.

§7Возврат значения: return

return возвращает результат из функции в место вызова. Возвращённое значение можно сохранить, вывести или использовать в вычислении.

После выполнения return работа текущего вызова функции заканчивается. Строки ниже него в этом пути уже не выполняются.

§9Повторное использование

Одно объявление можно вызывать с разными аргументами. Исправление формулы внутри функции сразу действует для всех вызовов.

§11Проверьте себя

Выполняется ли тело функции сразу после def?

Нет. def создаёт функцию. Её тело выполняется только после вызова со скобками.

Чем параметр отличается от аргумента?

Параметр — имя в объявлении функции, аргумент — конкретное значение при вызове.

Зачем нужен return?

Чтобы передать вычисленный результат из функции в вызывающий код и затем использовать его.

§12Шпаргалка

Один параметрdef greet(name): print(name)
Вернуть результатdef add(a, b): return a + b
Вызватьresult = add(2, 3)

Итог главы

def объявляет функцию, а имя со скобками вызывает её. Параметры принимают переданные аргументы. print() показывает значение, а return возвращает его из функции для дальнейшей работы.
