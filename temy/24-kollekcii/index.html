Коллекции в Python

Коллекция хранит группу значений под одним именем. Выбор между списком, кортежем, множеством и словарём зависит от того, важны ли порядок, изменение, уникальность и обращение по ключу.

§2Что такое коллекция

Коллекция — структура для хранения нескольких элементов. С коллекцией можно добавлять и удалять значения, искать их, изменять и перебирать циклом — конкретные возможности зависят от её типа.

Имя коллекции по традиции ставят во множественное число: temperatures, names, prices. Это сразу подсказывает читателю кода, что внутри не одно значение.

Скобки различаются: квадратные у списка, круглые у кортежа, фигурные у множества и словаря. Дополнительные структуры, например deque и namedtuple, находятся в стандартной библиотеке и изучаются после основных коллекций.

Основной инструмент начинающего — список. Дальше в главе разбирается прежде всего он.

§4Список и индексы

Список — упорядоченная изменяемая коллекция. Каждый элемент занимает позицию с числовым индексом, а первый индекс равен нулю.

Индекс — это не номер по счёту, а смещение от начала. Поэтому третий по счёту элемент лежит под индексом 2.

Список из четырёх — индексы до трёх

Последний допустимый индекс всегда на единицу меньше количества элементов. Обращение к numbers[4] здесь вызовет IndexError.

§5Отрицательные индексы

Python умеет отсчитывать позиции с конца. Индекс -1 означает последний элемент, -2 — предпоследний.

Это избавляет от вычислений вида «длина минус один» там, где нужен просто последний элемент. Нуля с минусом не существует: -0 — это тот же 0, то есть первый элемент.

§6len(): длина коллекции

len() — встроенная функция, которая возвращает количество элементов. Она понадобится почти в каждой задаче с коллекциями.

У пустого списка [] длина равна 0, и обращаться по любому индексу к нему нельзя. Проверка if len(items) > 0 — стандартный способ убедиться, что данные вообще есть.

§7Изменение списка

Элемент списка можно заменить по индексу. Сам список после этого остаётся той же коллекцией, но его содержимое меняется.

Слева от знака = запись numbers[1] означает не «взять значение», а «указать ячейку для записи». Подробно этот механизм разбирается в главе 3.5.

§8Перебор циклом

Главная причина складывать данные в коллекцию — возможность обработать их одним циклом, независимо от количества.

Переменная цикла получает значение очередного элемента. Имя для неё берут в единственном числе — temperature при списке temperatures, — и код читается как фраза: «для каждой температуры из температур».

Если нужны не значения, а позиции, используют форму for index in range(len(items)) — ей посвящена глава 3.5.

У словаря порядок добавления сохраняется, но запись dictionary[0] означает поиск ключа 0, а не первого элемента. У множества индексов нет вовсе: {1, 2, 3}[0] вызовет TypeError.

§10Изменяемость

Изменяемые коллекции можно обновлять после создания. Неизменяемые нельзя менять по частям — для другого содержимого создают новый объект.

ИзменяемыеНеизменяемые
list, dict, set, dequetuple, str, frozenset

Неизменяемость — не ограничение, а гарантия. Кортеж уместен там, где данные не должны меняться случайно: координаты точки, дата, пара «широта и долгота».

§11Разные типы элементов

Список может хранить значения разных типов одновременно.

Это допустимо, но однородный список обычно проще обрабатывать: все температуры или все имена можно передать в sum() или отсортировать, а смешанный — нет.

Исключение — записи, где позиции имеют разный смысл: ["Иванов", 17, True]. Для таких данных обычно лучше подходят словарь или кортеж.

§13Строка как последовательность

Строка тоже упорядоченная коллекция — из символов. К ней применимы индексы, отрицательные индексы, len() и перебор циклом.

Отличие одно, но важное: строка неизменяема. Запись word[0] = "J" вызовет TypeError — вместо изменения создают новую строку.

§16Проверьте себя

Как получить первый элемент списка items?

items[0], потому что индексация начинается с нуля.

Как получить последний элемент, не зная длины?

items[-1]. Отрицательные индексы отсчитывают позиции с конца.

Чему равна len(matrix) для [[1, 2], [3, 4]]?

2: во внешнем списке два элемента, и каждый из них — список.

Что означает запись matrix[1][0]?

Сначала из matrix берётся элемент с индексом 1, а затем из полученного списка — элемент с индексом 0.

Какая коллекция хранит только уникальные элементы?

Множество set.

Можно ли заменить элемент кортежа по индексу?

Нет. Кортеж неизменяем; для другого содержимого нужно создать новый кортеж.

Итог главы

Коллекции хранят группы данных под одним именем и потому позволяют обрабатывать любое количество значений одним циклом. Список изменяем и поддерживает доступ по позиции, кортеж неизменяем, множество хранит уникальные элементы, а словарь связывает ключи со значениями. Индексы начинаются с нуля, отрицательные отсчитывают с конца, а len() даёт количество элементов.
