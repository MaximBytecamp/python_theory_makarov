Коллекции в Python

Коллекция хранит группу значений. Выбор между списком, кортежем, множеством и словарём зависит от того, важны ли порядок, изменение, уникальность и обращение по ключу.

§1Что такое коллекция

Коллекция — структура для хранения нескольких элементов. С коллекцией можно добавлять и удалять значения, искать их, изменять и перебирать циклом — конкретные возможности зависят от её типа.

§2Четыре основных вида

ТипЗаписьГлавная особенность
list[10, 20, 30]упорядоченный изменяемый список
tuple(10, 20, 30)упорядоченная неизменяемая последовательность
set{10, 20, 30}неупорядоченный набор уникальных элементов
dict{"name": "Alex"}пары «ключ — значение»

Дополнительные структуры, например deque и namedtuple, находятся в стандартной библиотеке и изучаются после основных коллекций.

§3Список и индексы

Список — упорядоченная изменяемая коллекция. Каждый элемент занимает позицию с числовым индексом, а первый индекс равен нулю.

§4Изменение списка

Элемент списка можно заменить по индексу. Сам список после этого остаётся той же коллекцией, но его содержимое меняется.

§5Порядок и доступ

КоллекцияПорядокКак обращаются к элементу
list, tuple, strпозиции идут последовательнопо числовому индексу
dictсохраняет порядок добавленияпо ключу, а не по позиции

У словаря порядок добавления сохраняется, но запись dictionary[0] означает поиск ключа 0, а не первого элемента.

§6Изменяемость

Изменяемые коллекции можно обновлять после создания. Неизменяемые нельзя менять по частям — для другого содержимого создают новый объект.

ИзменяемыеНеизменяемые
list, dict, set, dequetuple, str, frozenset

§7Разные типы элементов

Список может хранить значения разных типов одновременно.

Это допустимо, но однородный список обычно проще обрабатывать: например, все температуры или все имена.

§8Вложенные коллекции

Элементом списка может быть другая коллекция. Так представляют таблицы и составные записи.

§10Проверьте себя

Как получить первый элемент списка items?

items[0], потому что индексация начинается с нуля.

Какая коллекция хранит только уникальные элементы?

Множество set.

Можно ли заменить элемент кортежа по индексу?

Нет. Кортеж неизменяем; для другого содержимого нужно создать новый кортеж.

Итог главы

Коллекции хранят группы данных. Список изменяем и поддерживает доступ по позиции, кортеж неизменяем, множество хранит уникальные элементы, а словарь связывает ключи со значениями. Тип коллекции выбирают по нужным операциям.
