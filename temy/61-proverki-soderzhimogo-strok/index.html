5.7

Проверки содержимого строк

Методы isalpha(), isascii(), isdecimal(), isdigit(), isnumeric() и isidentifier() отвечают на разные вопросы о символах строки. Важно выбрать проверку под формат данных, а не только получить True.

§1Методы возвращают bool и не изменяют строку

§2isalpha() требует только буквы

§3isascii() проверяет диапазон кодов 0–127

В отличие от большинства методов вида is..., isascii() возвращает True для пустой строки: в ней нет символа вне ASCII.

§4Числовые проверки образуют вложенные группы

isdecimal() — самая строгая проверка. isdigit() принимает ещё некоторые символы цифр. isnumeric() охватывает более широкий класс числовых символов, включая отдельные дроби.

§5isdecimal() подходит для записи целого числа цифрами

Метод не проверяет синтаксис любого числа. Для знака, десятичной точки и других форм записи нужна отдельная логика или попытка преобразования.

§12Проверьте себя

Почему "Python3".isalpha() возвращает False?

Потому что цифра 3 не является буквой.

Какая из трёх числовых проверок самая широкая?

isnumeric().

Достаточно ли isidentifier() для выбора имени переменной?

Нет. Нужно также исключить ключевые слова через keyword.iskeyword().

Итог главы

Методы is... проверяют свойства всех символов. Они не заменяют описание формата: сначала определите допустимые символы, затем выберите одну или несколько проверок.
