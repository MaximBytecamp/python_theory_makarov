§1Как разбирать задачи

Перед написанием цикла ответьте на три вопроса: какие значения перебираются, что происходит с одним значением и нужен ли общий результат после завершения.

  1. Выберите последовательность: строку, список или range().
  2. Дайте переменной цикла имя одного элемента.
  3. Если нужен итог, создайте переменную-накопитель до цикла.
  4. После цикла выведите или используйте накопленный результат.

§2Числа и квадраты

Задача 1: вывести числа от 1 до 5.

Задача 2: рядом с каждым числом вывести его квадрат.

§3Накопление суммы

Задача 3: найти сумму чисел от 1 до 5. Накопитель начинается с нуля, потому что прибавление нуля не меняет сумму.

print() стоит без отступа, поэтому выполняется один раз после завершения цикла.

§4Фильтрация по условию

Задача 4: вывести только чётные числа от 1 до 10. Условие внутри цикла решает, какие значения подходят.

§5Накопление произведения

Задача 5: вычислить факториал числа 5, то есть произведение 1 · 2 · 3 · 4 · 5. Для произведения накопитель начинается с единицы.

Если начать с нуля, первое же умножение превратит весь результат в ноль.

§6Перебор символов

Задача 6: вручную подсчитать количество символов. Счётчик увеличивается один раз для каждого символа.

Задача 7: вывести каждый символ строки отдельно.

§7Сумма цифр

Задача 8: найти сумму цифр положительного целого числа. После преобразования числа в строку цикл получает символы, а int() превращает каждый символ обратно в число.

Для отрицательного числа строка содержит знак -, который нельзя преобразовать в целое число. Такой случай требует отдельной обработки, например str(abs(number)).

§8Поиск максимума

Задача 9: найти наибольшее число без функции max(). Первое значение берётся как начальный кандидат, затем каждый элемент сравнивается с ним.

Алгоритм предполагает, что список не пуст. Иначе элемента с индексом 0 не существует.

§9Подсчёт подходящих элементов

Задача 10: подсчитать чётные числа в списке. Здесь соединяются фильтрация условием и счётчик.

§10Таблица умножения

Задача 11: вывести таблицу умножения для числа 3. Переменная цикла задаёт второй множитель.

§11Построение новой строки

Задача 12: перевернуть строку. Каждый новый символ добавляется не в конец, а перед уже собранной частью.

После первых трёх повторений накопитель меняется так: "P" → "yP" → "tyP".

§12Поиск с break и else

Задача 13: проверить, является ли число простым. Если найден делитель, цикл завершается через break. Иначе после полного перебора выполняется else.

Пример рассчитан на целое число не меньше 2. Проверку остальных значений нужно добавить до цикла.

§13Диапазон с шагом

Задача 14: вывести числа от 0 до 20 с шагом 5.

§14Подсчёт гласных

Задача 15: подсчитать английские гласные. Оператор in внутри условия проверяет, входит ли текущий символ в строку "aeiou".

§16Проверьте себя

Почему накопитель суммы начинается с нуля, а произведения — с единицы?

Ноль не меняет сумму при сложении, а единица не меняет произведение при умножении.

Где должен находиться вывод итогового результата?

Без отступа после цикла, если результат нужно вывести один раз. Внутри цикла выводятся промежуточные значения.

Зачем в поиске простого числа нужен else цикла?

Он выполняется, только если цикл перебрал все возможные делители и не завершился через break.

Итог главы

Большинство начальных задач с for строятся из нескольких схем: выполнить действие для каждого элемента, накопить сумму или произведение, увеличить счётчик по условию, обновить лучший результат либо завершить поиск через break. Узнавание схемы упрощает решение новой задачи.
