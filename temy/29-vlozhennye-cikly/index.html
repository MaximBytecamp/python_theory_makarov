3.7

Вложенные циклы
(nested loops)

Во вложенной конструкции полный внутренний цикл выполняется заново для каждого значения внешнего. Так обрабатывают таблицы, матрицы и пары элементов.

§1Общая схема

Внутренний for находится в теле внешнего. Поэтому каждый новый outer запускает весь перебор inner сначала.

§2Пошаговое выполнение

При row = 0 внутренний цикл получает 0, 1, 2. Затем row становится равен 1, и внутренний диапазон снова начинается с нуля.

§3Количество повторений

Если внешний цикл делает N повторений, а внутренний — M для каждого внешнего, самое глубокое действие выполняется N × M раз.

§4Таблица умножения

print() без аргументов выровнен с внутренним циклом, поэтому выполняется после каждой готовой строки.

§5Матрица

Матрицу можно представить списком строк. Внешний цикл получает строку, внутренний — элементы этой строки.

§6Поиск совпадений

Вложенные циклы позволяют сравнить каждый элемент первого списка с каждым элементом второго.

§7break во вложенном цикле

break завершает только ближайший цикл — тот, внутри которого написан.

§8continue во вложенном цикле

continue пропускает текущий шаг ближайшего цикла. Внешнее значение при этом не меняется.

§9Сложность

Два полных цикла по n элементов выполняют около n² сравнений. Для 100 элементов это 10 000, а для 10 000 — уже 100 000 000.

Сначала правильность, затем масштаб

Вложение удобно и понятно для небольших таблиц. При больших наборах проверьте, можно ли заменить полный перебор множеством, словарём или другим алгоритмом.

§11Проверьте себя

Сколько раз выполнится действие при диапазонах 4 и 5?

4 × 5 = 20 раз.

Какой цикл завершит break внутри внутреннего тела?

Только ближайший внутренний цикл.

Почему внутренний цикл запускается повторно?

Потому что его полный перебор является телом каждой итерации внешнего цикла.

Итог главы

Для каждого значения внешнего цикла внутренний цикл проходит все свои значения. Глубокое действие выполняется N × M раз. break и continue управляют только ближайшим циклом.
