Truthy и Falsy
значения

Условию в Python необязательно передавать готовый True или False. Числа, строки и коллекции тоже имеют логическую истинность, которую Python проверяет через bool().

§1Логический контекст

if, while, not, and и or оценивают истинность полученного значения. Условие if value: принимает решение так, как если бы использовало bool(value).

§2Какие значения считаются Falsy

Falsy — значения, которые становятся False в логическом контексте.

ГруппаПримеры
логическое и отсутствие значенияFalse, None
числовой ноль0, 0.0, 0j
пустые последовательности"", [], (), range(0)
пустые отображения и множества{}, set()

Ноль внутри непустой коллекции не делает саму коллекцию ложной: bool([0]) равно True, потому что в списке есть элемент.

§3Какие значения считаются Truthy

Truthy — остальные значения, если их тип не определяет особое поведение. Отрицательное число истинно, непустая строка истинна, непустая коллекция истинна.

§4Проверка строки

Если важен сам факт наличия текста, строку можно проверять напрямую.

Строка из пробелов не пуста. Если пробелы нужно игнорировать, проверяйте if name.strip():.

§5Проверка коллекции

if items: означает «в коллекции есть элементы», а if not items: — «коллекция пуста».

Такая запись точнее выражает намерение, чем len(numbers) > 0, когда нужна лишь проверка пустоты.

§6Где используется истинность

Одно правило работает во всех логических контекстах.

§7filter(None, ...)

filter(None, iterable) оставляет только истинные элементы. Он удалит не только None, но и нули, пустые строки и другие Falsy-значения.

§8Когда нужен явный bool()

Внутри if преобразование уже происходит автоматически. bool(value) полезен, когда логический результат нужно сохранить, вывести или вернуть из функции.

§10Проверьте себя

Почему bool([0]) возвращает True?

Список не пуст: его единственный элемент не влияет на истинность самого списка.

Чем отличаются if items: и if len(items) > 0:?

Для обычной коллекции результат одинаков, но первая запись напрямую выражает проверку непустоты.

Пуста ли строка " "?

Нет, в ней есть пробел. Для проверки текста без окружающих пробелов используйте value.strip().

Итог главы

Python оценивает истинность любого значения в логическом контексте. Ноль, None и пустые коллекции считаются Falsy; непустые коллекции и ненулевые числа — Truthy. Прямые проверки if items: и if not items: ясно выражают наличие или отсутствие данных.
