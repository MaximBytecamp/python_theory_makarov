4.10

Включения
в Python

Включение собирает новую коллекцию из существующей одним выражением. Это не «короткая запись цикла ради краткости»: включение сразу объявляет намерение — «получить новый список из этих элементов», — и потому читается быстрее, чем цикл с накоплением.

«Разбираться в основах — значит экономить время в будущем.»

§1От цикла к включению

Задача «построить новый список на основе существующего» решается циклом с накоплением — приёмом из главы 3.10.

Здесь четыре строки, из которых по-настоящему содержательна одна — number * number. Остальные — обвязка: создать пустой список, открыть цикл, вызвать append(). Включение убирает обвязку.

§2Строение включения

Внутри квадратных скобок три части, и порядок их непривычен: сначала говорится, что получить, и только потом — откуда.

Читать удобно с середины: сначала часть for, затем выражение слева. «Для каждого number из диапазона — положить number * number».

§3Преобразование элементов

Самое частое применение — применить к каждому элементу одно и то же действие.

Без фильтрации включение всегда даёт ровно столько элементов, сколько было на входе. Исходный список при этом не меняется — создаётся новый.

§4Фильтрация через if

Необязательная часть if в конце отбирает, какие элементы вообще попадут в результат.

Теперь длина результата может быть меньше исходной. Порядок частей строгий: сначала for, потом if.

§5Два if подряд

Условий может быть несколько — тогда элемент должен пройти все.

Два if подряд равнозначны одному с and. Выбор — вопрос читаемости: когда условия логически независимы, раздельная запись понятнее.

§6Условие в результате

Есть и другой if — не отбирающий, а выбирающий значение. Он ставится слева, в части «что положить», и обязательно с else.

Это тернарный оператор из главы 2.6, поставленный на место выражения. Он ничего не отбрасывает — только решает, какое значение положить.

§7Два разных if

Два if из §5 и §6 выглядят похоже, но делают противоположное. Различить их можно по позиции и по наличию else.

Где стоитЕсть elseЧто делаетДлина результата
в конце, после forнетотбирает элементыможет уменьшиться
в начале, до forда, обязательновыбирает значениене меняется

Первая запись сокращает список, вторая сохраняет его длину. Требование else в левой форме не случайно: если условие ложно, что-то же надо положить в результат.

§8Включение множества

Скобки определяют тип результата. Фигурные с одним выражением дают множество — со всеми его свойствами из главы 4.5.

Слов три, длин тоже три — но если бы среди слов нашлись одинаковые по длине, в множестве осталась бы одна запись.

§9Включение словаря

Те же фигурные скобки, но выражение содержит пару через двоеточие.

Именно эта форма решала задачу из главы 4.3: {key: [] for key in keys} создаёт по независимому списку на каждый ключ, в отличие от dict.fromkeys().

§10Обращение словаря

Частая задача — поменять ключи и значения местами. Со словарным включением это одна строка.

Здесь работает распаковка пар из главы 4.1. Важная оговорка: значения могли повторяться, а ключи уникальны — при совпадении значений часть данных потеряется.

§11Скобки решают тип

ЗаписьТип результата
[x for x in data]list
{x for x in data}set
{k: v for k, v in pairs}dict
(x for x in data)генератор, не кортеж

Последняя строка — исключение из правила: круглые скобки кортеж не создают. Чтобы получить кортеж, результат оборачивают: tuple(x for x in data).

§12Генераторное выражение

Круглые скобки дают генератор — объект, который вычисляет элементы по одному при обходе, а не строит список целиком.

Практическая польза — экономия памяти, когда результат нужен один раз. Запись sum(len(w) for w in words) не создаёт промежуточный список: скобки генератора можно опустить, если он единственный аргумент функции.

Генераторы подробно разбираются в главе 7.2.

§13Область видимости

Переменная включения живёт только внутри него и наружу не выходит.

Это отличие от обычного цикла, где переменная остаётся доступной после завершения. Свойство полезное: включение не засоряет окружающий код и не может случайно затереть существующую переменную с тем же именем.

§14Независимые списки

Одна задача, где включение не просто короче, а единственно верно, — создание списка списков.

Причина та же, что у dict.fromkeys() в главе 4.3: умножение копирует ссылку на один и тот же список, а включение выполняет выражение заново на каждом шаге и создаёт новый список. Подчёркивание в роли переменной — приём из главы 6.7.

§15Когда нужен обычный цикл

Включение — не всегда лучший выбор. Есть случаи, где цикл понятнее.

Четвёртая строка про частую ошибку стиля: включение ради одного print() создаёт список из None, который тут же выбрасывается. Если результат не нужен — нужен цикл.

§17Проверьте себя

В каком порядке читать включение?

С середины: сначала часть for — откуда берутся элементы, затем выражение слева — что кладётся в результат.

Чем отличаются два if во включении?

if в конце отбирает элементы и может уменьшить длину результата. if ... else слева выбирает значение и длину не меняет.

Почему в левой форме else обязателен?

Потому что это тернарный оператор: если условие ложно, в результат всё равно нужно что-то положить.

Что создаст (x for x in data)?

Генератор, а не кортеж. Для кортежа нужно tuple(x for x in data).

Доступна ли переменная включения после него?

Нет, обращение к ней даёт NameError. В обычном цикле переменная сохраняется.

Почему [[0] * 3] * 2 — ошибка?

Умножение копирует ссылку на один список, и обе строки окажутся одним объектом. Включение создаёт новый список на каждом шаге.

Итог главы

Включение строит новую коллекцию одним выражением, объявляя намерение раньше механики. Тип результата задают скобки: квадратные дают список, фигурные — множество или словарь, круглые — генератор, а не кортеж. Два вида if различаются позицией: справа он отбирает элементы, слева выбирает значение и требует else. Переменная включения наружу не выходит, а само включение — единственный корректный способ создать список независимых списков.
