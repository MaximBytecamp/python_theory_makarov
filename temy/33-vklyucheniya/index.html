Включения
в Python

Включение создаёт новую коллекцию из элементов другой последовательности. В одной записи можно указать перебор, преобразование и условие отбора.

§1Основная идея

Включение проходит по исходным данным и добавляет вычисленный результат в новую коллекцию. Для списка используется схема:

  1. Взять очередной элемент из источника.
  2. Проверить условие, если оно есть.
  3. Вычислить выражение.
  4. Добавить результат в новую коллекцию.

§2От обычного цикла к включению

Обе записи создают одинаковый список квадратов. Сначала находите знакомый цикл, затем переносите выражение перед for.

§3Преобразование каждого элемента

Выражение слева от for определяет, что попадёт в новый список. Исходные элементы при этом не меняются.

§4Фильтрация через if

if после цикла отвечает на вопрос «добавлять ли этот элемент?». Если условие ложно, элемент пропускается.

§5Условное выражение внутри результата

Тернарное выражение перед for не отбрасывает элементы, а выбирает для каждого одно из двух значений.

Положение условияНазначениеСхема
после циклафильтрует элементы[x for x in data if test]
перед цикломвыбирает одно из двух значений[a if test else b for x in data]

§6Включение для множества

Фигурные скобки без пары «ключ — значение» создают множество. Повторяющиеся результаты исчезают.

sorted() здесь нужен лишь для предсказуемого отображения: само множество не хранит позиционный порядок.

§7Включение для словаря

Для словаря выражение содержит ключ и значение через двоеточие.

§8Область видимости переменной

Имя перебора внутри включения не заменяет одноимённую внешнюю переменную.

§9Генераторное выражение

Круглые скобки создают не кортеж, а генераторное выражение: значения вычисляются по мере перебора. Это удобно, когда функция вроде sum() сразу потребляет результат.

Список или генератор

[expr for x in data] сразу хранит все результаты. (expr for x in data) выдаёт их по одному. Генератор экономит память, но после полного перебора исчерпывается.

§10Когда выбрать обычный цикл

Включение удобно для одного понятного преобразования и короткого условия. Если нужны несколько действий, промежуточные переменные, обработка ошибок или сложные ветви, обычный цикл читается легче.

§12Проверьте себя

Какая часть включения определяет добавляемое значение?

Выражение перед for.

Чем отличаются if после цикла и if ... else перед циклом?

Первый отбирает элементы, второй выбирает результат для каждого элемента.

Что создаёт запись в круглых скобках?

Генераторное выражение, которое выдаёт значения по одному.

§13Шпаргалка

Список[expr for x in data]
Фильтр[x for x in data if test]
Множество{expr for x in data}
Словарь{key: value for x in data}

Итог главы

Включение строит новую коллекцию из перебираемых данных. Выражение задаёт результат, for — источник, а завершающий if — фильтр. Квадратные скобки создают список, фигурные — множество или словарь, круглые — генераторное выражение.
