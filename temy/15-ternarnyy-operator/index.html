условный оператор

§1От if / else к выражению

Обычная конструкция выбирает, какое значение записать в переменную:

Условное выражение делает тот же выбор в одной строке:

Эту форму часто называют тернарным оператором, потому что в ней участвуют три части: два возможных значения и условие.

§2Порядок частей

Чтобы разобрать строку, сначала найдите условие после if. При True выбирается значение слева, при False — значение после else.

  1. Вычислить условие.
  2. При True взять левое значение.
  3. При False взять правое значение.

§3Пример с текстом

В переменную message попадает только одна строка. Само условное выражение ничего не печатает.

§4Пример с числами

Выбираться могут не только строки, но и числа.

§5Выражение прямо в print()

Условное выражение возвращает значение, поэтому его можно передать функции.

Для короткого сообщения такая запись читается нормально. Если выражение становится длинным, отдельная переменная помогает назвать результат.

§6Когда применять

Условное выражение подходит, когда выполняются три условия:

  • есть ровно два возможных значения;
  • выбор помещается в одну короткую строку;
  • в ветках нет отдельных действий, нужен только результат.

§7Когда оставить обычный if

Если каждая ветка содержит несколько действий, условное выражение применять не нужно.

Также избегайте вложенных тернарных выражений. Цепочка из нескольких if и else в одной строке требует слишком много внимания при чтении.

§9Проверьте себя

Как читается status = "on" if enabled else "off"?

Если enabled истинно, в status записывается "on", иначе — "off".

Обязательна ли часть else?

Да. Условное выражение всегда должно вернуть одно из двух значений.

Когда лучше использовать обычный if?

Когда ветки выполняют действия, содержат несколько строк или когда однострочная запись стала трудной для чтения.

Итог главы

Тернарный условный оператор выбирает одно из двух значений по схеме значение if условие else другое_значение. Он подходит для короткого присваивания или вывода. Если ветки содержат действия или строка перестала читаться сразу, используйте обычный if / else.
