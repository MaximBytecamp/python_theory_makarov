§4Как работает key

key принимает функцию. Для каждого элемента Python один раз вычисляет ключ, сортирует по ключам и возвращает исходные элементы в новом порядке.

§6Сложные элементы

Lambda-функция извлекает нужную часть кортежа или словаря.

§7Несколько критериев

Кортеж-ключ сравнивается слева направо: сначала первый критерий, при равенстве — второй.

§8Обратный порядок

reverse=True разворачивает итоговый порядок после применения key.

§9Стабильная сортировка

Если ключи равны, Python сохраняет относительный порядок элементов. Поэтому среди слов одинаковой длины раньше останется то, которое раньше находилось в исходных данных.

§10Параметр key в min() и max()

Тот же принцип применяется при выборе одного элемента. Возвращается исходный элемент, а не вычисленный ключ.

§12Проверьте себя

Какой инструмент меняет исходный список?

Метод list.sort(). Функция sorted() возвращает новый список.

Что возвращает функция key?

Ключ сравнения для одного элемента; в итоговую коллекцию всё равно попадает исходный элемент.

Что происходит с элементами, у которых равные ключи?

Благодаря стабильности сортировки они сохраняют взаимный порядок.

Итог главы

list.sort() изменяет список и возвращает None, а sorted() принимает любой итерируемый объект и создаёт новый список. Функция key один раз вычисляет признак каждого элемента; кортеж позволяет задать несколько критериев, а стабильность сохраняет порядок равных ключей.
