Функция sum()

sum() последовательно складывает числовые элементы итерируемого объекта. Она заменяет ручной цикл с накоплением суммы и хорошо сочетается с выражениями, которые создают числа по одному.

§1Назначение и синтаксис

sum(iterable, start=0) складывает элементы iterable, начиная со значения start. Второй аргумент необязателен.

ПараметрЧто передаёмПо умолчанию
iterableобъект, который выдаёт складываемые значенияобязателен
startзначение, прибавляемое до элементов0

§2Обычная сумма

Ручной цикл дал бы тот же результат, но потребовал бы отдельно создать переменную-накопитель и обновлять её на каждой итерации.

§3Параметр start

Начальное значение не заменяет первый элемент. Оно прибавляется к сумме всех элементов.

§4Разные итерируемые объекты

sum() принимает не только список. Важно не название типа, а возможность получить из объекта складываемые значения.

§5Пустая коллекция

Без элементов результат равен начальному значению. Поэтому sum([]) возвращает 0, а не вызывает ошибку.

§6Подсчёт элементов по условию

В арифметике Python True ведёт себя как 1, а False — как 0. Поэтому сумма результатов проверок равна количеству выполненных условий.

§7Сумма преобразованных значений

Внутри sum() можно формировать каждое слагаемое. Такая запись не требует заранее создавать отдельный список квадратов.

Конструкцию внутри скобок подробно разберём в следующей главе. Пока достаточно читать её как «квадрат каждого числа из numbers».

§8Объединение списков и строк

sum(lists, []) способен объединить небольшие списки, но многократно создаёт промежуточные списки. Для крупных данных лучше использовать специализированные способы.

Строки складывать нельзя

sum(["Hello", "World"], "") вызывает TypeError. Для объединения строк используйте " ".join(words).

§10Проверьте себя

Чему равно sum([], 7)?

7: элементов нет, поэтому результатом остаётся начальное значение.

Что означает второй аргумент sum()?

Начальное значение, к которому прибавляются все элементы.

Как объединить список строк?

Методом separator.join(words), например " ".join(words).

Итог главы

sum() складывает значения из одного итерируемого объекта. Необязательный start задаёт начальное значение, пустая коллекция возвращает именно его, а сумма логических результатов позволяет подсчитать выполненные условия. Для строк используется join().
