§1keys() даёт представление ключей

Для обычного перебора запись for key in user короче и даёт те же ключи. Явный keys() полезен, когда нужно подчеркнуть область операции или сохранить представление.

§2Представление связано с исходным словарём

dict_keys, dict_values и dict_items — динамические представления. Они не являются списками и не поддерживают доступ по индексу.

§5pop() удаляет ключ и возвращает значение

Без второго аргумента отсутствующий ключ вызывает KeyError. С запасным значением метод безопасно возвращает его и не меняет словарь.

§7popitem() снимает последнюю добавленную пару

У пустого словаря popitem() вызывает KeyError. Метод подходит для последовательной обработки с удалением, но не заменяет выбор по конкретному ключу.

§8setdefault() читает или сразу создаёт

§9Группировка через setdefault()

Для первого города метод создаёт пустой список, а для следующих возвращает уже существующий. Затем append() работает с этим списком.

§10update() переносит пары в исходный словарь

Метод принимает другой словарь, итерируемый объект пар или именованные аргументы. Он меняет исходный словарь и возвращает None.

§11Оператор | создаёт новый словарь

|=, напротив, обновляет словарь слева. Оба оператора доступны начиная с Python 3.9.

§13Проверьте себя

Чем представление словаря отличается от списка?

Оно связано с исходным словарём, отражает последующие изменения и не поддерживает числовые индексы.

Когда setdefault() меняет словарь?

Только когда указанного ключа ещё нет: тогда метод добавляет ключ со значением по умолчанию.

Что возвращает update()?

None. Метод меняет исходный словарь.
