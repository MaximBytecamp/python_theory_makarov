§1Как работать с примерами

В каждом примере сначала определена задача функции, затем показан её вызов. Не ограничивайтесь чтением: изменяйте аргументы и заранее предполагайте результат.

  1. Назовите одно действие, которое должна выполнять функция.
  2. Определите, какие данные ей нужны в параметрах.
  3. Решите, должна ли она вывести сообщение или вернуть значение.
  4. Вызовите функцию с несколькими аргументами и проверьте результат.

§2Функция без параметров

Задача: создать функцию, которая выводит приглашение к работе.

Параметров нет, поэтому скобки в объявлении и вызове остаются пустыми.

§3Функция с параметром

Задача: принимать имя и составлять приветствие. Один код работает для разных людей.

§4Возвращаем результат

Задача: вычислять квадрат числа. Здесь полезнее return, потому что результат может понадобиться в другом вычислении.

§5Условие внутри функции

Функция может принимать решение и возвращать логический результат.

Для выбора одного из двух результатов можно использовать обычное ветвление.

§6Функция вызывает функцию

Задача: сложить квадраты двух чисел. Уже готовую функцию square() можно использовать внутри новой функции.

sum_of_squares() отвечает за общую задачу, а square() — за одно небольшое вычисление.

§7Вложенная функция

Функцию можно объявить внутри другой функции. Внутренняя функция служит помощником и вызывается из тела внешней.

Вызов outer() создаёт внутреннюю функцию, а затем строка inner() запускает её.

multiply() создаётся во время вызова rectangle_area() и предназначена для использования внутри неё. На начальном этапе применяйте вложенные функции только тогда, когда внутренний помощник не нужен остальной программе.

§8Несколько функций в программе

Небольшую задачу можно разделить на отдельные вычисления, а затем собрать их в управляющей функции.

§9Анализ числа

Несколько маленьких функций делают каждый шаг заметным. Сначала объединим проверку чётности, абсолютное значение и квадрат.

Во втором варианте разберём положительное целое число на последнюю цифру и оставшуюся часть.

Для отрицательных чисел правила % и // требуют отдельного внимания. Этот пример рассчитан на положительное целое число.

§10Функция-меню

В небольшой программе одна функция может получать данные, а отдельные функции — выполнять вычисления.

calculator() управляет сценарием, а add() и multiply() отвечают только за свои вычисления.

§12Проверьте себя

Почему is_even() возвращает True или False?

Выражение number % 2 == 0 является сравнением и само даёт логический результат.

Зачем sum_of_squares() вызывает square() дважды?

Чтобы не повторять формулу квадрата: каждый вызов вычисляет квадрат одного аргумента.

Когда уместна вложенная функция?

Когда небольшой помощник нужен только одной внешней функции и не должен использоваться в остальных частях программы.

Итог главы

Функция может получать параметры, возвращать значение, содержать условие и вызывать другие функции. Чем точнее одна функция отвечает за одну задачу, тем легче читать, проверять и переиспользовать программу.
