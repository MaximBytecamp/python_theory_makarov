§1pop(): удалить и вернуть

pop() отличается от всех методов предыдущей главы тем, что возвращает значение, а не None. Он удаляет элемент и отдаёт его программе.

Без аргумента удаляется последний элемент. Именно поэтому removed = numbers.pop() — правильная запись, в отличие от numbers = numbers.append(...) из главы 3.2.

Извлечь — не то же самое, что удалить

Если извлечённое значение не нужно, результат можно не сохранять: numbers.pop() отдельной строкой просто удалит последний элемент.

§2pop() по индексу

pop(index) удаляет элемент с указанной позиции. Элементы правее сдвигаются влево, и их индексы уменьшаются на единицу.

Отрицательный индекс поддерживается: pop(-1) извлекает последний элемент. Если списка нет элемента с таким индексом — в том числе если список пуст, — возникает IndexError.

§3Список как стек

Пара append() и pop() превращает список в стек: последний добавленный элемент выходит первым. Такой порядок называют LIFO — last in, first out.

Так устроены отмена последнего действия, история переходов «назад» и разбор вложенных скобок: везде, где нужно вернуться к тому, что отложили последним.

§4Список как очередь

pop(0) извлекает первый элемент — получается очередь, где первым выходит тот, кто раньше пришёл (FIFO).

Работает это корректно, но не бесплатно: после удаления нулевого элемента все остальные сдвигаются на одну позицию. Для списка из миллиона элементов каждый pop(0) — миллион перемещений, тогда как pop() с конца обходится без них.

Когда очередь длинная

Для больших очередей в стандартной библиотеке есть collections.deque с методом popleft(): он удаляет первый элемент без сдвига остальных. В учебных задачах на десятки элементов разница незаметна, и pop(0) вполне уместен.

§5clear(): очистить список

clear() удаляет все элементы, сохраняя сам список.

§6clear() или новый список

На первый взгляд numbers.clear() и numbers = [] делают одно и то же. Разница проявляется, когда у списка два имени — как в главе 3.2.

clear() опустошает сам объект — его видят все имена. Присваивание numbers = [] создаёт новый пустой список и связывает с ним только имя numbers; прежний список продолжает жить под именем another.

Как выбрать

Нужно, чтобы изменение увидели все, кто работает с этим списком, — clear(). Нужно просто начать накопление заново в своей переменной — = [].

§7index(): найти позицию

index(value) возвращает индекс первого вхождения значения.

§9count(): посчитать совпадения

count(value) проходит список и возвращает число равных элементов. Если совпадений нет, результатом будет 0, а не ошибка.

§10sort(): сортировать на месте

sort() меняет порядок элементов исходного списка и возвращает None. По умолчанию числа идут по возрастанию.

Аргумент reverse=True задаёт убывание. Python использует устойчивый алгоритм Timsort со сложностью порядка O(n log n) для общего случая: «устойчивый» означает, что равные элементы сохраняют исходный взаимный порядок.

Заглавные буквы идут раньше строчных

Сравниваются коды символов, а не буквы «по-человечески». Поэтому "Яблоко" окажется раньше "арбуз". Чтобы регистр не влиял, используют names.sort(key=str.lower).

Смешивать несравнимые типы нельзя: [1, "a"].sort() вызовет TypeError — Python не знает, что больше, число или строка.

Разница та же, что между reverse() и [::-1] или между clear() и = []: метод меняет объект, функция строит новый. sorted() к тому же принимает любую коллекцию — строку, кортеж, множество — и всегда возвращает список.

§13Удаление внутри цикла

Есть ошибка, которую совершают почти все и которая не выдаёт никакого сообщения. Задача: убрать из списка все двойки.

Причина в том, что цикл идёт по позициям, а удаление сдвигает элементы влево. Внутренний счётчик цикла об этом не знает и продолжает увеличиваться, перепрыгивая через элементы.

Позиция циклаСписок сейчасВзят элементДействие
0[1, 2, 2, 3, 2]1пропуск
1[1, 2, 2, 3, 2]2удалена, список стал [1, 2, 3, 2]
2[1, 2, 3, 2]3вторая двойка пропущена: она сдвинулась на позицию 1
3[1, 2, 3, 2]2удалена первая двойка, список стал [1, 3, 2]
4[1, 3, 2]—элементов больше нет, цикл заканчивается

Надёжное решение — не удалять из того, что перебираешь, а собрать новый список из подходящих элементов.

Второй вариант — перебирать копию, а удалять из оригинала: for number in numbers.copy(). Тогда цикл идёт по неизменяемому набору, и сдвиги ему не мешают.

Общее правило

Не изменяйте длину списка, пока перебираете его циклом. Ошибки при этом не будет — будет тихо неверный результат.

§16Проверьте себя

Чем pop() отличается от remove()?

pop() удаляет по индексу и возвращает элемент, а remove() удаляет первое совпавшее значение и возвращает None.

Почему pop(0) медленнее, чем pop()?

После удаления первого элемента все остальные сдвигаются на одну позицию, а удаление с конца сдвигов не требует.

Чем clear() отличается от numbers = []?

clear() опустошает сам объект, и это видят все его имена. Присваивание создаёт новый пустой список только для одной переменной.

Что вернёт count(), если совпадений нет?

Число 0. В отличие от index(), ошибки не будет.

Почему нельзя удалять элементы прямо в цикле по этому же списку?

Удаление сдвигает элементы влево, а счётчик цикла продолжает расти — часть элементов оказывается пропущена.

Как отсортировать, не меняя исходный список?

Сохранить результат sorted(numbers) в новую переменную.

Итог главы

pop() удаляет и возвращает элемент, clear() очищает список, index() находит первую позицию, count() считает совпадения, а sort() сортирует исходный список. Для нового отсортированного списка используют sorted(). И главное правило безопасности: не менять длину списка, пока идёт цикл по нему.
