§1pop(): удалить и вернуть

pop(index) удаляет элемент по индексу и возвращает его. Без аргумента удаляется последний элемент.

Отрицательный индекс поддерживается: pop(-1) также извлекает последний элемент.

§2Стек и очередь

Пара append() и pop() позволяет использовать список как стек: последний добавленный элемент выходит первым.

pop(0) извлекает первый элемент, но сдвигает весь остаток списка. Для часто используемой очереди эффективнее collections.deque.

§3clear(): очистить список

clear() удаляет все элементы, сохраняя сам список.

§4clear() или новый список

Если два имени обозначают один список, clear() делает его пустым для обоих имён. Присваивание numbers = [] связывает только имя numbers с новым пустым списком.

Теперь важны связи имён и объектов

Ранее эта модель не требовалась. Для методов, меняющих коллекцию на месте, она объясняет разницу между очисткой существующего списка и созданием нового.

§5index(): найти позицию

index(value) возвращает индекс первого вхождения. Если значения нет, возникает ValueError.

Полная форма — index(value, start, stop); правая граница stop не включается.

§6count(): посчитать совпадения

count(value) проходит список и возвращает число равных элементов. Если совпадений нет, результатом будет 0, а не ошибка.

§7sort(): сортировать на месте

sort() меняет порядок элементов исходного списка и возвращает None. По умолчанию числа идут по возрастанию.

Python использует устойчивый алгоритм Timsort со сложностью порядка O(n log n) для общего случая.

§11Проверьте себя

Чем pop() отличается от remove()?

pop() удаляет по индексу и возвращает элемент, а remove() удаляет первое совпавшее значение и возвращает None.

Что вернёт count(), если совпадений нет?

Число 0.

Как отсортировать, не меняя исходный список?

Сохранить результат sorted(numbers) в новую переменную.

Итог главы

pop() удаляет и возвращает элемент, clear() очищает список, index() находит первую позицию, count() считает совпадения, а sort() сортирует исходный список. Для нового отсортированного списка используют sorted().
