§1Модуль и библиотека

Модуль — файл с расширением .py. В нём могут находиться переменные, функции, классы и другой код.

Библиотека — готовый набор кода для определённых задач. Она может состоять из одного модуля или из множества модулей и пакетов. В разговоре эти слова иногда используют как близкие, но они описывают разные размеры структуры.

§2Зачем нужны модули

Модули позволяют не хранить всю программу в одном длинном файле и не писать заново уже готовые решения.

  • разделять большую программу на понятные части;
  • повторно использовать функции в разных файлах;
  • подключать инструменты из стандартной библиотеки Python;
  • использовать сторонние библиотеки для специальных задач.

§3Подключение через import

Ключевое слово import загружает модуль и создаёт в программе имя, через которое можно обратиться к его содержимому.

math входит в стандартную библиотеку Python, поэтому отдельно устанавливать его не нужно.

§4Обращение через точку

После обычного импорта объект внутри модуля указывают по схеме модуль.объект.

Полное имя показывает происхождение функции. Если в программе встретится math.sqrt(), сразу видно, что sqrt() взята из math.

§5Импорт конкретного объекта

Конструкция from ... import ... добавляет в программу конкретное имя из модуля. После этого имя модуля перед функцией не пишется.

Два разных способа

После import math пишут math.sqrt(). После from math import sqrt пишут просто sqrt().

§6Псевдонимы: as

as задаёт импортированному объекту другое имя. Псевдоним используют для принятого сокращения или для более понятного названия.

Для некоторых библиотек существуют общепринятые сокращения, например import numpy as np. Такое сокращение работает только после установки самой библиотеки.

§7Стандартные и сторонние библиотеки

ВидОткуда берётсяПримеры
стандартная библиотекаустанавливается вместе с Pythonmath, random, datetime
сторонняя библиотекаустанавливается отдельноnumpy, requests

Сторонние библиотеки обычно устанавливают в терминале через менеджер пакетов pip.

Команда установки не является кодом Python: её вводят в терминале. Перед установкой проверьте название библиотеки и используйте окружение своего проекта.

§8Собственный модуль

Любой созданный вами файл .py может стать модулем. Поместим функцию в один файл, а вызов — в другой.

Для такого импорта файлы geometry.py и main.py должны находиться в одной папке. Более сложную структуру проекта разберём отдельно.

§9Какой способ импорта выбрать

ЗаписьВызовОсобенность

Для начала чаще выбирайте import module: полное имя легче читать и оно реже конфликтует с вашими переменными и функциями.

§11Проверьте себя

Как вызвать sqrt() после import math?

Через имя модуля и точку: math.sqrt(число).

Чем модуль отличается от библиотеки?

Модуль — отдельный файл .py, а библиотека — готовый набор кода, который может включать несколько модулей и пакетов.

Что делает as?

Назначает импортированному модулю или объекту другое имя в текущей программе.

§12Шпаргалка

Модульimport mathmath.sqrt(16)
Один объектfrom math import sqrtsqrt(16)
Псевдоним модуляimport math as mm.sqrt(16)
Псевдоним объектаfrom math import sqrt as root

Итог главы

Модуль — файл Python с готовым кодом. import подключает модуль, точка выбирает объект внутри него, from ... import ... импортирует конкретное имя, а as задаёт псевдоним. Стандартные модули поставляются с Python, сторонние библиотеки устанавливаются отдельно.
