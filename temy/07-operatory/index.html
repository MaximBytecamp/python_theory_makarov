§1Оператор и операнды

Оператор — знак или слово, которое указывает Python, какое действие выполнить. Данные, над которыми выполняется действие, называются операндами.

Один и тот же оператор может работать по-разному с разными типами. 2 + 3 складывает числа, а "Py" + "thon" соединяет строки. Поэтому при чтении выражения смотрите не только на знак, но и на тип значений рядом с ним.

Три вида деления требуют отдельного разбора, поэтому следующая глава целиком посвящена операторам /, // и %.

§3Операторы сравнения

Сравнение не изменяет значения. Оно отвечает на вопрос и возвращает True или False.

ОператорВопросПример
==равны ли значения?5 == 5 → True
!=различаются ли значения?5 != 3 → True
>, <больше или меньше?7 > 4 → True
>=, <=включается ли граница?18 >= 18 → True
Не путайте = и ==

= присваивает значение переменной, а == сравнивает два значения. В вопросе «равно ли?» всегда два знака равенства.

§4Операторы присваивания

Составное присваивание берёт текущее значение переменной, выполняет действие и записывает результат обратно.

Такие формы существуют для основных арифметических операций: +=, -=, *=, /=, //=, %= и **=.

§5Унарные операторы

Большинство операторов стоят между двумя значениями. Унарный оператор работает с одним: - меняет знак числа, а + оставляет его положительным.

§6Приоритет и скобки

Python соблюдает привычный порядок: сначала скобки, затем степень, умножение и деление, после них сложение и вычитание. Операторы одного уровня выполняются слева направо, кроме степени.

Если порядок трудно увидеть сразу, добавьте скобки. Они не только управляют вычислением, но и показывают читателю замысел формулы.

§7Какие группы будут дальше

В Python есть и другие группы операторов. Их полезно узнавать, но применять будем после соответствующей теории.

  • and, or, not объединяют логические проверки;
  • in и not in проверяют наличие элемента в коллекции;
  • &, |, ^, <<, >> работают с двоичной записью чисел;
  • условное выражение значение if условие else другое_значение выбирает одно из двух значений.

Сейчас достаточно арифметики, сравнений и присваивания. Остальные группы получат собственные главы.

§9Проверьте себя

Что в записи total = price + delivery является оператором?

= — оператор присваивания, + — оператор сложения. total, price и delivery — имена переменных.

Что выведет print(3 + 2 ** 2)?

7. Сначала выполняется степень 2 ** 2, затем сложение.

Итог главы

Оператор задаёт действие над данными. Для первых программ нужны три основные группы: арифметические операторы вычисляют, операторы сравнения отвечают True или False, а операторы присваивания записывают результат в переменную. Порядком вычисления управляет приоритет, а явные скобки делают формулу понятнее.
