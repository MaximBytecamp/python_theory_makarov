§1Что делает while

Цикл повторяет один блок кода несколько раз. В конструкции while повторение продолжается, пока условие даёт True.

После условия ставится двоеточие, а тело цикла записывается с отступом. Строки без этого отступа выполняются уже после завершения цикла.

§2Проверка перед каждым повтором

while называют циклом с предусловием, потому что условие проверяется до входа в тело — в том числе перед самым первым повтором.

  1. Python вычисляет условие после while.
  2. Если результат True, выполняется всё тело цикла.
  3. После тела программа возвращается к условию и вычисляет его заново.
  4. Если результат False, цикл заканчивается.
Ноль повторений — тоже результат

Если условие ложно при первой проверке, тело while не выполнится ни разу.

§3Цикл со счётчиком

Переменная number начинается с 1. В конце каждого повторения она увеличивается, поэтому после вывода числа 5 условие становится ложным.

§4Когда число повторений неизвестно

Один из типичных сценариев — принимать значения, пока пользователь не введёт специальный сигнал завершения. В примере таким сигналом служит ноль.

Заранее неизвестно, сколько чисел будет введено. Поэтому цикл удобно завершить в тот момент, когда получен ноль.

§6Досрочный выход: break

break немедленно завершает ближайший цикл независимо от его условия.

§7Пропуск шага: continue

continue прекращает только текущее повторение и сразу возвращает программу к следующей проверке условия.

Счётчик увеличивается до continue. Если перенести number += 1 ниже, то при значении 3 программа будет бесконечно пропускать строку увеличения.

§8Блок else у цикла

else после while выполняется при обычном завершении: когда условие стало ложным. Если цикл прерван через break, блок else пропускается.

§9Квадраты до границы

Задача: вывести квадраты натуральных чисел, которые не превышают заданное значение.

§10Анализ цифр числа

Задача: узнать, сколько раз в натуральном числе встречается цифра 3 и сколько раз повторяется его последняя цифра.

Выражение number % 10 получает последнюю цифру, а number //= 10 удаляет её. Без удаления цифры условие number > 0 не изменялось бы.

§13Проверьте себя

Может ли тело while не выполниться ни разу?

Да. Условие проверяется до первого входа в тело. Если оно сразу ложно, цикл пропускается.

Чем отличаются break и continue?

break завершает весь цикл, а continue пропускает остаток только текущего повторения.

Когда выполнится else после while?

Когда цикл завершился обычным способом, потому что условие стало ложным. После break этот блок не выполняется.

Итог главы

while проверяет условие перед каждым повторением и работает, пока оно истинно. Чтобы цикл завершился, его условие должно измениться или должен выполниться break. continue пропускает один шаг, а else отмечает завершение без break.
