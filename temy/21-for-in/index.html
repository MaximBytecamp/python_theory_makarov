§1Что делает for

for используют, когда нужно пройти по готовому набору значений. На каждом повторении цикл берёт следующее значение, помещает его в переменную и выполняет тело.

После последовательности ставится двоеточие. Тело цикла записывается с отступом в четыре пробела.

§2Переменная цикла

  1. number получает первое значение 1, затем выполняется print().
  2. Переменная получает 2, и тело выполняется снова.
  3. Так продолжается до последнего значения 5.
  4. Когда значения закончились, цикл завершается.

Название переменной выбирает программист. Лучше называть её по смыслу одного элемента: number, letter, name.

§3Перебор строки

Строку можно перебирать посимвольно. На каждом повторении переменная получает один символ.

§4Перебор списка

Список хранит несколько значений в квадратных скобках. Подробно списки разбираются в модуле о коллекциях, но цикл работает с ними по тому же принципу.

§5Числа через range()

range() создаёт диапазон целых чисел, который удобно перебирать циклом for.

Следующая глава отдельно разбирает начало, границу и шаг range().

§6Досрочный выход: break

break немедленно завершает ближайший цикл. Значения, которые остались в последовательности, уже не обрабатываются.

§7Пропуск шага: continue

continue пропускает остаток текущего повторения, после чего for берёт следующее значение.

§8Блок else у цикла

else после for выполняется, если перебор завершился без break. Если последовательность закончилась обычным образом, блок запускается даже после нуля повторений.

§9Поиск делителя

Связка for / break / else удобна для поиска. Если делитель найден, break завершает цикл. Если не найден ни один, выполняется else.

Этот вариант рассчитан на целые числа не меньше 2. Для меньших значений нужно добавить отдельную проверку.

§10Итерация и итерируемый объект

Итерация — одно выполнение тела цикла. Итерируемый объект — объект, из которого for может по очереди получать значения.

ОбъектЧто получает переменная цикла
строкаочередной символ
список или кортежочередной элемент
range()очередное целое число диапазона
словарьочередной ключ при обычном переборе

Как именно объекты отдают значения циклу, будет разобрано в отдельной теме об итераторах. Пока достаточно модели «for берёт следующий элемент».

§12Проверьте себя

Сколько раз выполнится тело для строки "Code"?

Четыре раза — по одному разу для символов C, o, d и e.

Чем for отличается от while?

for перебирает готовые значения, а while повторяет блок, пока условие истинно.

Когда выполнится else цикла for?

Когда перебор завершился без break.

Итог главы

for получает значения из итерируемого объекта по одному. Переменная цикла хранит текущее значение, а тело выполняется для каждого элемента. break завершает перебор, continue пропускает один шаг, а else выполняется при завершении без break.
