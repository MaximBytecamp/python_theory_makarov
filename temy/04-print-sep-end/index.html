§1Параметры со значением по умолчанию

Кроме самих значений print() принимает именованные параметры — их передают по имени, через знак =, после всех выводимых значений. Два из них нужны постоянно:

ПараметрЗа что отвечаетЗначение по умолчанию
sepчто ставится между значениями" " — пробел
endчто ставится в конце вывода"\n" — перевод строки

Значение по умолчанию — это то, что подставляется, когда вы параметр не указали. Поэтому print(a, b) и print(a, b, sep=" ", end="\n") работают одинаково: во втором случае значения параметров указаны явно.

§2sep — разделитель между значениями

Параметр sep (от separator) задаёт, чем разделяются значения, перечисленные через запятую.

Разделителем может быть любая строка — символ, несколько символов или вообще пустая строка. Обратите внимание: он ставится только между значениями, но не в начале и не в конце.

Последняя строка — типичное применение: собрать дату, путь или список через один и тот же знак, не расставляя его руками между каждой парой значений.

§3end — чем заканчивается вывод

Параметр end задаёт, что будет добавлено после всего выведенного. По умолчанию это перевод строки — поэтому каждый следующий print() начинается с новой строки.

Заменим перевод строки на пустую строку — и переноса не будет: следующий вывод продолжится там же, где закончился предыдущий.

§4Что такое \n

Запись "\n" выглядит как два символа, но означает один — перевод строки. Обратный слеш здесь начинает управляющую последовательность: сочетание, которым записывают символ, не имеющий видимого начертания.

ЗаписьЧто означает
\nперевод строки — то, что происходит при нажатии Enter
\tтабуляция, отступ до следующей позиции колонки
\\сам обратный слеш
\"кавычка внутри строки в таких же кавычках

§5sep и end вместе

Оба параметра передаются в одном вызове, порядок между ними неважен — они именованные. Важно другое: сначала перечисляются все выводимые значения, и только потом идут параметры.

Не увлекайтесь: тот же результат короче и понятнее даёт f-строка — print(f"итого: {total} руб."). Параметры sep и end хороши не для украшения одной строки, а там, где значений много или вывод собирается из нескольких вызовов.

§6Разбор задачи: вывод в строку

Настоящая польза от end видна, когда вызовов много и они идут не подряд в коде, а, например, в цикле. Циклы мы разберём в модуле 2, но идея видна и на трёх строках: без end="" каждый вывод занимал бы свою строку экрана, с ним — все складываются в одну.

На полях: как выбрать между sep и f-строкой

Если разделитель одинаков для всех значений и их много — берите sep: один параметр вместо повторяющегося текста. Если между значениями разный текст — «Имя: …, возраст: …» — берите f-строку. Смешивать оба подхода в одном выводе можно, но читать такую строку тяжело.

§8Проверьте себя

Что выведет print("a", "b", "c", sep="")?

abc. Пустая строка в качестве разделителя означает, что между значениями не ставится ничего. Перевод строки в конце при этом остаётся: за него отвечает end, а он не менялся.

Сколько строк займёт вывод: print("Hello", end=" "), затем print("world")?

Одну: Hello world. Первый вызов закончился пробелом вместо переноса, поэтому второй продолжил ту же строку и уже сам её завершил.

Чем отличается print(1, 2, 3, sep="\n") от трёх отдельных вызовов print(1), print(2), print(3)?

На экране — ничем, результат одинаковый: три строки. Отличие в коде: один вызов вместо трёх. Так удобно выводить набор значений, который у вас уже есть под рукой.

Почему в print("Python", end=" "), print("Java", end=" "), print("C++") у последнего вызова не задан end?

Потому что вывод нужно завершить переносом строки — иначе следующий текст в консоли прилипнет к C++. У последнего вызова end оставляют по умолчанию именно для этого.

Задача для практики: вывести дату 04.09.2026, имея три переменные — day = 4, month = 9, year = 2026.

Через sep: print(day, month, year, sep=".") — но получится 4.9.2026, без ведущих нулей. Чтобы вышло ровно 04.09.2026, нужна f-строка с указанием ширины: print(f"{day:02d}.{month:02d}.{year}"). Хороший пример того, где sep уже не хватает.

Итог главы

У print() есть два параметра, которые обычно не указывают, потому что их значения по умолчанию подходят: sep=" " ставит пробел между значениями, end="\n" переводит строку в конце. Задав их явно, вы управляете форматом вывода: собираете дату через точку, печатаете значения столбиком или склеиваете несколько вызовов в одну строку. Для текста с разными подписями по-прежнему удобнее f-строка — sep и end берут своё там, где формат однороден.
