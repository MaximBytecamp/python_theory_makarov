Unicode, ord()
и chr()

Строка Python хранит символы Unicode. Функция ord() получает кодовую точку одного символа, а chr() выполняет обратное преобразование.

§1Символу соответствует кодовая точка

Unicode задаёт единое пространство кодовых точек для букв, цифр, знаков и множества других символов. Кодовая точка — целое число, например U+0041 для латинской A.

§2ord() принимает ровно один символ

Аргумент должен иметь тип str и длину 1. Пустая строка и строка из нескольких символов вызывают TypeError.

§5Допустимый диапазон chr()

Python принимает кодовые точки от 0 до 0x10FFFF, то есть до 1_114_111 включительно. Число вне диапазона вызывает ValueError.

§10Проверьте себя

Что возвращает ord()?

Целое число — кодовую точку единственного символа Unicode.

Как восстановить символ из результата ord()?

Передать число в chr().

Почему ord("ab") вызывает ошибку?

Функция принимает один символ, а переданная строка содержит два.

Итог главы

ord() переводит один символ в кодовую точку, chr() выполняет обратное преобразование. Для получения кодов нескольких символов строку нужно перебрать.
