1.6

Множественное
присваивание

Python позволяет присвоить значения нескольким переменным одной строкой. Приём выглядит как сокращение записи, но за ним стоит важная деталь механизма: правая часть вычисляется целиком до того, как хоть одно имя получит новое значение. Именно это делает возможным обмен значениями без третьей переменной.

Приём уместен, когда переменные связаны по смыслу и читаются как одна мысль: x, y = 0, 0, day, month, year = 4, 9, 2026. А вот собирать в одну строку четыре разнородных значения не стоит — короче станет, понятнее нет.

§2Как это выполняется

Здесь и находится суть темы. Интерпретатор выполняет такую строку в два отдельных шага:

  1. Полностью вычисляет правую часть — все значения сразу, до единого.
  2. Присваивает готовые значения именам слева, по порядку.

Никакое имя слева не меняется, пока правая часть не досчитана. Поэтому в правой части всегда используются старые значения переменных — те, что существовали до начала строки. Запомните это: почти всё остальное в главе — следствие.

На полях: количество должно совпадать

Имён слева и значений справа должно быть поровну. При несовпадении программа остановится с ValueError: too many values to unpack или not enough values to unpack — сообщение прямо говорит, чего оказалось больше. Ошибка возникает при выполнении строки, а не при написании, так что редактор о ней не предупредит.

§5Одно значение нескольким именам

Есть и вторая форма записи — цепочка знаков =. Она присваивает одно и то же значение сразу нескольким именам.

Формы легко перепутать, поэтому держите различие в голове:

Цепочку берут для начальных значений — обнулить счётчики, задать стартовые координаты. В этой главе используем её только с числами и строками. Особенности такого присваивания для списков и других коллекций разберём в отдельной теме.

§6Где это применяют

За пределами учебных примеров множественное присваивание встречается постоянно.

Последняя строка забегает вперёд — метод split() разбирается в главе о строках, — но показывает главное направление, ради которого приём и существует: получить несколько значений разом и сразу дать им имена. Так же будут возвращать результат функции в модуле 4.

Читаемость важнее краткости

Запись a, b, c, d, e = 1, 0, "нет", 3.14, "" технически безупречна, но, чтобы понять, какое значение чьё, читателю придётся считать позиции. Правило простое: объединяйте в одну строку то, что и мыслится вместе. Пара координат — да; пять разнородных настроек — пять строк.

§8Проверьте себя

Что выведет программа: a, b = 5, 10, затем a, b = b, a, затем print(a, b)?

10 5. Правая часть вычисляется целиком до присваивания, поэтому в неё попадают старые значения — 10 и 5, — и они уходят именам в обратном порядке.

Почему обмен через a, b = b, a не требует третьей переменной?

Потому что оба значения правой части вычисляются до того, как изменится хоть одно имя слева. Старое значение a уже вычислено к моменту, когда a получает новое, — терять нечего. Третья переменная нужна там, где присваивание идёт строго по одному.

Чем x = y = 0 отличается от x, y = 0, 0?

Результат для чисел одинаков: обе переменные равны нулю. Отличается смысл записи: первая даёт одно значение обоим именам, вторая раздаёт разные значения по позициям. Для чисел разницы не видно, для списков она станет принципиальной.

Что будет при выполнении x, y, z = 1, 2?

Программа остановится с ValueError: not enough values to unpack (expected 3, got 2). Имён три, значений два — интерпретатор не станет придумывать третье.

Задача для практики: пользователь вводит два числа. Выведите их в порядке возрастания, не используя условий.

Условий мы ещё не проходили, но задача решается тем, что уже есть: a, b = min(a, b), max(a, b). Встроенные функции min() и max() вернут меньшее и большее, а множественное присваивание разложит их по именам за один шаг. Дальше достаточно print(a, b).

Итог главы

Множественное присваивание раздаёт значения нескольким именам за одну строку. Работает оно в два шага: сначала целиком вычисляется правая часть, потом значения расходятся по именам слева. Из этого порядка следует главное практическое умение — обмен значениями a, b = b, a, для которого не нужна третья переменная. Форму x = y = 0 не путайте с ней: она даёт одно значение всем именам сразу.
