§1Зависимые проверки

Вложенное условие — это if внутри блока другого if. Внутренняя проверка запускается только тогда, когда программа вошла во внешнюю ветку.

Например, билет имеет смысл проверять только после проверки возраста. Если возраст не подходит, до вопроса о билете программа не доходит.

§2Общий синтаксис

Второй if находится внутри первого блока и получает ещё один уровень отступа. Действие внутри второго if имеет восемь пробелов относительно начала строки.

§3Как выполняется код

  1. Проверяется age >= 18.
  2. Если результат True, проверяется has_ticket.
  3. Сообщение выводится, только если обе проверки истинны.

При age = 17 внутренняя проверка не запускается. При age = 20 и has_ticket = False она запускается, но её блок пропускается.

§4К какому if относится else

else относится к тому if, с которым стоит на одном уровне отступа.

Здесь else выровнен со вторым if, поэтому сообщает об отсутствии билета. Он ничего не делает для случая неподходящего возраста.

§5Разные варианты вложения

Внутренние и внешние ветки else

Внешний else выровнен с первым if, а внутренний — со вторым. По отступам видно, какую проверку дополняет каждая ветка.

Вложенный if внутри else

Внутренняя проверка может находиться не только в ветке if, но и в ветке else. Тогда до неё программа доходит лишь после ложного внешнего условия.

Если бы денег хватало, выполнился бы первый блок, а has_discount вообще не проверялся бы.

Цепочка if / elif / else внутри if

Внутри внешней ветки можно выбрать один из нескольких вариантов с помощью elif.

Сначала решается вопрос о входе. Только после этого внутренняя цепочка выбирает один вариант по роли.

Действие между двумя проверками

Внешний блок может содержать свои действия до внутреннего if. Это один из случаев, когда вложение точнее передаёт ход программы, чем одно условие с and.

§6Вложение или and

Если действие одно и обе проверки равноправны, вложение можно заменить оператором and.

ВложениеСоставное условие
if age >= 18:
    if has_ticket:
        print("Вход")		if age >= 18 and has_ticket:
    print("Вход")

Вложение нужно, когда после первой проверки появляются отдельные действия или разные ответы. Если требуется только один общий результат, составное условие обычно читается проще.

§7Как не запутаться в отступах

  • каждый новый уровень if добавляет четыре пробела;
  • else выравнивается с тем if, который он дополняет;
  • не смешивайте табуляцию и пробелы;
  • если уровней стало больше двух-трёх, разделите задачу на более простые проверки.
Читайте по уровням

Сначала закройте рукой внутренний блок и поймите внешнюю проверку. Затем разберите только тот путь, по которому программа вошла внутрь.

§9Проверьте себя

Когда проверяется внутренний if?

Только после того, как программа вошла в блок внешнего if.

Как определить, к какому if относится else?

По отступу: else стоит на одном уровне со своим if.

Можно ли заменить два вложенных условия одним and?

Да, если нужно выполнить одно действие только при истинности обеих проверок. Если после первой проверки есть отдельная логика, вложение сохраняют.

§10Шпаргалка

Второй уровеньif first: if second:
Внутренний else if second: ... else:
Внешний elseif first: ...else:
Одно действиеif first and second:

Итог главы

Вложенный if создаёт зависимую проверку: внутреннее условие рассматривается только после успешного внешнего. Уровни задаются отступами, а каждый else относится к if на той же позиции. Для одного общего действия два условия часто можно соединить через and.
