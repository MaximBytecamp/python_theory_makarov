§1Список можно менять, кортеж — нельзя

Кортеж (tuple) — упорядоченная неизменяемая последовательность. У элементов остаются позиции, индексы и срезы, но сама последовательность после создания фиксирована.

§2Создание кортежа

tuple() принимает любой итерируемый объект и получает из его элементов новый кортеж.

§3Кортеж из одного элемента определяет запятая

Главная деталь

Кортеж создаёт запятая. Скобки помогают сгруппировать запись, но выражение (5) остаётся числом.

§4Индексы и срезы работают как у списка

§5Нельзя изменить структуру кортежа

Присваивание по индексу завершится TypeError. У кортежа также нет методов append(), remove() и pop().

Неизменяемость относится к позициям кортежа. Если внутри лежит список, сам список всё ещё можно менять.

§6Объединение, повторение и проверка наличия

Операторы + и * не меняют исходный кортеж: они создают новый.

§7Преобразование между коллекциями

При преобразовании множества порядок результата нельзя считать заранее известным: у множества нет позиционного порядка.

§10Пары словаря приходят как кортежи

Каждый элемент items() — пара вида (ключ, значение). Кортеж из неизменяемых элементов также можно использовать как составной ключ: visits[(user_id, date)].

§11У кортежа два собственных метода

МетодРезультатПример
count(value)число совпадений(1, 1, 2).count(1) == 2
index(value)индекс первого совпадения(10, 20).index(20) == 1

Кроме того, с кортежами работают универсальные функции: len(), min(), max(), sum(), sorted(), enumerate() и другие.

§13Проверьте себя

Что именно создаёт кортеж из одного элемента?

Запятая: (value,). Одни скобки лишь группируют выражение.

Может ли кортеж содержать изменяемый список?

Да. Нельзя заменить позицию кортежа, но вложенный список сохраняет собственную изменяемость.

Что возвращает функция с записью return x, y?

Один кортеж (x, y), который затем можно распаковать.

Итог главы

Кортеж сохраняет порядок, поддерживает индексы и срезы, но фиксирует набор позиций. Он особенно полезен для небольших структурированных записей, возврата нескольких результатов, распаковки и составных ключей словаря.
