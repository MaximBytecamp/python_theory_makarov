6.9

Lambda-функции

lambda создаёт короткую функцию из одного выражения. Обычно её передают прямо в sorted(), map() или filter(), когда отдельное имя не сделает код понятнее.

§1Что создаёт lambda

Lambda-функция — функция без имени в самой записи. Ключевое слово lambda перечисляет параметры, а выражение после двоеточия становится возвращаемым результатом.

Название происходит от λ-исчисления — математической системы для описания функций. Для использования синтаксиса Python знать её не требуется.

§2Синтаксис

После двоеточия допускается одно выражение. Его значение автоматически возвращается вызывающему коду.

§3Сравнение с def

Именованная функция

Если функции всё равно нужно имя и она используется повторно, запись через def обычно читается лучше. Основная польза lambda — передача короткой функции прямо в место использования.

§4Несколько параметров

До двоеточия можно перечислить несколько параметров через запятую.

§5Прямой вызов

Lambda-выражение можно заключить в скобки и сразу вызвать. Такой пример показывает, что конструкция действительно создаёт функцию, хотя в обычной программе чаще встречается передача функции аргументом.

§6Сортировка по ключу

Lambda удобна, когда ключ нужно извлечь из сложного элемента. В примере функция получает кортеж и возвращает его второй элемент.

§7Lambda с map()

map() вызывает переданную lambda-функцию для каждого числа.

Здесь включение [number * 2 for number in numbers] короче. Lambda становится полезнее, когда интерфейс функции явно ожидает вызываемый аргумент.

§8Lambda с filter()

Для filter() выражение должно отвечать, оставлять ли элемент.

§9Условное выражение внутри lambda

Обычные операторы if и else требуют блоков кода и не помещаются в lambda. Тернарное выражение остаётся одним выражением, поэтому допустимо.

§10Ограничения lambda

  • После двоеточия находится только одно выражение.
  • Нельзя записать несколько инструкций, присваивание или обычный многострочный if.
  • Сложные вложенные условия быстро ухудшают читаемость.
  • Для длинной логики нельзя добавить понятные промежуточные шаги.

Одно выражение может переноситься на несколько строк внутри скобок, но от этого lambda не превращается в многооператорную функцию.

§13Проверьте себя

Что возвращает lambda-функция?

Значение единственного выражения после двоеточия; слово return не пишется.

Почему в key=lambda item: item[1] нет вызова lambda?

sorted() получает функцию и самостоятельно вызывает её для каждого элемента.

Когда лучше заменить lambda на def?

Когда функция повторно используется, содержит сложную логику или нуждается в понятном имени и документации.

§14Шпаргалка

Итог главы

lambda создаёт функцию из одного выражения и автоматически возвращает его значение. Она удобна для короткого одноразового правила рядом с sorted(), map() или filter(). Повторно используемую и сложную логику лучше оформлять через def.
