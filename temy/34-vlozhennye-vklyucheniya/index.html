включения

Несколько частей for заменяют вложенные циклы, а включение внутри выражения создаёт вложенную структуру. Главное — различать плоский результат и список списков.

§1Две формы вложенности

ФормаПримерРезультат
несколько частей for[value for row in matrix for value in row]один плоский список
включение внутри выражения[[expr for x in row] for row in matrix]список списков

Обе формы связаны с вложенными циклами, но скобки определяют структуру результата.

§2Несколько частей for

Запись с двумя for повторяет порядок двух вложенных циклов.

§3Как читать порядок перебора

После выражения части for читаются слева направо: сначала внешний цикл, затем внутренний. Каждое следующее имя может использовать значения предыдущего цикла.

§4Комбинации элементов

Вложенный перебор создаёт все сочетания одного элемента из левой коллекции с одним элементом из правой.

§5Выпрямление вложенного списка

Сначала перебираются строки матрицы, затем значения каждой строки. В результате дополнительные скобки исчезают.

§6Создание матрицы

Чтобы сохранить строки отдельно, внутреннее включение помещают в квадратные скобки. Оно создаёт одну строку, а внешнее повторяет создание строк.

  1. Внешний цикл получает row = 0.
  2. Внутреннее включение создаёт [0, 1, 2].
  3. Внешний цикл переходит к row = 1 и создаётся следующая строка.
  4. После трёх повторений готов список из трёх списков.

§8Условие во вложенном переборе

Условие относится к тому циклу, после которого оно записано. В примере сначала выбирается строка, затем из неё остаются только чётные значения.

§9Когда лучше обычные циклы

Вложенное включение подходит, если соответствующие циклы короткие и их цель видна сразу. Если появляются несколько условий, промежуточные вычисления или три уровня вложенности, разверните конструкцию в циклы.

§11Проверьте себя

Что создаёт запись [x for row in matrix for x in row]?

Один плоский список из всех элементов всех строк.

В каком порядке выполняются две части for?

Слева направо: первая соответствует внешнему циклу, вторая — вложенному.

Как сохранить строки матрицы отдельными списками?

Сделать внутреннее включение выражением внешнего: [[expr for x in row] for row in matrix].

§12Шпаргалка

Комбинации[(x, y) for x in A for y in B]
Выпрямление[x for row in matrix for x in row]
Матрица[[expr for x in row] for row in matrix]
С фильтром[x for row in matrix for x in row if test]

Итог главы

Несколько частей for создают плоский результат в том же порядке, что и вложенные циклы. Включение в квадратных скобках внутри другого включения сохраняет вложенную структуру. Если запись перестаёт быстро читаться, обычные циклы подходят лучше.
