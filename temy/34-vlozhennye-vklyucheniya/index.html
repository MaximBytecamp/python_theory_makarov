§1Две разные вложенности

Начать нужно с различия, без которого дальше всё сольётся. Формы похожи, результаты противоположны.

ФормаПризнакРезультатЗадача
несколько forскобки одниплоский списокразвернуть или скомбинировать
включение внутривторые скобки слевасписок списковпостроить таблицу

Простое правило: сколько пар скобок — столько уровней в результате.

§2Несколько частей for

Части for в одном включении работают как вложенные циклы: каждая следующая перебирается полностью для каждого значения предыдущей.

Тот же результат даёт вложенный цикл из главы 3.7.

§3Порядок перебора

Отсюда правило чтения: части for идут в том же порядке, что вложенные циклы, — слева направо, сверху вниз.

Быстрее всего меняется последняя переменная — как в вывод из §2: сначала перебраны обе цифры для A, потом для B.

§4Выпрямление таблицы

Главное применение формы с двумя for — превратить список списков в плоский.

Читается это так: «для каждой строки в таблице, для каждого элемента в строке — взять элемент». Двумерные списки разбирались в главе 3.13.

§5Порядок нельзя менять

Части for зависят друг от друга: вторая использует переменную первой. Поменять их местами не выйдет.

Это частая ошибка: по аналогии с выражением слева хочется поставить «главное» вперёд. Но части for читаются строго слева направо, как вложенные циклы.

§6Комбинации значений

Когда источники независимы, получаются все сочетания.

Число элементов результата — произведение длин: два размера на два цвета дают четыре. С тремя источниками по десять элементов получится уже тысяча, и об этом стоит помнить.

§7Включение внутри выражения

Вторая форма: на месте «что положить» стоит целое включение. Тогда каждый элемент результата сам становится списком.

Сравните с §4: те же данные, почти те же слова, но результат другой. Разница — во вторых квадратных скобках слева.

§8Создание матрицы

Приём из главы 4.10, теперь в контексте вложенности.

Внутреннюю строку можно построить и включением: [[0 for _ in range(3)] for _ in range(2)]. Результат тот же, запись длиннее — умножение здесь читается лучше.

§9Таблица умножения

Классический пример, где внутреннее включение зависит от внешней переменной.

Внешнее включение задаёт строки, внутреннее — ячейки внутри строки. Переменная i доступна внутреннему включению, потому что оно вычисляется для каждого значения i заново.

§10Зависимая вложенность

Внутренняя часть может зависеть от внешней и в форме с двумя for — тогда длины строк получатся разными.

Такие «рваные» таблицы встречаются реже прямоугольных, но включение справляется с ними так же.

§11Условие: где его ставить

С двумя формами появляются и два места для if — и они дают разный результат.

Первая запись теряет разбиение на строки, вторая его сохраняет — и допускает пустые строки, если в какой-то не нашлось подходящих элементов. Выбор зависит от того, нужна ли структура дальше.

§12Три уровня

Ограничений на число частей for нет, но читаемость падает быстро.

Три уровня — практический предел. Дальше строка перестаёт читаться, и обычные циклы становятся понятнее.

§15Проверьте себя

Как по записи понять, будет результат плоским или вложенным?

По числу пар квадратных скобок: одни скобки с двумя for дают плоский список, вторые скобки слева — список списков.

В каком порядке перебираются части for?

Слева направо, как вложенные циклы: первая часть — внешний цикл, последняя меняется быстрее всех.

Почему [x for x in row for row in matrix] даёт NameError?

Части for читаются слева направо, и row используется раньше, чем объявляется.

Чем отличаются два места для if при вложенности?

if в конце общего включения фильтрует элементы плоского результата. if внутри вложенного включения фильтрует внутри каждой строки, сохраняя структуру.

Сколько элементов даст включение по двум источникам?

Произведение их длин: два размера и два цвета — четыре комбинации.

Когда включение стоит заменить циклами?

Когда уровней больше трёх, в теле нужно несколько действий или требуется break.

§16Шпаргалка

Выпрямить[x for row in m for x in row]
Сохранить форму[[f(x) for x in row] for row in m]
Комбинации[(a, b) for a in A for b in B]
Матрица[[0] * n for _ in range(m)]
Таблица[[i * j for j in R] for i in R]
Отбор плоско[x for r in m for x in r if cond]
Отбор в строке[[x for x in r if cond] for r in m]

Итог главы

Вложенность бывает двух видов, и различает их число пар скобок. Несколько частей for в одних скобках работают как вложенные циклы и дают плоский результат — это способ выпрямить таблицу или собрать комбинации. Включение внутри выражения даёт список списков и сохраняет структуру. Порядок частей for строго слева направо: переставить их нельзя, потому что каждая следующая опирается на переменную предыдущей. Место для if тоже зависит от формы и определяет, останется ли разбиение на строки.
