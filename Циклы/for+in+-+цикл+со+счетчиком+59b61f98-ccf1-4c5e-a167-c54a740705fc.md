Цикл `for` в Python используется для **повторного выполнения блока кода определённое количество раз** или **для перебора элементов последовательности**.

Общий синтаксис:

```Python
for переменная in последовательность:
    блок_кода
```

---

# Как работает цикл

Цикл последовательно берёт элементы из коллекции и присваивает их переменной.

Пример:

```Python
for i in [1, 2, 3, 4, 5]:
    print(i)
```

Результат:

```Python
1
2
3
4
5
```

Здесь:

```Python
i — переменная цикла
[1,2,3,4,5] — последовательность
```

# Перебор строки

Строка тоже является последовательностью.

```Python
for letter in "Python":
    print(letter)
```

Результат:

```Python
P
y
t
h
o
n
```

# Перебор списка

```Python

for n in numbers:

```

# Функция range()

Чаще всего `for` используется вместе с функцией `range()`.

Она создаёт последовательность чисел.

### range(stop)

```Python
for i in range(5):
    print(i)
```

Результат:

```Python
0
1
2
3
4
```

---

### range(start, stop-1)

```Python
for i in range(2, 6):
    print(i)
```

Результат:

```Python
2
3
4
5
```

---

### range(start, stop-1, step)

```Python
for i in range(0, 10, 2):
    print(i)
```

Результат:

```Python
0
2
4
6
8
```

# Оператор break

`break` полностью **останавливает цикл**.

```Python
for i in range(10):
    if i == 5:
        break
    print(i)
```

Результат:

```Python
0
1
2
3
4
```

---

# Оператор continue

`continue` **пропускает текущую итерацию**.

```Python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

Результат:

```Python
0
1
3
4
```

---

# Цикл с else

В Python цикл может иметь блок `else`.

Он выполняется **если цикл завершился без break**.

```Python
for i in range(5):
    print(i)
else:
    print("Цикл завершён")
```

Результат:

```Python
0
1
2
3
4
Цикл завершён
```

---

# Пример с break и else

```Python
number = 7

for i in range(2, number):
    if number % i == 0:
        print("Не простое число")
        break
else:
    print("Простое число")
```

Здесь:

- если найден делитель → `break`

- если делителей нет → выполняется `else`

# Итерация, итератор, итерируемость

Эти понятия связаны с работой цикла `for`.

**Итерация** — один проход цикла.

**Итерируемый объект** — объект, по которому можно пройти циклом.

Примеры итерируемых объектов:

```Python
строки
списки
кортежи
множества
словари
range
```

---

# Пример задачи №1

Вывести квадраты чисел от 1 до 5.

```Python
for i in range(1, 6):
```

# Пример задачи №2

Найти сумму чисел.

