`range()` — это встроенная функция Python, которая создаёт **последовательность чисел в заданном диапазоне**.

Чаще всего она используется **в циклах `for`**, когда нужно выполнить действие определённое количество раз.

---

# Сигнатура функции

```Python
range(start, stop, step)
```

Где:

- **start** — начало диапазона (включительно)

- **stop** — конец диапазона (не включается)

- **step** — шаг (по умолчанию равен `1`)

---

# Основные формы использования

## 1. range(stop)

Если указать только одно число, диапазон начнётся с **0**.

```Python
for i in range(5):
    print(i)
```

Результат:

```Python
0
1
2
3
4
```

Здесь создаётся последовательность:

```Python
0 → 1 → 2 → 3 → 4
```

---

# 2. range(start, stop)

Можно задать начало диапазона.

```Python
for i in range(2, 6):
    print(i)
```

Результат:

```Python
2
3
4
5
```

---

# 3. range(start, stop, step)

Третий параметр задаёт **шаг изменения числа**.

```Python
for i in range(0, 10, 2):
    print(i)
```

Результат:

```Python
0
2
4
6
8
```

---

# Пример обратного диапазона

`range()` также может работать **в обратном направлении**.

```Python
for i in range(5, 0, -1):
    print(i)
```

Результат:

```Python
5
4
3
2
1
```

---

# Использование `range()` со списками

Иногда требуется пройти по **индексам списка**.

Для этого используется конструкция:

```Python
range(len(список))
```

Пример:

```Python
lst = [10, 20, 30]

for i in range(len(lst)):
    print(i, lst[i])
```

Результат:

```Python
0 10
1 20
2 30
```

Здесь:

```Python
i — индекс элемента
lst[i] — сам элемент списка
```

---

# Важно помнить

`range()` **не создаёт список чисел**, а создаёт специальный объект диапазона.

Например:

```Python
print(range(5))
```

Результат:

```Python
range(0, 5)
```

Если нужно получить список:

```Python
print(list(range(5)))
```

Результат:

```Python
[0, 1, 2, 3, 4]
```

---

# Итог

Функция `range()` используется для создания последовательности чисел.

Основные формы:

```Python
range(stop)
range(start, stop)
range(start, stop, step)
```

Применяется чаще всего:

- в циклах `for`

- при переборе индексов

- при создании числовых последовательностей.
