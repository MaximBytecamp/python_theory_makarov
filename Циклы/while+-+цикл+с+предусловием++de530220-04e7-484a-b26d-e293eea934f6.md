Цикл `while` — это конструкция в Python, которая **повторяет выполнение блока кода до тех пор, пока заданное условие остаётся истинным**.

Он используется в тех случаях, когда **количество повторений заранее неизвестно** и зависит от выполнения некоторого условия.

---

# Общий синтаксис

```Python
while условие:
    блок_кода
```

Работа цикла:

1. Проверяется условие

2. Если условие **True** → выполняется тело цикла

3. После выполнения условие проверяется снова

4. Если условие **False** → цикл завершается

---

# Простой пример

```Python
i = 1

while i <= 5:
    print(i)
    i += 1
```

Результат:

```Python
1
2
3
4
5
```

Здесь:

```Python
i += 1
```

увеличивает значение переменной, чтобы условие со временем стало ложным.

---

# Потенциальная бесконечность

Если условие **никогда не станет False**, цикл будет бесконечным.

Пример бесконечного цикла:

```Python
while True:
    print("Этот цикл будет выполняться бесконечно")
```

Такие циклы иногда используются в программах, которые должны **работать постоянно** (например серверы).

---

# break в цикле while

Оператор `break` **прерывает цикл** независимо от условия.

```Python
i = 1

while True:
    print(i)

    if i == 5:
        break

    i += 1
```

Результат:

```Python
1
2
3
4
5
```

---

# continue в цикле while

`continue` пропускает текущую итерацию.

```Python
i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)
```

Результат:

```Python
1
2
4
5
```

---

# while + else

Как и `for`, цикл `while` может иметь блок `else`.

Он выполняется **если цикл завершился без break**.

```Python
i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("Цикл завершён")
```

Результат:

```Python
1
2
3
Цикл завершён
```

# Сравнение циклов `for` и `while`

|Цикл|Когда используется|
|-|-|
|`for`|Когда известно количество итераций|
|`while`|Когда выполнение зависит от условия|

`for`

```Python
известное количество повторений
```

`while`

```Python
повторение до выполнения условия
```

# Пример №1

### Найти сумму и количество чисел последовательности

Дана последовательность чисел, которая заканчивается **нулём**.

Нужно найти:

```Python
1. сумму всех чисел
2. количество чисел
```

### Решение

```Python
total_sum = 0
count = 0

while True:
    num = int(input("Введите число: "))

    if num == 0:
        break

    total_sum += num
    count += 1

print("Сумма:", total_sum)
print("Количество:", count)
```

# Пример №2

### Вывести квадраты чисел, не превышающие n

Дано число `n`.

Нужно вывести:

```Python
1², 2², 3², ...
```

пока квадрат не станет больше `n`.

### Решение

```Python
n = int(input("Введите число: "))

i = 1

while i * i <= n:
    print(i * i)
    i += 1
```

Пример результата (n = 30):

```Python
1
4
9
16
25
```

# Пример №3

### Анализ цифр числа

Дано натуральное число.

Нужно определить:

```Python
1. количество цифр 3
2. сколько раз встречается последняя цифра
```

### Решение

```Python
n = int(input("Введите число: "))

last_digit = n % 10
count_three = 0
count_last = 0

while n > 0:
    digit = n % 10

    if digit == 3:
        count_three += 1

    if digit == last_digit:
        count_last += 1

    n //= 10

print("Количество цифр 3:", count_three)
print("Количество последней цифры:", count_last)
```
